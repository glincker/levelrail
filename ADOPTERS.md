# Adopters

Organizations and teams that run Levelrail in production are welcome to list themselves here. The list is empty until someone adds an entry, and no one is listed by default.

## How to add your organization

1. Open a pull request that adds one row to the table above.
2. Use your organization's public name and a short, factual use case (one line).
3. Leave the contact column empty if you do not want it published. Do not include secrets, internal hostnames or customer data.

Entries are reviewed by the maintainer before merge.
