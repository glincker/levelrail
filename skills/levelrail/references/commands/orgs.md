## levelrail-cli orgs

Subcommands: avatar, rename, set-description, set-slug, show

```
Usage:
  levelrail-cli orgs show <org> [--json]                   profile, counts, failing apps and recent activity
  levelrail-cli orgs rename <org> <name>                   change the display name (org admins)
  levelrail-cli orgs set-slug <org> <slug>                 3 to 40 chars: lowercase letters, digits, single hyphens; "" clears
  levelrail-cli orgs set-description <org> <text>          at most 500 characters; "" clears
  levelrail-cli orgs avatar set <org> <file>               upload a PNG or JPEG avatar
  levelrail-cli orgs avatar rm <org> [--yes]               remove the avatar

"teams" accepts the same verbs. Every command takes --token, --api-url, --profile and --json.
```
