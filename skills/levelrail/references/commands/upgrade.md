## levelrail-cli upgrade

Subcommands: auto, backup-now, cancel, retry, rollback, schedule, status

```
Usage:
  levelrail-cli upgrade [flags]

Checks the running version against the latest release, runs the preflight
(release signature, Docker Engine, free disk, backup), takes a control plane
backup, and prints the command that upgrades. It never upgrades by itself.

--history shows every recorded upgrade and --ack <id> acknowledges one;
--plan (or --dry-run) shows breaking changes and the rollback commands and --apply upgrades with automatic rollback;
--attempts lists self-upgrade runs; --migrate-check tries the pending migrations on a copy of the database; --rollback <version> --yes returns to a retained release (binary only); --list shows recent releases; --rollback-plan <version> previews returning to
one. The upgrade is refused when its backup fails or the disk is short unless you pass --skip-backup. Subcommands: schedule (--at TIME | --window, show, cancel), auto (get, set) and backup-now. A rollback that needs a backup restore is applied on the host with `sudo <control plane binary> rollback`.

Flags:
  -ack id
    	acknowledge the recorded upgrade id
  -ack-breaking ids
    	with --apply: comma-separated breaking-change ids you acknowledge
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -apply
    	download, verify, back up, swap and health-check the new release, rolling back automatically on failure
  -attempts
    	list recorded self-upgrade attempts with their step timelines
  -channel string
    	with --list: stable, beta or all (default: the configured channel)
  -dry-run
    	same as --plan: show target schema, migration count and rollback commands, change nothing
  -history
    	list recorded control plane upgrades, rollbacks and installs (add --json for JSON)
  -json
    	print the preflight as JSON to stdout and nothing else
  -list
    	list the last 5 releases with a schema compatibility verdict
  -migrate-check
    	try the running binary's pending migrations on a copy of the database and report; the live database is not touched
  -no-backup
    	do not take the control plane backup at all
  -no-wait
    	with --apply: return once the upgrade has started instead of following it
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -plan
    	show the breaking changes between the running version and the target, change nothing
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -rollback version
    	roll the control plane back to retained release version (binary only, needs --yes)
  -rollback-plan version
    	preview a rollback to version (read-only; applying happens on the host)
  -skip-backup
    	do not stop when the control plane backup fails or the disk is short; with --apply the upgrade then has no database restore point
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -version tag
    	with --apply or --plan: release tag to install (default: latest on the channel)
  -yes
    	with --rollback: confirm the rollback
```

## levelrail-cli upgrade auto

Subcommands: get, set

```
Usage:
  levelrail-cli upgrade auto get
  levelrail-cli upgrade auto set --mode off|patch|any [flags]

Automatic upgrades are on by default (any eligible release, 03:00 UTC for 2h) until a policy is saved;
turn them off with --mode off. Releases with breaking changes that need acknowledgement,
and major version jumps, are never applied automatically.

Flags:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -json
    	print the result as JSON to stdout and nothing else
  -min-age-days days
    	wait this many days after a release is published
  -mode string
    	off, patch (same minor version only) or any (any new release on the channel)
  -notify ids
    	comma-separated notification channel ids (empty keeps the current ones)
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -pause
    	pause automatic upgrades without losing the policy
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -resume
    	resume paused automatic upgrades
  -timezone string
    	IANA timezone the window cron is evaluated in
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -window-cron expression
    	maintenance window start as a cron expression, for example "0 3 * * *"
  -window-duration duration
    	how long the window stays open, for example 2h
```

## levelrail-cli upgrade schedule

Subcommands: cancel, show

```
Usage:
  levelrail-cli upgrade schedule [--at TIME | --window] [flags]
  levelrail-cli upgrade schedule show
  levelrail-cli upgrade schedule cancel

Schedules the control plane upgrade. The preflight re-runs at the scheduled time and the upgrade
is not applied if it fails; it then retries until the grace period or window ends.

Flags:
  -ack-breaking ids
    	comma-separated breaking-change ids you acknowledge
  -ack-major
    	acknowledge a major version jump
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -at time
    	run at time: RFC 3339 (2026-10-12T03:00:00+02:00) or a local time like "2026-10-12 03:00"
  -json
    	print the result as JSON to stdout and nothing else
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -replace
    	replace an existing pending schedule
  -timezone string
    	IANA timezone a local --at time is in (default: the server's)
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -version tag
    	release tag to install (default: latest on the channel)
  -window
    	run in the next maintenance window instead of at a time
```
