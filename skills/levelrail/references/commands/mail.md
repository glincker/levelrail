## levelrail-cli mail

Subcommands: audiences, broadcasts, dns, status, suppressions

```
Usage:
  levelrail-cli mail status                       show whether the mail server is installed, running and ready
  levelrail-cli mail ports [--app name]                  list the four mail ports, their bind and firewall state
  levelrail-cli mail ports open --confirm [--app name]    make 25, 465, 587, 993 public and allow them in the firewall (asks your password)
  levelrail-cli mail domains list                          list the mail domains your teams own
  levelrail-cli mail domains claim <domain> --team ID [--app name]   give a served domain to one team (asks your password)
  levelrail-cli mail mailboxes list [--domain D]           list mailboxes
  levelrail-cli mail mailboxes add <address> [--linked-user ID]    create a mailbox; prints its password once
  levelrail-cli mail mailboxes suspend|resume <address>    block or allow logins; mail keeps arriving while suspended
  levelrail-cli mail mailboxes passwd <address>            set a new generated password, shown once (asks your password)
  levelrail-cli mail mailboxes delete <address> --confirm <address> [--delete-mail]   delete for good (asks your password)
  levelrail-cli mail aliases list --domain D               list a domain's aliases
  levelrail-cli mail aliases add <address> --to a@d,b@d    forward an address to mailboxes your team owns
  levelrail-cli mail aliases remove <address>              remove an alias
  levelrail-cli mail queue list [--app name] [--max N]     list queued mail (sender, recipient domain, attempts, last error)
  levelrail-cli mail queue hold|release [--app name] [--ids 1,2]   pause or resume delivery; release asks your password
  levelrail-cli mail cert status [--app name]            show the served certificate: subject, issuer, expiry, days left, self-signed or not
  levelrail-cli mail cert upload --cert F --key F [--app name] [--restart-now]   install your own certificate (asks your password)
  levelrail-cli mail cert obtain [--app name]             get one through ACME (not yet implemented)
  levelrail-cli mail backup run [--app name] [--wait]   back up, verify and encrypt the mail server now
  levelrail-cli mail backup list [--app name]           list backups with size, mox version and verified state
  levelrail-cli mail backup verify <id> [--app name]    check a backup decrypts and matches its checksum (dry-run restore)
  levelrail-cli mail backup restore <id> [--app name] [--confirm <id>]   dry run, or with --confirm <id> restore for real (asks your password)
  levelrail-cli mail storage show [--app name]          show the backup destination
  levelrail-cli mail storage set --kind local|s3 [--bucket B --access-key-id K --secret-env VAR --endpoint URL --region R --path-style] [--app name]
  levelrail-cli mail storage test [--app name]          run the destination check again (put, get, list, delete)
  levelrail-cli mail system-email status            show whether system emails go through your mail server
  levelrail-cli mail system-email enable <domain> [--to ADDR] [--port 587|465] [--replace-existing]   send invites, resets and alerts as noreply@<domain> (asks your password)
  levelrail-cli mail system-email disable            put the previous email provider back and suspend noreply (asks your password)
  levelrail-cli mail system-email rotate             set a new noreply password; it is sealed, never shown (asks your password)
  levelrail-cli mail system-email test [--to ADDR]   send a test email through your mail server
  levelrail-cli mail broadcasts list                       list broadcasts with sent, failed and suppressed counts
  levelrail-cli mail broadcasts send --subject S (--body T | --body-file F) (--audience ID | --to a@d,b@d) [--schedule RFC3339] [--dry-run]
                                                   queue an announcement; --dry-run only counts who would get it
  levelrail-cli mail broadcasts cancel <id>                stop a scheduled or running broadcast
  levelrail-cli mail audiences list                        list saved recipient groups
  levelrail-cli mail suppressions list|add|remove [address] [--reason R]   manage addresses that never get announcements
  levelrail-cli mail dns plan <domain> [flags]    dry run: diff the mail records against the live zone
  levelrail-cli mail dns apply <domain> --plan-hash H --confirm [flags]   write a plan you reviewed
  levelrail-cli mail dns check <domain> [--host H] [--dkim-selector S]    grade the live mail DNS
  levelrail-cli mail dns provider <domain>        where the domain's DNS lives and whether it is connected
  levelrail-cli mail dns status <domain>          each mail record: live, waiting, different, conflict or unknown
  levelrail-cli mail dns domains                  candidate domains: install, claimed, app domains and zones
  levelrail-cli mail dns applied <domain>         the records mail DNS added, with provider record ids

Plan and apply flags (same values on both, or the plan hash will not match):
  --host H  --ipv4 IP  --ipv6 IP  --mx-priority N  --preset ID
  --spf-mode server|include  --spf-include HOSTS  --dkim-selector S  --dkim-key-file F
  --dmarc-policy none|quarantine|reject  --dmarc-rua ADDR  --dmarc-pct N
  --mta-sts testing|enforce  --tls-rpt  --autoconfig  --replace-existing KINDS
  --provider P  --plan-hash H  --confirm
Without --provider, plan and apply use the connected provider the domain's
nameservers point at, falling back to the first connected one.

Experimental: needs APP_EXPERIMENTAL=mail. The default is add-only: existing
MX, SPF, DKIM and DMARC records are never replaced unless --replace-existing
lists their kind (MX, SPF, DKIM, DMARC, HOST, MTASTS, TLSRPT, AUTOCONFIG).
Presets: fastmail, google, mailgun, postmark, proton, ses, zoho.
```
