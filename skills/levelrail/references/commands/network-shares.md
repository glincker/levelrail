## levelrail-cli network-shares

Subcommands: create, delete, get, list, test, update

```
Usage:
  levelrail-cli network-shares list [flags]                                                                         list connected network shares
  levelrail-cli network-shares get <id> [flags]                                                                      show one network share
  levelrail-cli network-shares create --name NAME --protocol nfs|cifs --host HOST --remote-path PATH [flags]         connect a new network share
  levelrail-cli network-shares update <id> --name NAME --protocol nfs|cifs --host HOST --remote-path PATH [flags]    update a network share, optionally rotating its password
  levelrail-cli network-shares delete <id> [flags]                                                                   disconnect a network share
  levelrail-cli network-shares test <id> [flags]                                                                     check a share's host is reachable on its protocol's standard port

Run "levelrail-cli network-shares <subcommand> -h" for a subcommand's own flags.
```
