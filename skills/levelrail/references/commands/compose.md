## levelrail-cli compose

Subcommands: deploy, down, logs, preview, redeploy, revisions, rollback, schedules, status

```
Usage:
  levelrail-cli compose deploy <app> -f compose.yaml [--profile-name P]   deploy or update a stack
  levelrail-cli compose preview -f compose.yaml                            validate and show what would deploy
  levelrail-cli compose status <app>                                       per-service status and the stack phase
  levelrail-cli compose revisions <app>                                    deploy history, newest first
  levelrail-cli compose logs <app> [--service S] [--since 1h] [-f]         logs for one or every service
  levelrail-cli compose redeploy <app> [--service S]                       recreate every service, or one
  levelrail-cli compose rollback <app> [--revision N]                      re-apply an earlier compose file
  levelrail-cli compose down <app> [--volumes]                             remove the stack (volumes kept by default)
  levelrail-cli compose schedules <list|add|run|runs|pause|resume|rm> ...  cron commands inside one service

Run "levelrail-cli compose <subcommand> -h" for a subcommand's own flags.
```

## levelrail-cli compose schedules

Subcommands: add, list, pause, resume, rm, run, runs

```
Usage:
  levelrail-cli compose schedules list <app>                                      every schedule of every service
  levelrail-cli compose schedules add <app> <service> --schedule CRON [--name N] -- CMD...
  levelrail-cli compose schedules run <app> <service> <id|name>                    run now, inside that service
  levelrail-cli compose schedules runs <app> <service> <id|name> [--limit N]       run history with exit codes
  levelrail-cli compose schedules pause|resume <app> <service> <id|name>
  levelrail-cli compose schedules rm <app> <service> <id|name>
```
