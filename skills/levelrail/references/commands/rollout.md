## levelrail-cli rollout

Subcommands: history, restart, state, status, undo, waves

```
Usage:
  levelrail-cli rollout status <app> [flags]     show rolling waves and replica counts, then wait for the
                                       latest deploy to converge (same as apps wait)
  levelrail-cli rollout waves <app> [--json]     show the rollout policy and the last rolling deploy's
                                       wave, updated, ready, unavailable and surge counts
  levelrail-cli rollout state <app> [--json]     show the health gate, traffic flip and hold countdown of the
                                       newest release (thresholds are the app's deploy-safety settings)
  levelrail-cli rollout history <app> [flags]    list deploy attempts, newest first (same as apps deploys list)
  levelrail-cli rollout undo <app> [flags]       roll back to the previous deploy (same as apps rollback)
  levelrail-cli rollout restart <app> [flags]    restart the app (same as apps restart)

Each verb forwards its flags to the apps command named above, so run
"levelrail-cli apps wait --help" and the like for the full flag list.

rollout pause and rollout resume do not exist: no API holds a rollout open.
For scheduled deploy windows see "levelrail-cli apps freeze".
```
