## levelrail-cli dashboards

Subcommands: create, delete, export, import, list, show

```
Usage:
  levelrail-cli dashboards list [--project ID] [flags]     list the dashboards you can see (yours plus shared)
  levelrail-cli dashboards show <id|name> [flags]          print one dashboard with its widgets
  levelrail-cli dashboards create --name NAME [--template KEY --target NAME] [--scope user|shared] [--project ID] [--default] [flags]
  levelrail-cli dashboards export <id|name> [flags]        print the portable JSON document, ready to commit to git
  levelrail-cli dashboards import <file|-> [--scope user|shared] [--project ID] [flags]   create a dashboard from an exported document
  levelrail-cli dashboards delete <id|name> [flags]        delete a dashboard

Templates: app-health, fleet-overview, cost. App templates need --target APP.

Flags:
  --token string     API token (default: levelrail-cli env var, then the credentials file)
  --api-url string   control plane base URL (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then LEVELRAIL_API_URL or APP_API_URL)
  --profile string   named credentials profile to read
  --json             print the result as JSON to stdout, nothing else
  --output string    output format: json, table, or text
  --query string     JMESPath expression to filter the result before printing
  -h, --help         show this help
```
