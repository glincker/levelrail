## levelrail-cli users

Subcommands: create, delete, grants, list, require-password-change, role, roles, set-abilities

```
Usage:
  levelrail-cli users list [flags]                                          list every user
  levelrail-cli users create --email EMAIL --password PASSWORD (--role ROLE | --abilities LIST) [flags]   create a user
  levelrail-cli users set-abilities <id> (--role ROLE | --abilities LIST) [flags]                          replace a user's abilities, directly or via a curated role
  levelrail-cli users delete <id> [flags]                                    remove a user
  levelrail-cli users roles [flags]                                          list the curated role presets --role accepts
  levelrail-cli users role set <user> <role> [flags]                         assign a stored role (id or name)
  levelrail-cli users grants get|set <user> [--environment ID ...] [flags]   read or replace a guest's environment grants
  levelrail-cli users require-password-change <id> [--off] [flags]           make a user choose a new password before signing in again

Run "levelrail-cli users <subcommand> -h" for a subcommand's own flags.
```
