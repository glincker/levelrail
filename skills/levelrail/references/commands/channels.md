## levelrail-cli channels

Subcommands: create, delete, deliveries, list, quiet-hours, test, update

```
Usage:
  levelrail-cli channels list [flags]                                           list connected notification channels
  levelrail-cli channels create --name NAME --kind KIND [flags]              connect a new notification channel
  levelrail-cli channels update <id> --name NAME --kind KIND [flags]         fully replace a channel's configuration
  levelrail-cli channels delete <id> [flags]                                    disconnect a channel
  levelrail-cli channels test <id> [flags]                                       send a real test message to a connected channel
  levelrail-cli channels deliveries <id> [flags]                                lists a channel's recorded send history, newest first
  levelrail-cli channels quiet-hours <id> [--start HH:MM --end HH:MM | --clear]  hold non-critical alerts during a daily window

Valid --kind values: generic, slack, discord, telegram, email, pushover, pagerduty, teams, resend, ntfy, gotify, mattermost, lark, rocketchat, opsgenie, webex, googlechat.

Run "levelrail-cli channels <subcommand> -h" for a subcommand's own flags.
```
