# levelrail-cli dns

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli dns

Subcommands: check, health-checks, records, zones

```
Usage:
  levelrail-cli dns zones list [--provider P]                       zones the connected provider can see
  levelrail-cli dns zones create <domain> [--account-id ID]           create a zone and print its name servers
  levelrail-cli dns zones delete <zone> --confirm <zone> [--force]    delete a zone (force when it still has records)
  levelrail-cli dns zones nameservers <zone>                         the name servers to set at your registrar
  levelrail-cli dns zones verify <zone>                              check delegation through public resolvers
  levelrail-cli dns records list|add|update|delete|import|export|template <zone> [flags]
  levelrail-cli dns check <name> [--type T] [--zone Z]                answers from resolvers and the zone's own servers
  levelrail-cli dns health-checks list|create|delete [flags]          Route53 health checks for failover records

Zones and records live at Cloudflare or Route53, using the DNS provider
credentials connected under "levelrail-cli domains cloudflare-dns" or
"levelrail-cli domains route53-dns". <zone> is a zone id or name. --provider picks
one when both are connected.
```
