## levelrail-cli db branch

Subcommands: create

```
Usage:
  levelrail-cli databases branch create <source> <new-name> (--from-backup ID | --at TIME) [flags]

Creates a new, independent database from a backup of <source>, or from a
point in time when point-in-time recovery is enabled on it (MySQL and
MariaDB). <source> is never changed. The branch gets its own generated
credentials, no linked apps and no pooler.

Flags:
  --from-backup string  id of a succeeded backup of <source>
  --at string           RFC3339 time to branch from
  --project string      project id for the branch (default: the source's project)
```

## levelrail-cli db params

Subcommands: apply, discard, rollback, set, show, unset

```
Usage:
  levelrail-cli databases params show <database>                   default, current and staged value of each parameter
  levelrail-cli databases params set <database> NAME=VALUE...      stage a change (no restart)
  levelrail-cli databases params unset <database> NAME...          stage a return to the engine default
  levelrail-cli databases params rollback <database>               stage the set that ran before the last apply
  levelrail-cli databases params discard <database>                drop the staged change
  levelrail-cli databases params apply <database> --yes            apply the staged change, restarts the database

Only allowlisted parameters with typed values are accepted. A staged change
also goes live on the next "databases start".
```

## levelrail-cli db pooler

Subcommands: disable, enable, show

```
Usage:
  levelrail-cli databases pooler show <database> [flags]      pooler state, pooled and direct URLs
  levelrail-cli databases pooler enable <database> [--pool-size N] [--max-client-conn N]   run a transaction pooler beside a Postgres database
  levelrail-cli databases pooler disable <database> [flags]   remove the pooler, apps go back to the direct URL

Flags for enable:
  --pool-size N        server connections per database (0 keeps the default)
  --max-client-conn N  client connections the pooler accepts (0 keeps the default)

Linked apps get the pooled URL from the "url" field; "direct_url" always
bypasses the pooler, use it for migrations.
```
