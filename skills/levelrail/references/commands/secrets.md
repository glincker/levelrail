## levelrail-cli secrets

Subcommands: binding-status, generate-master-key, key-policy, key-status, rebind, rotate-dek, rotate-master-key, scan

```
Usage:
  levelrail-cli secrets generate-master-key --out PATH [--json]
  levelrail-cli secrets rotate-master-key --new-key-file PATH [flags]
  levelrail-cli secrets binding-status [flags]
  levelrail-cli secrets rebind [flags]
  levelrail-cli secrets scan [<app> | --path DIR] [flags]
  levelrail-cli secrets connection list|create|update|delete|test [flags]
  levelrail-cli secrets key-status | rotate-dek <app>|--all | key-policy [flags]

scan looks for credentials in a directory or an app's plain env values and
sets the deploy-time secret scan policy.

generate-master-key writes a new master key to a file, locally, never
contacting the control plane. rotate-master-key re-wraps every stored data encryption key under a new
master key in one atomic step, live, then binds any legacy values.
binding-status counts secret values not yet bound to their slot, and
rebind binds them. Read docs/master-key-rotation.md before running these
in production.

key-status, rotate-dek and key-policy manage per-app data key rotation and
the maximum key age reminder.

Run "levelrail-cli secrets <command> -h" for its own flags.
```
