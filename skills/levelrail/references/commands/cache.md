## levelrail-cli cache

Subcommands: history, purge, rules, status

```
Usage:
  levelrail-cli cache status [<app>]
  levelrail-cli cache rules show <app> [--domain D]
  levelrail-cli cache rules set <app> (--preset static | --file cache.json) [--domain D]
  levelrail-cli cache rules clear <app> [--domain D]
  levelrail-cli cache purge <app> (--url /a?b=1 | --prefix /static | --tag NAME | --all) [--domain D]
  levelrail-cli cache history <app>

The response cache lives in the ingress. Only GET and HEAD are cached, and
responses with Set-Cookie, private, no-store or no-cache never are.
With no --domain a command covers every domain of the app.
```
