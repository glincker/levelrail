# levelrail-cli models

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli models

Subcommands: benchmark, cache, catalog, delete, deploy, endpoint, fit, get, gpus, keys, list, logs, metrics, preflight, residency, restart, rotate-key, sleep, swap-group, usage, wake

```
Usage:
  levelrail-cli models list [flags]                 list AI models
  levelrail-cli models get <name> [flags]           show one model, its status and endpoint
  levelrail-cli models deploy [flags]               deploy a model on a GPU node (prints its API key once)
  levelrail-cli models logs <name> [flags]          search or follow a model engine's logs
  levelrail-cli models delete <name> [flags]        remove a model (its downloaded weights volume is kept)
  levelrail-cli models restart <name> [flags]       recreate the engine container
  levelrail-cli models rotate-key <name> [flags]    issue a new API key (prints it once)
  levelrail-cli models keys list|create|revoke|rotate   named API keys with limits, expiry and rotation grace
  levelrail-cli models usage <name> [flags]         gateway requests, tokens, errors and latency per key
  levelrail-cli models residency <name> --mode M    always resident, or on_demand (stop when idle, start on first request)
  levelrail-cli models swap-group <name> --group G  share a GPU with other models in group G (--clear to remove)
  levelrail-cli models endpoint add|test|routing|credential   use a server you run yourself (Ollama on a Mac) as a model
  levelrail-cli models wake|sleep <name> [flags]    start or stop an on-demand model's engine now
  levelrail-cli models fit --engine E --model M     estimate VRAM fit (fits, tight, no) on each GPU node (--compute cpu for CPU mode)
  levelrail-cli models metrics <name> [flags]       engine metrics: KV cache, queue, prefix hits, tokens per second, first token
  levelrail-cli models gpus [flags]                 list GPU nodes with VRAM and usage
  levelrail-cli models catalog [flags]              curated small models for CPU mode: licence, memory, estimated speed
  levelrail-cli models benchmark <name> [flags]     measure tokens per second, first token and peak memory of a running model
  levelrail-cli models preflight <repo> [flags]     check a Hugging Face repo: access, size, quants, fit, disk
  levelrail-cli models cache list|prune [flags]     list cached model weights, prune unused ones (--dry-run first)

Run "levelrail-cli models <subcommand> -h" for a subcommand's own flags.
```

## levelrail-cli models cache

Subcommands: list, prune

```
Usage:
  levelrail-cli models cache list [flags]                  list cached model weights per node
  levelrail-cli models cache prune [--dry-run] [volume...]  remove unused, unreferenced weights
```

## levelrail-cli models endpoint

Subcommands: add, credential, routing, test

```
Usage:
  levelrail-cli models endpoint add --name N --url URL [flags]   register a model server Levelrail does not run
  levelrail-cli models endpoint test <name> | --url URL          probe an endpoint and list its models
  levelrail-cli models endpoint routing <name> [flags]           fall back to another model when the endpoint is down or slow
  levelrail-cli models endpoint credential <name> [flags]        set or remove the endpoint's API key

Delete a registered endpoint with "levelrail-cli models delete <name>". Keys, usage and limits use the
regular "models keys" and "models usage" commands.
```

## levelrail-cli models keys

Subcommands: create, list, revoke, rotate

```
Usage:
  levelrail-cli models keys list <model> [flags]             list a model's API keys
  levelrail-cli models keys create <model> --name N [flags]  create a named key (printed once)
  levelrail-cli models keys revoke <model> <key-id> [flags]  stop a key working at once
  levelrail-cli models keys rotate <model> <key-id> [flags]  issue a replacement, old key works for a grace window
```
