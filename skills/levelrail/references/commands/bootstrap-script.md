## levelrail-cli bootstrap-script

Subcommands: create, delete, list, show

```
Usage:
  levelrail-cli bootstrap-script list [flags]                                  list saved node bootstrap scripts
  levelrail-cli bootstrap-script show <id> [flags]                             print one script, body included
  levelrail-cli bootstrap-script create --name NAME --file PATH [flags]        save a script (use --file - for stdin)
  levelrail-cli bootstrap-script delete <id> [flags]                           remove a saved script

A saved script runs once on a new cloud node's first boot, after the built-in
bootstrap, when a node is provisioned with its bootstrap_script_id. The control
plane stores it as text and never runs it. Do not put secrets in a script.
```
