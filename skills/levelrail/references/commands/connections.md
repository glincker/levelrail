## levelrail-cli connections

Subcommands: bind, bindings, catalog, list, show, unbind

```
Usage:
  levelrail-cli connections list [--kind KIND] [--scope SCOPE] [--health HEALTH] [flags]   list every connected integration
  levelrail-cli connections show <ref> [flags]                                              show one connection
  levelrail-cli connections catalog [flags]                                                 list the providers that can be connected
  levelrail-cli connections bind <ref> --app NAME|--org ID --role ROLE [--rules JSON]       use a connection for a role on an app or org
  levelrail-cli connections unbind <id> --app NAME|--org ID                                 remove a binding
  levelrail-cli connections bindings --app NAME|--org ID [flags]                            list bindings, with org defaults an app inherits

Run "levelrail-cli connections <subcommand> -h" for a subcommand's own flags.
```
