## levelrail-cli setup

Subcommands: next, reset, skip, status, undo

```
Usage:
  levelrail-cli setup status [flags]       the Get started checklist and how ready this server is for production
  levelrail-cli setup next [flags]         the one step to do next
  levelrail-cli setup skip <step> [flags]  mark a step as skipped (undo with "setup undo")
  levelrail-cli setup undo <step> [flags]  clear a skip or manual override
  levelrail-cli setup reset [flags]        clear every override and show the guide again
  levelrail-cli setup admin [--username U] [--api-url URL] [--profile NAME]  create the first admin on a fresh server (token from "setup-token" on the host)

Flags:
  --token string      API token (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then the credentials file)
  --api-url string    control plane base URL (default: LEVELRAIL_API_URL or APP_API_URL env var, then http://localhost:8080)
  --profile string    named credentials profile to read (overrides APP_PROFILE, default "default")
  --json              print the checklist as JSON to stdout, nothing else
  --output string     output format: json, table, or text (default table; --json is shorthand for --output json)
  --query string      JMESPath expression to filter the result before printing
  -h, --help          show this help
```
