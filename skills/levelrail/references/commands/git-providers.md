## levelrail-cli git-providers

Subcommands: add, branches, connections, default, disconnect, list, rename, repos, test, use-as-source, validate

```
Usage:
  levelrail-cli git-providers [list] [flags]
  levelrail-cli git-providers validate <github|gitlab|gitea|bitbucket> [flags]
  levelrail-cli git-providers repos <github|gitlab|gitea|bitbucket> [--connection ID] [--search Q] [--refresh] [flags]
  levelrail-cli git-providers connections|add|rename|default|disconnect|branches|use-as-source ...

Shows connection status and capabilities (list branches, register a
webhook, authenticated clone) for github, gitlab, bitbucket, and gitea,
then every connected account. Run "levelrail-cli git-providers connections -h"
for managing several accounts per provider.

Flags:
  --token string          API token (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then the credentials file)
  --api-url string       control plane base URL (default: LEVELRAIL_API_URL or APP_API_URL env var, then http://localhost:8080)
  --profile string       named credentials profile to read (overrides APP_PROFILE, default "default")
  --json                    print providers as a JSON array to stdout, nothing else
  --output string          output format: json, table, or text (default table; --json is shorthand for --output json)
  --query string           JMESPath expression to filter the result before printing
  -h, --help               show this help
```
