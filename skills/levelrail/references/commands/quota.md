## levelrail-cli quota

Subcommands: clear, set, show

```
Usage:
  levelrail-cli quota show <team|project> <id>            limits and current usage
  levelrail-cli quota set <team|project> <id> [flags]     replace the limits (admins); 0 means unlimited
  levelrail-cli quota clear <team|project> <id>           remove every limit (admins)

Flags for set: --max-apps N --max-databases N --max-memory-mb N --max-cpu F --max-previews N
```
