# levelrail-cli cloud

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli cloud

Subcommands: connect, connection

```
Usage:
  levelrail-cli cloud connection list [flags]
  levelrail-cli cloud connection create NAME --provider oracle|aws|azure|gcp|hetzner|digitalocean --auth oidc_federation|role_assumption|secret_ref|static [config flags] [--credential-ref REF]
  levelrail-cli cloud connection update NAME [--auth METHOD] [config flags] [--credential-ref REF] [--team ID]
  levelrail-cli cloud connection delete NAME [flags]
  levelrail-cli cloud connection test NAME [flags]
  levelrail-cli cloud connect oci [flags]   guided setup of a scoped OCI credential (dry run by default)

Preview. Cloud connections are off until the runtime setting cloud.connections_enabled
is on. A connection stores non-secret settings and a credential reference only
(secret://CONNECTION/path#key for secret_ref and role_assumption, NAMESPACE/KEY for
static); the credential itself stays in your vault or secret store. "test" runs one
read-only check and prints a class and a short reason. Config flags: --region,
--account-id, --compartment, --role-arn, --subscription-id, --resource-group,
--oidc-audience.
```

## levelrail-cli cloud connect

Subcommands: oci

```
Usage:
  levelrail-cli cloud connect oci [--profile P] [--region R] [--tenancy OCID] [--compartment-name N]
      [--parent-compartment OCID] [--name NAME] [--dry-run=false --yes]
  levelrail-cli cloud connect oci --paste --name NAME --tenancy OCID --compartment-ocid OCID --region R
      --user-ocid OCID --fingerprint FP [--key-env VAR]

Preview. Uses your local oci CLI session once to create a dedicated compartment, group,
API-only user, a policy scoped to that compartment and a key pair made on this machine.
Only that scoped credential reaches Levelrail. The default is a dry run that prints every
command; --yes runs them. Root or tenancy admin credentials are never accepted.
--paste stores a scoped credential you already made; the key comes from --key-env or stdin.
```
