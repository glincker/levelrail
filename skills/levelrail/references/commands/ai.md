## levelrail-cli ai

Subcommands: chat, sessions

```
Usage:
  levelrail-cli ai chat "<message>" [--session ID] [flags]
  levelrail-cli ai sessions list|get|delete|resolve [flags]

Talks to the in-app AI assistant (read-and-suggest only: it never
deploys, rolls back, or restarts anything without an explicit approval,
see "levelrail-cli ai sessions resolve -h"). Requires the ai-chat experimental
flag (see "levelrail-cli settings ai-assistant -h") and a configured provider/
model/key ("levelrail-cli settings ai-assistant providers set").

Run "levelrail-cli ai <subcommand> -h" for a subcommand's own flags.
```

## levelrail-cli ai sessions

Subcommands: delete, get, list, resolve

```
Usage:
  levelrail-cli ai sessions list [flags]
  levelrail-cli ai sessions get <id> [flags]
  levelrail-cli ai sessions delete <id> [flags]
  levelrail-cli ai sessions resolve <id> <confirmation-id> --approve|--reject [flags]

Manages AI assistant chat sessions. "levelrail-cli ai chat" starts and sends to
one; these subcommands list, inspect, remove, and resolve a pending
confirmation on one.

Run "levelrail-cli ai sessions <subcommand> -h" for a subcommand's own flags.
```
