# levelrail-cli resources

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli resources

Subcommands: list, tag, untag, views

```
Usage:
  levelrail-cli resources list [--q TEXT] [--kind app|database|node|domain|bucket|network] [--tag T]...
  levelrail-cli resources tag --tag T [--dry-run] KIND:NAME...      tag many resources, preview first with --dry-run
  levelrail-cli resources untag --tag T [--dry-run] KIND:NAME...
  levelrail-cli resources views [list]                              saved explorer views
  levelrail-cli resources views save NAME [--q TEXT] [--kind K] [--tag T]...
  levelrail-cli resources views delete ID

Tags are key or key:value (for example team:shop). "usage report --by tag"
groups cost by tag.
```

## levelrail-cli resources views

Subcommands: delete, list, save

```
Usage of levelrail-cli resources views:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -json
    	print the result as JSON to stdout and nothing else
  -kind string
    	kind filter to store (save)
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -q string
    	search text to store (save)
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -tag value
    	tag filter to store, repeatable (save)
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
```
