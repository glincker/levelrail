## levelrail-cli export

Subcommands: audit, destinations

```
Usage:
  levelrail-cli export [--project P] [--app A] [-o DIR|-] [--include-env-values=false] [flags]

Writes the live state as resource documents. Output is stable, so exporting
twice gives identical files. Secret values are never written: secret env vars
become secretRef, and secret looking values become ${{ env.NAME }} placeholders.
Supply those at apply time with --var, --var-file or --allow-env.

Flags:
  --project P                  only this project and what it holds
  --app A                      only this app and its load balancer, pipelines and alert rules
  -o DIR|-                     directory to write one file per document, or - for stdout (default -)
  --include-env-values=false   write every plain env value as a ${{ env.NAME }} placeholder
                               (always the case without the read:sensitive ability)

Common flags:
  --token string     API token (default: the credentials file or the API token env var)
  --api-url string   control plane base URL
  --profile string   named credentials profile
  --json             print the result as JSON and nothing else
  --output string    json, table, or text
  --query string     JMESPath expression applied to the result
```

## levelrail-cli export destinations

Subcommands: create, delete, disable, enable, list, status, test

```
Usage:
  levelrail-cli export destinations list [flags]                 list data export destinations and their delivery state
  levelrail-cli export destinations create --name N --kind K [flags]   add a destination
  levelrail-cli export destinations test <id> [flags]            send one probe and report the result
  levelrail-cli export destinations status <id> [flags]          show delivery state: last success, error, queue depth
  levelrail-cli export destinations enable|disable <id> [flags]  pause or resume delivery
  levelrail-cli export destinations delete <id> [flags]          remove a destination and its stored secrets
  levelrail-cli export audit [--from T] [--to T] [--format ndjson|csv] [flags]   download the audit log

Kinds: logs_http, logs_loki, logs_otlp, logs_syslog, logs_newrelic, logs_datadog, logs_axiom,
logs_betterstack, audit_webhook, audit_s3, audit_splunk, audit_syslog, audit_otlp, metrics_otlp,
metrics_remote_write.
Run "levelrail-cli export destinations create -h" for the create flags.
```
