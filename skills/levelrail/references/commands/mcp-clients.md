## levelrail-cli mcp-clients

Subcommands: create, delete, list

```
Usage (experimental, root only, needs the mcp-http feature on the control plane):
  levelrail-cli mcp-clients create --name N --redirect-uri URI [--redirect-uri URI]... [--redirect-uris URI,URI] [--scope mcp:read|mcp:read:sensitive]... [--json]
  levelrail-cli mcp-clients list [--json]
  levelrail-cli mcp-clients delete --id ID [--json]

create registers a public client and prints its generated client_id; there is no client secret.
Redirect URIs must be absolute https (or http on 127.0.0.1 or [::1]) with no fragment. --scope
defaults to mcp:read. delete removes the client and revokes every token it was granted.
```
