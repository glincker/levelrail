# levelrail-cli control-plane

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli control-plane

Subcommands: rehydrate

```
Usage:
  levelrail-cli control-plane rehydrate plan [flags]     dry run: which databases and volumes would be restored, and from which backup
  levelrail-cli control-plane rehydrate run --yes        restore them, with a per-resource result and a DR report
  levelrail-cli control-plane rehydrate status [flags]   the live or last DR report

Run these after the control plane itself is restored. A run overwrites live
databases and volumes, so it needs --yes. Backups older than
APP_REHYDRATE_MAX_BACKUP_AGE block their resource unless --allow-stale is set.
All subcommands need a root-scoped token.
```
