## levelrail-cli app-volume-backups

Subcommands: clone-restores, delete, download, list, restore, restore-as-new, restores, schedule, trigger, verifications, verify

```
Usage:
  levelrail-cli app-volume-backups list <app> <volume> [flags]                                  list backup history for an app's named volume
  levelrail-cli app-volume-backups trigger <app> <volume> --target ID [flags]                 trigger a manual backup
  levelrail-cli app-volume-backups delete <app> <volume> <backup-id> [flags]                  delete one archived backup on demand (destructive)
  levelrail-cli app-volume-backups download <app> <volume> <backup-id> [flags]                stream a succeeded backup's own object to stdout
  levelrail-cli app-volume-backups restore <app> <volume> --backup ID --confirm APP/VOLUME [flags]   restore a volume from a backup (destructive)
  levelrail-cli app-volume-backups restore-as-new <app> <volume> --backup ID [flags]           restore a backup into a brand-new, standalone volume (non-destructive)
  levelrail-cli app-volume-backups schedule set <app> <volume> --target ID --cron EXPR [flags]   configure a recurring backup
  levelrail-cli app-volume-backups schedule clear <app> <volume> [flags]                       remove a recurring backup
  levelrail-cli app-volume-backups restores <app> <volume> [flags]                         list restore attempt history for a volume
  levelrail-cli app-volume-backups clone-restores <app> <volume> [flags]                   list restore-as-new attempt history for a volume
  levelrail-cli app-volume-backups verify<app> <volume> --backup ID [flags]                   verify a backup is intact (no live restore)
  levelrail-cli app-volume-backups verifications <app> <volume> --backup ID [flags]            list past verification attempts for a backup

<volume> is a logical volume name declared in <app>'s app.yaml (see
"levelrail-cli apps get <app>" to list an app's volumes).

Run "levelrail-cli app-volume-backups <subcommand> -h" for a subcommand's own flags.
```
