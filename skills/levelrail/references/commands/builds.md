Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli builds

Subcommands: cache, cancel, drain, kill-all, list, pause, prune, queue, resume, retry, show

```
Usage:
  levelrail-cli builds list [--app A] [--status S] [--limit N]
  levelrail-cli builds show <id>
  levelrail-cli builds cancel <id>
  levelrail-cli builds retry <id>
  levelrail-cli builds cache [--node N]
  levelrail-cli builds cache quota [--app-quota-gb N] [--reclaim APP]
  levelrail-cli builds prune [--node N] [--older-than-hours H] [--apply]
  levelrail-cli builds queue [--json]
  levelrail-cli builds pause [--reason TEXT]
  levelrail-cli builds drain [--reason TEXT]
  levelrail-cli builds resume
  levelrail-cli builds kill-all --yes [--reason TEXT] [--pause]

The build center: queued, running and finished builds across every app with
duration, cache hit ratio, image size change and the node that ran each one.
retry rebuilds the connected branch of a failed or canceled build. prune
previews by default and only removes idle BuildKit cache with --apply; cache
an in-flight build holds is never removed. cache quota shows the per app quota
(0 is off) and the recent reclaims; --app-quota-gb changes the live setting
(root or admin), --reclaim trims one app now. pause and drain hold new builds
in the queue (running builds finish), resume starts them again, and kill-all
cancels every queued and running build after a password step-up.
```
