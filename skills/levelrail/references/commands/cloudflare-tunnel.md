## levelrail-cli cloudflare-tunnel

Subcommands: disconnect, get, set

```
Usage:
  levelrail-cli cloudflare-tunnel get [flags]                          show the current settings and connection status
  levelrail-cli cloudflare-tunnel set --cf-tunnel-token TOKEN [flags]  configure and enable
  levelrail-cli cloudflare-tunnel disconnect [flags]                   disable and forget the token

Runs the cloudflared container connected to a tunnel token generated in
your own Cloudflare Zero Trust dashboard, exposing this control plane
without opening an inbound port. Hostname routing stays configured on
Cloudflare's side. This is a distinct credential from
"levelrail-cli domains cloudflare-dns", which configures the DNS-01 ACME
challenge instead.

Run "levelrail-cli cloudflare-tunnel <subcommand> -h" for a subcommand's own flags.
```
