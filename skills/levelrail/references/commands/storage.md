# levelrail-cli storage

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli storage

Subcommands: add, buckets, delete, destinations, list, providers, test

```
Usage:
  levelrail-cli storage providers                       list provider presets (aws, r2, b2, minio, wasabi, gcs, custom)
  levelrail-cli storage list                            list connected storage destinations
  levelrail-cli storage add --name N --provider P --bucket B --access-key-id ID --secret-access-key KEY [flags]
  levelrail-cli storage test <id>                       write, read back and delete a probe object
  levelrail-cli storage delete <id>                     disconnect a destination
  levelrail-cli storage destinations ls|add|test|default   destination commands (add --node N for a node directory)
  levelrail-cli storage buckets <subcommand>            named buckets bound to apps (run "storage buckets help")

Add flags:
  --provider string        aws, r2, b2, minio, wasabi, gcs, or custom (default custom)
  --account-id string      Cloudflare account id (r2)
  --region string          bucket region (aws, b2, wasabi)
  --endpoint string        endpoint URL (minio, custom; overrides the preset)
  --virtual-hosted         use virtual-hosted addressing instead of path style
  --skip-verify            save without running the connection test first
  --node string            store on this enrolled node's confined directory instead of S3 (no credentials)
  --directory string       directory under the node's storage root (default backups)
  --quota-gb float         soft quota in GB, flagged when exceeded (0 = none)

Default:
  levelrail-cli storage destinations default                   show the default per data class
  levelrail-cli storage destinations default set <class> <id>  classes: backups, archives, artifacts, cache, dumps
  levelrail-cli storage destinations default clear <class>

Common flags:
  --token string     API token (default: the credentials file or the API token env var)
  --api-url string   control plane base URL
  --profile string   named credentials profile
  --json             print the result as JSON and nothing else
  --output string    json, table, or text
  --query string     JMESPath expression applied to the result
```

## levelrail-cli storage buckets

Subcommands: bind, create, delete, get, list, ls, presign, put, rm, sweep, unbind, update, usage

```
Usage:
  levelrail-cli storage buckets list [--app NAME]                  list buckets
  levelrail-cli storage buckets create --name N --destination ID [--app NAME] [--env-prefix P] [--public] [--quota-mb N] [--expire-days N]
  levelrail-cli storage buckets update <id> [--public=true|false] [--quota-mb N] [--expire-days N]
  levelrail-cli storage buckets delete <id> [--purge]              remove a bucket, --purge also deletes its files
  levelrail-cli storage buckets bind <id> --app NAME [--env-prefix P]   inject its S3 env vars into an app at next container start
  levelrail-cli storage buckets unbind <id> --app NAME
  levelrail-cli storage buckets usage <id>                         stored size against the quota
  levelrail-cli storage buckets ls <id> [--prefix P]               list files
  levelrail-cli storage buckets put <id> <key> <file>              upload a file
  levelrail-cli storage buckets get <id> <key> [--out FILE]        download a file
  levelrail-cli storage buckets rm <id> <key>                      delete a file
  levelrail-cli storage buckets presign <id> <key> [--method GET|PUT] [--expires 15m]
  levelrail-cli storage buckets sweep <id>                         run the expire-after-N-days rule now

Common flags:
  --token string     API token (default: the credentials file or the API token env var)
  --api-url string   control plane base URL
  --profile string   named credentials profile
  --json             print the result as JSON and nothing else
  --output string    json, table, or text
  --query string     JMESPath expression applied to the result
```
