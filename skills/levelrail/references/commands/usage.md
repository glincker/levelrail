# levelrail-cli usage

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli usage

Subcommands: budgets, report, settings

```
Usage:
  levelrail-cli usage report [--period mtd|30d|last_month|custom] [--from D --to D] [--by project|environment|team|resource|tag] [--csv]
  levelrail-cli usage settings                                   show prices and node bills
  levelrail-cli usage settings set [flags]                       change prices (instance admin)
  levelrail-cli usage budgets                                    list budgets and where they stand
  levelrail-cli usage budgets set project|team ID --monthly N [--warn-pct 80]
  levelrail-cli usage budgets delete BUDGET-ID

Cost is allocated from your own prices by measured usage. It is a showback
figure for sharing a bill fairly, not an invoice.
```

## levelrail-cli usage budgets

Subcommands: delete, set

```
Usage of levelrail-cli usage budgets:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -json
    	print the result as JSON to stdout and nothing else
  -monthly float
    	monthly budget amount (set)
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -warn-pct float
    	percent of the budget that raises the first alert, default 80 (set)
```

## levelrail-cli usage settings

Subcommands: set

```
Usage of levelrail-cli usage settings:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -basis string
    	avg or p50
  -cpu-core-hour float
    	price per vCPU hour (unit mode) (default -1)
  -cpu-weight-pct float
    	percent of a node bill attributed to CPU, the rest to memory (default -1)
  -currency string
    	currency label, such as USD
  -egress-gib float
    	price per GiB sent out (default -1)
  -idle-spread-pct float
    	percent of idle capacity spread over apps by usage (0 to 100) (default -1)
  -json
    	print the settings as JSON to stdout and nothing else
  -mem-gib-hour float
    	price per GiB of memory hour (unit mode) (default -1)
  -mode string
    	unit (price per core and GiB hour) or node (split each node's monthly bill)
  -node value
    	node bill as NODE=MONTHLY[:VCPUS[:GIB]], repeatable; replaces all node bills
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -reprice-month
    	also reprice the month to date with the new prices
  -storage-gib-month float
    	price per GiB of volume storage per month (default -1)
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
```
