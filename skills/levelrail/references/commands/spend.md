## levelrail-cli spend

Subcommands: caps

```
Usage:
  levelrail-cli spend caps list
  levelrail-cli spend caps status app|project NAME
  levelrail-cli spend caps set app|project NAME [--cost N] [--egress 500GiB] [--warn 80,100] [--mode alert|block_deploys] [--action none|throttle|pause]
  levelrail-cli spend caps rm app|project NAME
  levelrail-cli spend caps dry-run app|project NAME
  levelrail-cli spend caps override app NAME --reason TEXT

A cap alerts at each warn level once a month. In block_deploys mode, new
deploys are refused at 100% until the month rolls over, the cap is raised,
or a root token overrides the guard (audited, with a reason). dry-run only
previews what a pause would stop and save; it changes nothing. --egress is
for app caps only. Setting block_deploys needs a root token.
```
