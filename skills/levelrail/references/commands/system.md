## levelrail-cli system

Subcommands: address, db-space, disk, health, integrity, networks, processes, restart, slow-statements

```
Usage:
  levelrail-cli system address [--domain NAME] [flags]   show this server's public IPv4 and IPv6
  levelrail-cli system address --ipv4 IP [--ipv6 IP]     override the detected addresses
  levelrail-cli system address --clear                   go back to detection
  levelrail-cli system restart [--wait] [--yes]          restart the control plane process
  levelrail-cli system restart status                    show the restart state and boot id
  levelrail-cli system health [--fix ID]                 show control plane saturation, optionally apply a fix
  levelrail-cli system integrity [--check [--full]]      database integrity state and restorable snapshots
  levelrail-cli system integrity --restore NAME|latest   stage a verified snapshot for the next start
  levelrail-cli system db-space [compact [--force]]      database size report, explicit compaction
  levelrail-cli system slow-statements                   slowest control plane database statements
  levelrail-cli system processes                         largest processes on the control plane host
  levelrail-cli system networks [--orphans]             list app networks, owners and pool usage
  levelrail-cli system networks prune --dry-run|--yes    remove orphaned, empty app networks
  levelrail-cli system disk history [--days N]           disk use over time and a days-until-full forecast

With --domain, also prints the exact DNS records to create for that name.
```

## levelrail-cli system networks

Subcommands: prune

```
Usage:
  levelrail-cli system networks [--orphans]
  levelrail-cli system networks prune --dry-run|--yes

Flags:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -dry-run
    	prune: show what would be removed without removing it
  -json
    	print the result as JSON to stdout and nothing else
  -orphans
    	list only networks whose owner no longer exists
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -yes
    	prune: remove the orphaned, empty networks
```

## levelrail-cli system restart

Subcommands: status

```
Usage:
  levelrail-cli system restart [--wait] [--yes] [--timeout DURATION] [flags]
  levelrail-cli system restart status [flags]

Restarts the control plane process through its supervisor. Asks for
confirmation unless --yes. With --wait, polls until a new process answers
(its boot id differs), tolerating connection errors while it is down.
If no supervisor was detected, prints the reason and the command to run
on the server, and exits non-zero.

Flags:
  --wait                   wait until the control plane is back
  --yes                    skip the confirmation prompt
  --timeout duration       how long --wait polls before giving up (default 2m0s)
  --token string           API token (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then the credentials file)
  --api-url string         control plane base URL (default: LEVELRAIL_API_URL or APP_API_URL env var, then http://localhost:8080)
  --profile string         named credentials profile to read (overrides APP_PROFILE, default "default")
  --json                   print the restart state as JSON to stdout, nothing else
  --output string          output format: json, table, or text (default table; --json is shorthand for --output json)
  --query string           JMESPath expression to filter the result before printing
  -h, --help               show this help
```
