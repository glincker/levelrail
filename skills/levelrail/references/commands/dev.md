## levelrail-cli dev

Subcommands: status, stop

```
Usage:
  levelrail-cli dev [flags]       run a private instance on this machine, open its dashboard
  levelrail-cli dev status        show whether it is running and where
  levelrail-cli dev stop          shut it down

Runs the control plane bound to 127.0.0.1 with its own data directory, generates
an admin sign-in (printed once, kept in the data directory with mode 0600) and
serves deployed apps at <app>.localhost over plain http. Needs Docker running.
Ctrl-C stops it cleanly.

Flags:
  --port N          dashboard port (default 8080, or the next free port)
  --data-dir DIR    data directory (default: per-user, env APP_DEV_DATA_DIR)
  --no-open         do not open the dashboard in a browser
  --reset           delete the local instance's data first
  --bin PATH        control plane binary (default: next to this binary, then PATH, env APP_DEV_CONTROL_PLANE_BIN)
  --json            status: print JSON
```
