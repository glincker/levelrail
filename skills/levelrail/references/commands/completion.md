# levelrail-cli completion

Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli completion

Subcommands: bash, fish, install, zsh

```
Usage:
  levelrail-cli completion bash    print a bash completion script
  levelrail-cli completion zsh     print a zsh completion script
  levelrail-cli completion fish    print a fish completion script
  levelrail-cli completion install [--shell bash|zsh|fish]   write the script and print the line to add

Completes command and subcommand names for the CLI's full command tree
(apps, databases, channels, and so on), plus the global flags (--json --output --query --token --api-url --debug --insecure-http --no-color -h --help).
After deploy, logs, apps get and similar verbs it also offers real app names
from the server, and real profile, project and environment names after
--profile, --project and --env. Server answers are cached for a few seconds
and a Tab press never prompts or prints an error.

Install:
  bash   source <(levelrail-cli completion bash)
         or: levelrail-cli completion bash | sudo tee /etc/bash_completion.d/levelrail-cli > /dev/null

  zsh    source <(levelrail-cli completion zsh)
         or: levelrail-cli completion zsh > "${fpath[1]}/_levelrail-cli"

  fish   levelrail-cli completion fish | source
         or: levelrail-cli completion fish > ~/.config/fish/completions/levelrail-cli.fish
```
