## levelrail-cli private-networks

Subcommands: allow, apply, create, delete, deny, list, map, set

```
Usage:
  levelrail-cli private-networks list [flags]                                  list private networks and allow rules
  levelrail-cli private-networks map [flags]                                   who can talk to whom, with blocked paths and fixes
  levelrail-cli private-networks create <name> [--members a,b] [--default-deny] [--project ID] [flags]
  levelrail-cli private-networks set <name|id> --members a,b [--default-deny] [flags]   replace members and default-deny
  levelrail-cli private-networks delete <name|id> [flags]                      remove a private network
  levelrail-cli private-networks allow <app> <app> [--note TEXT] [flags]       allow two apps to reach each other
  levelrail-cli private-networks deny <rule-id> [flags]                        remove an allow rule
  levelrail-cli private-networks apply [flags]                                 re-enforce networks and rules on Docker now

Run "levelrail-cli private-networks <subcommand> -h" for a subcommand's own flags.
```
