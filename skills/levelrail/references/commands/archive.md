## levelrail-cli archive

Subcommands: create, delete, download, ls, policy, restore, verify

```
Usage:
  levelrail-cli archive ls [flags]                       list archive bundles and the live row counts
  levelrail-cli archive create [--kind K] [--older-than DAYS]   archive cold rows now (no kind runs the whole policy)
  levelrail-cli archive restore <id> [flags]             put a bundle's rows back into the live tables
  levelrail-cli archive verify <id> [flags]              check hash and restore into a scratch database (exit 1 if not ok)
  levelrail-cli archive download <id> [--out FILE]       save a bundle (zstd compressed NDJSON)
  levelrail-cli archive delete <id> [flags]              delete one bundle
  levelrail-cli archive policy [--enabled=BOOL] [--audit-days N] [--deploy-days N] [--pipeline-days N] [--keep-days N]

Kinds: audit, deploys, pipelines. Bundles hold no secret values.
All subcommands need a root-scoped token.
```
