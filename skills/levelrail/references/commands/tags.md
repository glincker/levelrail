## levelrail-cli tags

Subcommands: apps, create, databases, delete, list, rename

```
Usage:
  levelrail-cli tags list [flags]              list every tag
  levelrail-cli tags create --name NAME [flags]   create a tag
  levelrail-cli tags rename <old> <new> [flags]   rename a tag, keeping its attachments
  levelrail-cli tags delete <name> [flags]        delete a tag by name (detaches it from every app it was on)
  levelrail-cli tags apps <name> [flags]          list every app attached to a tag, by tag name
  levelrail-cli tags databases <name> [flags]     list every database you can read that carries a tag

Every tag identifier this CLI's flags/arguments take is the tag's name,
never its numeric/opaque ID; commands that need the ID internally
resolve it from the name for you.

Tag/untag an individual app with "levelrail-cli apps tag <name> <tag>" and
"levelrail-cli apps untag <name> <tag>".

Run "levelrail-cli tags <subcommand> -h" for a subcommand's own flags.
```
