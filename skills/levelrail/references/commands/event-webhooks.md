## levelrail-cli event-webhooks

Subcommands: create, delete, deliveries, disable, enable, list, replay, rotate-secret, test

```
Usage:
  levelrail-cli event-webhooks list [flags]                        list webhooks with delivery counts
  levelrail-cli event-webhooks create --name N --url U [flags]     add a webhook, prints the signing secret once
  levelrail-cli event-webhooks test <id> [flags]                   send a signed probe and report the result
  levelrail-cli event-webhooks deliveries <id> [flags]             show the delivery log (state, attempts, last status)
  levelrail-cli event-webhooks replay <delivery-id> [flags]        re-send a failed or dead-lettered delivery
  levelrail-cli event-webhooks enable|disable <id> [flags]         pause or resume delivery
  levelrail-cli event-webhooks rotate-secret <id> [flags]          issue a new signing secret, printed once
  levelrail-cli event-webhooks delete <id> [flags]                 remove a webhook and its delivery log
```
