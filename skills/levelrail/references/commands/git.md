## levelrail-cli git

Subcommands: remote

```
Usage:
  levelrail-cli git remote add <app> [flags]            enable git push deploy and print the exact remote line (token shown once); --apply sets it in the current repo
  levelrail-cli git remote show <app> [flags]           show the remote URL, deploy branch and last push
  levelrail-cli git remote rotate <app> [flags]         issue a new token, the old one stops working at once; --apply updates the repo's remote
  levelrail-cli git remote branch <app> <branch> [flags]   choose the branch that deploys (default main)
  levelrail-cli git remote revoke <app> [flags]         turn the remote off and invalidate its token

Run "levelrail-cli git remote <subcommand> -h" for a subcommand's own flags.
```
