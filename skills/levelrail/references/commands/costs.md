## levelrail-cli costs

Subcommands: budgets, explore

```
Usage:
  levelrail-cli costs explore [--by app|project|tag|node|kind] [--granularity daily|monthly] [--period mtd|30d|last_month] [--months N]
  levelrail-cli costs budgets list
  levelrail-cli costs budgets create --name N --scope project|tag|app --value V --monthly AMOUNT [--thresholds 50,80,100] [--action none|throttle|pause] [--throttle-rps N]
  levelrail-cli costs budgets set BUDGET-ID [any create flag]
  levelrail-cli costs budgets delete BUDGET-ID

Budgets alert at each threshold once a month through your budget_threshold
alert rule. The optional action applies at 100% to the apps in scope and is
lifted when the budget is raised or the month rolls over.
```

## levelrail-cli costs budgets

Subcommands: create, delete, list, set

```
Usage of levelrail-cli costs budgets list:
  -action string
    	at 100%: none, throttle or pause
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -json
    	print the result as JSON to stdout and nothing else
  -monthly float
    	monthly amount
  -name string
    	budget name
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -scope string
    	project, tag or app
  -thresholds string
    	alert levels in percent, such as 50,80,100
  -throttle-rps int
    	requests per second per client when the action is throttle
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -value string
    	project, tag name or app the budget covers
```
