## levelrail-cli proxy

Subcommands: apply, disable, setup, status, verify

```
Usage:
  levelrail-cli proxy [--domain D | --app NAME] [--proxy traefik|nginx|caddy] [--verify]
  levelrail-cli proxy setup [--confirm] [--provider traefik|nginx|caddy|haproxy|auto] [--dynamic-dir DIR] [--cert-dir DIR]
  levelrail-cli proxy install [--provider traefik] [--confirm]
  levelrail-cli proxy status
  levelrail-cli proxy apply
  levelrail-cli proxy verify [--domain D [--retry-cert]]
  levelrail-cli proxy disable

Without a subcommand: shows what holds ports 80 and 443 and the configuration to paste
into that proxy, for the dashboard (--domain) or an app's domain (--app).

setup detects the proxy that owns ports 80 and 443. For Traefik and nginx, --confirm lets
this server write one route file per domain into the proxy's directory (nginx is checked
with nginx -t and reloaded, and rolled back if it refuses). For caddy and haproxy it only
prints the configuration to add by hand. Without --confirm it only prints what would change.
--provider picks the proxy; auto (the default) uses the one detected.

install starts a pinned Traefik container for you when none runs on this server, through the
Docker API: it publishes ports 80 and 443, writes a minimal static configuration and a route
directory under the data directory, and refuses if either port is already in use. Without
--confirm it only prints the plan.

Flags:
  -api-url string
    	control plane API base URL (overrides LEVELRAIL_API_URL or APP_API_URL and the credentials file, default http://localhost:8080)
  -app string
    	build the snippet for this app's domain (upstream: the ingress HTTP port) instead of the dashboard
  -domain string
    	hostname to serve the dashboard on, for example console.example.com
  -json
    	print the guide as JSON to stdout and nothing else
  -output string
    	output format: json, table, or text (default table; --json is shorthand for --output json)
  -profile string
    	named credentials profile to read (overrides APP_PROFILE, default "default")
  -proxy string
    	traefik, nginx or caddy (default: the one detected on this server)
  -query string
    	JMESPath expression to filter the result before printing (e.g. "[?status=='running'].name")
  -token string
    	API token (overrides LEVELRAIL_TOKEN or APP_API_TOKEN and the credentials file)
  -verify
    	check that the domain already reaches this dashboard
```
