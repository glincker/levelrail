## levelrail-cli iam policies

Subcommands: attach, attachments, create, delete, detach, get, list, update

```
Usage:
  levelrail-cli iam policies create --name NAME --document DOC [flags]                            create a policy
  levelrail-cli iam policies list [flags]                                                                     list policies
  levelrail-cli iam policies get <id> [flags]                                                                show one policy
  levelrail-cli iam policies update <id> --name NAME --document DOC [flags]                    replace a policy's name/description/document
  levelrail-cli iam policies delete <id> [flags]                                                            delete a policy
  levelrail-cli iam policies attach <id> --principal-type TYPE --principal-id ID [flags]        attach a policy to a user or token
  levelrail-cli iam policies detach <id> --principal-type TYPE --principal-id ID [flags]        detach a policy from a user or token
  levelrail-cli iam policies attachments <id> [flags]                                                     list a policy's attached principals

DOC is a policy document JSON string, e.g.:
  {"Statement":[{"Effect":"Allow","Action":["read"],"Resource":["app:web"]}]}
Pass it inline, or as file://path/to/policy.json to read it from a file.

--principal-type must be "user" or "token"; --principal-id is the matching
user or token's own id.

Run "levelrail-cli iam policies <subcommand> -h" for a subcommand's own flags.
```
