## levelrail-cli sso

Subcommands: mappings, oidc, saml, scim, settings

```
Usage:
  levelrail-cli sso saml list|get|add|update|remove|import-metadata|metadata|test   manage SAML identity providers (create and delete also work)
  levelrail-cli sso oidc list|get <provider>                          show OAuth and OIDC sign-in policy
  levelrail-cli sso oidc set <provider> [--jit=BOOL] [--sync-roles=BOOL] [--default-role ID] [--groups-claim NAME] [--allowed-domains a.com,b.com]
  levelrail-cli sso oidc test <provider>                              print the browser address that runs a test login
  levelrail-cli sso oidc evaluate <provider> --email E [--email-verified] [--groups g1,g2]   what a sign-in would do, changes nothing
  levelrail-cli sso mappings list                                     show IDP group to role mappings
  levelrail-cli sso mappings set --map GROUP=ROLE[:PRIORITY] ...      replace every mapping
  levelrail-cli sso settings get                                      show SSO settings and the SP certificate
  levelrail-cli sso settings set [--enforce=true|false] [--scim-default-role ROLE_ID]
  levelrail-cli sso scim tokens list|create <name>|rotate <id>|revoke <id>   manage directory sync tokens

Every command needs a root token. Run "levelrail-cli sso <area> <verb> -h" for its flags.
```
