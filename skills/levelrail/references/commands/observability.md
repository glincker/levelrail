## levelrail-cli observability

Subcommands: add, list, presets, rm, test

```
Usage:
  levelrail-cli observability presets [flags]                       list the provider presets and their form fields
  levelrail-cli observability add <preset> --name N --field K=V [--signal logs|metrics] [flags]
                                                          create an export from a preset
  levelrail-cli observability test <name> [flags]                   send one log line and metric, report the result
  levelrail-cli observability list [flags]                          list exports and their delivery state
  levelrail-cli observability rm <name> [flags]                     delete an export and its stored credentials

Run "levelrail-cli observability presets" to see the fields each preset takes. A field value written as
env:NAME is read from that environment variable, so a token stays out of shell history.
Credentials are stored encrypted and are never shown again.
```
