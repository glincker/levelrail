## levelrail-cli pipelines

Subcommands: approve, artifacts, cancel, delete, fixes, insights, list, logs, oidc, run, runs, save, sync, templates, triggers, validate

```
Usage:
  levelrail-cli pipelines list <app> [flags]                       list an app's pipelines
  levelrail-cli pipelines validate <file> [--json]                 validate a pipeline file locally (no API call)
  levelrail-cli pipelines save <app> <file-or-repo-dir> [--name N] [--paths G,...] [--paths-ignore G,...] [--report-status=false] [flags]   create or update pipelines from a file, or every file in a repo's pipeline directory
  levelrail-cli pipelines delete <app> <name> [flags]              delete a pipeline
  levelrail-cli pipelines run <app> <name> [--ref R] [--sha S] [--param k=v]... [--follow] [flags]   --input is the older spelling of --param
  levelrail-cli pipelines runs <app> [<run-id>] [--pipeline N] [--limit N] [flags]   list runs, or show one run's jobs and steps
  levelrail-cli pipelines runs --all [--status S] [--app A] [--trigger T] [--pipeline N] [--limit N] [flags]   list runs across every app
  levelrail-cli pipelines logs <app> <run-id> [--job KEY] [--follow] [flags]
  levelrail-cli pipelines cancel <app> <run-id> [flags]
  levelrail-cli pipelines approve <app> <run-id> [--reject] [--comment TEXT] [--approval ID] [flags]   decide approval gates, or release a run held for approval
  levelrail-cli pipelines sync <app> [--repo-truth=true|false] [flags]   sync pipeline files from the repository now, or set repository as source of truth
  levelrail-cli pipelines artifacts <app> <run-id> [--download JOB] [--out FILE] [flags]   list a run's stored artifacts, or download one job's archive
  levelrail-cli pipelines triggers <app> [flags]                   why recent git events did or did not start runs
  levelrail-cli pipelines triggers <app> <pipeline> [--enable [--hmac]|--disable|--rotate|--delete|--deliveries|--replay ID] [flags]   manage the pipeline's inbound webhook trigger
  levelrail-cli pipelines templates [<id>] [--out FILE] [--create APP [--name N]] [flags]   list the starter pipelines, print one, write it to a file, or save it on an app
  levelrail-cli pipelines fixes <app> <run-id> [--apply KIND --job J [--rerun]] [flags]   known-error fixes for a failed run, or apply an automatic one
  levelrail-cli pipelines insights <app> <pipeline> [flags]        per-job failure rate, p50 time, flaky jobs, and the latest run's timing diff
  levelrail-cli pipelines oidc [flags]                             whether pipeline jobs can mint OIDC tokens, and the JWKS URL to wire to a cloud provider
  levelrail-cli pipelines oidc rotate-key [--retire-after D] [flags]   rotate the OIDC signing key; the old key stays published in the JWKS until it retires

Pipelines live in the control plane per app, or in the repository under a
pipeline directory. Run "levelrail-cli pipelines <subcommand> -h" for its flags.
```
