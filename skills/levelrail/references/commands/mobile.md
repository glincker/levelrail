Generated by `levelrail-cli docs`. Do not edit.

## levelrail-cli mobile

Subcommands: devices, pair

```
Usage:
  levelrail-cli mobile pair [flags]                  create a one-time pairing code for the mobile app
  levelrail-cli mobile devices list [flags]          list paired phones
  levelrail-cli mobile devices revoke <id> [flags]   revoke a paired phone

Needs the mobile-api beta feature (Settings, Beta features). "mobile pair"
needs a root token and asks for your password (and authenticator code).
```
