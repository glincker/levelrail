## levelrail-cli alerts

Subcommands: defaults, history, inbox, maintenance, silence, silences

```
Usage:
  levelrail-cli alerts silences list|create|delete [flags]     mute matching alerts for a while
  levelrail-cli alerts silence <app> <rule-id> [--for 1h]      silence one rule (quick action)
  levelrail-cli alerts maintenance list|create|update|delete   recurring silences (cron + duration + timezone)
  levelrail-cli alerts history [flags]                         firings and what happened to each notification
  levelrail-cli alerts explain <deploy-id>                     why a deploy failed, from its timeline (rule-based)
  levelrail-cli alerts inbox list|count|read|prefs             your alert inbox, read state, routing and daily digest

  levelrail-cli alerts defaults list|enable|disable|reset        the alerts seeded on first boot

Alert rules themselves live under "levelrail-cli apps alerts".
Run "levelrail-cli alerts <subcommand> -h" for its flags.
```

## levelrail-cli alerts defaults

Subcommands: disable, enable, list, reset

```
Usage:
  levelrail-cli alerts defaults list
  levelrail-cli alerts defaults enable <id>
  levelrail-cli alerts defaults disable <id>
  levelrail-cli alerts defaults reset

Default alerts are seeded on first boot: certificate expiry at 14, 7, 3 and
1 days, restore drill failures, node offline and more. Disabling one keeps
it disabled; it is never re-created or overwritten on restart.
```

## levelrail-cli alerts inbox

Subcommands: count, list, prefs, read

```
Usage:
  levelrail-cli alerts inbox list [--unread] [--limit N]
  levelrail-cli alerts inbox count
  levelrail-cli alerts inbox read (--id ID)... | --all
  levelrail-cli alerts inbox prefs [--min-severity S] [--mute APP]... [--unmute APP]... [--digest on|off] [--digest-hour H] [--digest-channel ID]

The inbox is the in-app list of alerts that reached you. By default it
shows warning and critical firings and resolutions and hides silenced,
grouped and rate limited noise. "prefs" with no flags prints the current
routing rules; the daily digest is sent at the chosen UTC hour through a
notification channel.
```

## levelrail-cli alerts silences

Subcommands: create, delete, list

```
Usage:
  levelrail-cli alerts silences list [--all]
  levelrail-cli alerts silences create --for DURATION [--rule ID] [--app NAME] [--node NAME] [--kind KIND] [--severity S] [--metric M] [--label k=v] [--reason TEXT]
  levelrail-cli alerts silences delete <id>

A silence keeps matching alerts evaluating and recorded in history but
stops them notifying. Every filter given must match (AND); repeat a
flag to accept any of several values. "delete" ends a silence now and
keeps it in history ("list --all").
```
