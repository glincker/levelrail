## levelrail-cli stack

Subcommands: apply, approve, cloud-state, create, delete, diff, drift, history, init, list, pin, plan, reject, rollback, settings, show, show-revision, templates, trust, unlock, unpin

```
Usage:
  levelrail-cli stack <command> [flags]

Stacks keep a named set of resources in git, plan each change, apply it as a
numbered revision and roll back to any earlier one. Needs APP_EXPERIMENTAL=iac.

Commands:
  templates                             list the bundled starter stacks
  init <template> [--dir D] [--set k=v] copy a starter stack into a directory
  list                                  list stacks
  show <name>                           one stack with its owned resources
  create <name> --project P|--scope install  create an empty stack
  plan <name> -f PATH [flags]           show what an apply would change
  apply <name> -f PATH [flags]          apply the files as a new revision
  history <name> [--limit N]            revisions, newest first
  show-revision <name> <n>              documents, plan and result of one revision
  diff <name> <n> [--against M|live]    compare a revision with another or with live state
  rollback <name> <n> [--yes]           apply the documents of revision n as a new revision
  approve <name> <n> [--secret ...]     approve a pending revision (root, never the requester)
  reject <name> <n> [--reason TEXT]     reject a pending revision (root)
  pin <name> <n>                        refuse applies except a rollback to revision n
  unpin <name>                          remove the pin
  unlock <name>                         release a stuck apply lease (root only)
  delete <name> [--mode forget|destroy] stop managing a stack, or also delete its resources
  drift <name>                          declared versus live drift; exit 2 when drifted, 0 when clean
  settings <name> [flags]               show or change --allow-prune, --drift, --require-approval (root only)
  trust add|list|remove <name> ...      OIDC trusts so CI needs no stored token (root only)
  cloud-state list|recover <name> ...   list or clear quarantined cloud state (root only)

Run 'levelrail-cli stack <command> --help' for the flags of a command.
```

## levelrail-cli stack trust

Subcommands: add, list, remove

```
Usage:
  levelrail-cli stack trust <command> [flags]

Trusts let a CI workflow swap its OIDC identity for a short-lived token bound to
one stack, so CI needs no stored secret. Root only.

Commands:
  add <name> --repo OWNER/NAME --ref PATTERN [flags]   trust a workflow identity
  list <name>                                          list the trusts of a stack
  remove <name> <id>                                   delete a trust

Run 'levelrail-cli stack trust <command> --help' for the flags of a command.
```
