## levelrail-cli forms

Subcommands: create, delete, export, fields, list, remove, snippet, spam, submissions, test, unspam, update

```
Usage:
  levelrail-cli forms list <app>
  levelrail-cli forms create <app> <name> [--redirect-url URL] [--honeypot FIELD] [--notify CHANNEL_ID,...]
  levelrail-cli forms update <app> <name> [--redirect-url URL] [--honeypot FIELD] [--notify CHANNEL_ID,...]
  levelrail-cli forms snippet <app> <name>
  levelrail-cli forms fields get <app> <name>
  levelrail-cli forms fields set <app> <name> --file schema.json
  levelrail-cli forms test <app> <name>
  levelrail-cli forms delete <app> <name>
  levelrail-cli forms submissions <app> <name> [--search TEXT] [--spam true|false] [--limit N]
  levelrail-cli forms spam|unspam <app> <name> <submission-id>
  levelrail-cli forms remove <app> <name> <submission-id>
  levelrail-cli forms export <app> <name> [--search TEXT] [--spam true|false]

schema.json holds {"fields":[{"name","type","label","required","placeholder","min_length","max_length","options"}],
"success_message":"","allowed_origins":["https://example.com"]}. Types: text, email, textarea, select,
checkbox, number, url, hidden. With fields set, undeclared submitted names are dropped. No fields keeps
the default name, email and message.

A form is a public endpoint a static site posts to (form-urlencoded, multipart or JSON).
Submissions keep a salted hash of the sender address, never the address itself, and are
deleted after FORMS_RETENTION_DAYS. Deleting a form deletes its submissions.
```
