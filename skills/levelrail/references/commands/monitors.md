## levelrail-cli monitors

Subcommands: create, delete, list, pause, results, resume, rotate-token, update

```
Usage (experimental, needs APP_MONITORS_ENABLED=true on the control plane):
  levelrail-cli monitors create --name N --kind http --url URL [--method GET] [--header NAME=VALUE]... [--expect 200-299,301] [--contains TEXT] [--follow-redirects] [--interval 60s] [--timeout 5s] [--status-link] [--link-confirm N] [--link-recovery 2m]
  levelrail-cli monitors create --name N --kind tcp --host HOST --port PORT [--interval 60s] [--timeout 5s] [--status-link]
  levelrail-cli monitors create --name N --kind heartbeat --interval 1h [--grace 10m] [--status-link]
  levelrail-cli monitors create --name N --kind tls --host HOST [--port 443] [--interval 24h] [--warn-days 21] [--crit-days 7] [--status-link]
  levelrail-cli monitors rotate-token <id>
  levelrail-cli monitors update <id> [--status-link=true|false] [--link-confirm N] [--link-recovery 2m]
  levelrail-cli monitors pause <id>
  levelrail-cli monitors resume <id>
  levelrail-cli monitors list
  levelrail-cli monitors results <id> [--window 24h] [--limit N]
  levelrail-cli monitors delete <id>

pause stops probing a monitor without deleting its history; resume starts it again.

--status-link opens a status page incident on the monitor's component while it is confirmed
down and resolves it after recovery. It is off by default; --link-confirm and --link-recovery
override the APP_MONITOR_LINK_* defaults for this monitor.

A heartbeat monitor prints a secret ping path once, at create and at rotate-token. A cron job
calls it with curl: success is the plain URL, then /start before and /fail on error. The monitor
goes down when no ping arrives within --interval plus --grace (default from APP_MONITOR_HEARTBEAT_GRACE)
and up on the next ping. A tls monitor reports days left on the certificate: degraded under
--warn-days and down under --crit-days (defaults APP_MONITOR_TLS_WARN_DAYS and APP_MONITOR_TLS_CRIT_DAYS);
an invalid chain is reported as a failure. rotate-token replaces the heartbeat URL at once.

Header values are stored encrypted and are never shown again. Interval floors
and limits come from the APP_MONITOR_* settings on the control plane.
```
