## levelrail-cli launchd

Subcommands: install, print, status, uninstall

```
Usage:
  levelrail-cli launchd install <control-plane|agent> --binary PATH [--arg A]... [--env K=V]...
  levelrail-cli launchd uninstall <control-plane|agent>
  levelrail-cli launchd status [--json]
  levelrail-cli launchd print <control-plane|agent> --binary PATH [--arg A]... [--env K=V]...

Manages per-user launchd units (~/Library/LaunchAgents) on macOS. print writes the plist to
stdout and changes nothing. Secrets are refused in --env: put them in the service env file.
Respawn gap: APP_LAUNCHD_THROTTLE_SECONDS (30). Logs: ~/Library/Logs/Levelrail.
```
