## levelrail-cli roles

Subcommands: create, delete, list, update

```
Usage:
  levelrail-cli roles list [flags]                                             list stored roles with their user counts
  levelrail-cli roles create <name> --abilities LIST [--visibility all|granted] [--description TEXT] [flags]   create a custom role
  levelrail-cli roles update <role> [--name N] [--abilities LIST] [--visibility V] [--description T] [flags]   edit a custom role
  levelrail-cli roles delete <role> [flags]                                    delete an unused custom role

<role> is a role id or name. Run "levelrail-cli roles <subcommand> -h" for its flags.
```
