## levelrail-cli registry-credentials

Subcommands: create, delete, get, list, repositories, tags, test, update

```
Usage:
  levelrail-cli registry-credentials list [flags]                                                                    list connected registry credentials
  levelrail-cli registry-credentials get <id> [flags]                                                                 show one registry credential
  levelrail-cli registry-credentials create --name NAME --registry-host HOST --username USER --password PASS [flags]   connect a new registry credential
  levelrail-cli registry-credentials update <id> --name NAME --registry-host HOST --username USER [flags]              update a registry credential, optionally rotating its password
  levelrail-cli registry-credentials delete <id> [flags]                                                               disconnect a registry credential
  levelrail-cli registry-credentials test <id> [flags]                                                                 authenticate a credential against its registry, without pulling anything
  levelrail-cli registry-credentials refresh <id> [flags]                                                              mint a new login now for an ECR, Artifact Registry or ACR credential
  levelrail-cli registry-credentials repositories <id> [flags]                                                         list every repository in the credential's external registry
  levelrail-cli registry-credentials tags <id> <repository> [flags]                                                    list every tag pushed for one repository in that registry

Run "levelrail-cli registry-credentials <subcommand> -h" for a subcommand's own flags.
```
