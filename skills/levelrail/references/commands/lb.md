## levelrail-cli lb

```
Usage:
  levelrail-cli lb list [--state S] [--search Q] [flags]       every load balancer across apps, with upstream health
  levelrail-cli lb show <app> [flags]                          show an app's load balancer config
  levelrail-cli lb set <app> [--algorithm ...] [flags]         create or change the load balancer (only the flags you pass change)
  levelrail-cli lb clear <app> [flags]                         remove the load balancer, back to a single upstream
  levelrail-cli lb status <app> [flags]                        live upstream table: health, active requests, req/s, error rate, p50/p95
  levelrail-cli lb check <app> [flags]                         probe every upstream once, right now
  levelrail-cli lb history <app> [--limit N] [flags]           recent checks and state changes per upstream
  levelrail-cli lb upstream <app> <id> --state S [flags]       set an upstream active, draining or disabled
  levelrail-cli lb export <app> --format FORMAT [--out FILE]   generate terraform, cdk, cloudformation, caddy or caddy-json
  levelrail-cli lb import <app> --file app.yaml [--service S]  load the loadbalancer: block of an app.yaml

Run "levelrail-cli lb <subcommand> -h" for a subcommand's own flags.
```
