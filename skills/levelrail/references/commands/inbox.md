## levelrail-cli inbox

Subcommands: archive, clear, delete, list, read

```
Usage:
  levelrail-cli inbox list [--unread] [--kind alert|approval|deploy|upgrade] [--archived] [--limit N]
  levelrail-cli inbox read (--id ID)... | --all
  levelrail-cli inbox archive (--id ID)... [--restore] | (--resolved | --read) [--older-than 72h]
  levelrail-cli inbox delete (--id ID)... --yes [--restore]
  levelrail-cli inbox clear (--archived | --resolved | --read) [--older-than 72h] --yes

The inbox gathers alerts, approval requests (sign-in and deploy), failed
deploys and failed database upgrades. Read and archive state is yours alone.
Only stored alert items can be deleted; approvals, failed deploys and failed
upgrades are derived live and can only be archived. Deleting needs --yes.
Approve or retry from the dashboard inbox page or with the commands the
title points to.
```
