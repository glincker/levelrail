## levelrail-cli build

Subcommands: branches, detect, frameworks

```
Usage:
  levelrail-cli build detect --repo-url URL [--ref REF] [flags]   show what framework the builder detects for a public repo, no build runs
  levelrail-cli build branches --repo-url URL [flags]             list the branches a public repo advertises
  levelrail-cli build frameworks [ID] [--dockerfile] [flags]      list framework presets, show one, or print its Dockerfile template

Both work against a public repository and need no existing app.

Run "levelrail-cli build <subcommand> -h" for a subcommand's own flags.
```
