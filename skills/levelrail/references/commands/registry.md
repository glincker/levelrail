## levelrail-cli registry

Subcommands: credentials, disable, enable, package-registries, repositories, status, tags

```
Usage:
  levelrail-cli registry status [flags]                    show the current settings and container status
  levelrail-cli registry enable --host HOST [flags]        provision and enable the built-in container registry
  levelrail-cli registry disable [flags]                   disable the registry and forget its generated credentials
  levelrail-cli registry repositories [flags]              list every repository pushed to the built-in registry
  levelrail-cli registry tags --repository NAME [flags]    list every tag pushed for one repository
  levelrail-cli registry credentials list|vendors|add|test|delete [flags]   external registry credentials, with vendor presets
  levelrail-cli registry package-registries list|add|test|delete [flags]    private npm, PyPI, Maven, NuGet, Cargo, Go and RubyGems registries for builds

Runs Levelrail's own built-in image registry (registry:2), so a
multi-node deployment gets a build cache/distribution backend without
signing up for an external registry first. The first "enable" call
generates a username and password; the password is printed once, in
that call's own response, and never shown again. This is a distinct
resource from "levelrail-cli registry-credentials", which stores credentials to
an external registry an operator already runs elsewhere.

Run "levelrail-cli registry <subcommand> -h" for a subcommand's own flags.
```

Subcommands: add, delete, list, test, vendors

```
Usage:
  levelrail-cli registry credentials list [flags]
  levelrail-cli registry credentials vendors [flags]          list the vendor presets for --vendor
  levelrail-cli registry credentials add --vendor ID [flags]  connect a credential with a vendor preset
  levelrail-cli registry credentials test <id> [flags]
  levelrail-cli registry credentials delete <id> [flags]
```

## levelrail-cli registry package-registries

Subcommands: add, delete, list, test

```
Usage:
  levelrail-cli registry package-registries list [flags]
  levelrail-cli registry package-registries add --ecosystem E --name NAME --url URL [flags]
  levelrail-cli registry package-registries test <id> [flags]
  levelrail-cli registry package-registries delete <id> [flags]

ECOSYSTEM is one of npm, pypi, maven, nuget, cargo, go, rubygems. The credential is mounted into Dockerfile
builds as a BuildKit secret (RUN --mount=type=secret,id=<build_secret_id>),
never as a build arg or an image layer.
```
