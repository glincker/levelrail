## levelrail-cli static-sites

Subcommands: delete, list, routes

```
Usage:
  levelrail-cli static-sites list [flags]
  levelrail-cli static-sites delete <name> [flags]
  levelrail-cli static-sites routes show|test|lint <app> [flags]

Lists every build.type: static app served directly through the embedded
Caddy ingress, with no container involved.

Run "levelrail-cli static-sites <subcommand> -h" for a subcommand's own flags.
```

## levelrail-cli static-sites routes

Subcommands: lint, show, test

```
Usage:
  levelrail-cli static-sites routes show <app> [flags]
  levelrail-cli static-sites routes test <app> <path> [--method M] [--request-query Q] [flags]
  levelrail-cli static-sites routes lint <app> [--redirects FILE] [--headers FILE] [flags]

show lists the redirect, rewrite and header rules the live deploy serves, with
the problems found when it was published. test runs one request through them
and says which rule or file answers. lint parses local _redirects and
_headers files without deploying.

Run "levelrail-cli static-sites routes <subcommand> -h" for its flags.
```
