## levelrail-cli containers

Subcommands: claim, list, orphans, reap, remove, stop

```
Usage:
  levelrail-cli containers [list] [flags]                       list every container on this node, managed or not
  levelrail-cli containers stop <name> [flags]                   stop an orphaned container
  levelrail-cli containers remove <name> [flags]                 remove an orphaned container
  levelrail-cli containers claim <name> [--as app-name] [flags]  adopt an orphaned container into a new app
  levelrail-cli containers orphans [flags]                       leftover containers and volumes, with grace status
  levelrail-cli containers reap [--dry-run] [flags]              remove due leftovers now (the reaper also runs on a schedule)

stop/remove/claim only ever act on a container Levelrail does not
already manage (409 otherwise); for a levelrail-cli-managed app, use
"levelrail-cli apps stop/start/restart/delete <name>" instead, which update
desired state correctly rather than fighting the reconciler.

Run "levelrail-cli containers <subcommand> -h" for a subcommand's own flags.

Flags:
  --token string       API token (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then the credentials file)
  --api-url string    control plane base URL (default: LEVELRAIL_API_URL or APP_API_URL env var, then http://localhost:8080)
  --profile string    named credentials profile to read (overrides APP_PROFILE, default "default")
  --json                  print the result as JSON to stdout, nothing else
  --output string        output format: json, table, or text (default table; --json is shorthand for --output json)
  --query string         JMESPath expression to filter the result before printing
  -h, --help            show this help
```
