## levelrail-cli nodes failure-policy

Subcommands: get, set

```
Usage:
  levelrail-cli nodes failure-policy get <id> [flags]
  levelrail-cli nodes failure-policy set <id> [--mode off|notify|auto] [--grace SECONDS] [flags]

Shows or sets what happens when a node stays unreachable. Default is off.
notify only reports it, auto also moves stateless apps to healthy nodes.
Apps with node-local volumes and databases are never moved automatically.
```

## levelrail-cli nodes patch

Subcommands: apply, preview, runs

```
Usage:
  levelrail-cli nodes patch preview <id> [--include-all] [--refresh] [flags]
  levelrail-cli nodes patch apply <id> --yes [--include-all] [--reboot-if-required] [--preview ID] [--no-wait] [flags]
  levelrail-cli nodes patch runs <id> [flags]

Preview lists exactly which OS packages would change (security updates only by
default; kernel, docker and containerd upgrades are held unless --include-all).
Apply installs that exact list and refuses when the list changed since the
preview, a deploy is running, or another patch run is active. It never reboots
unless --reboot-if-required is set and no apps or databases run on the node.
Today only the control plane's own host can be patched.

Flags:
  --include-all            include non-security, kernel and container runtime updates
  --refresh                refresh package lists before the preview
  --yes                    apply; without it apply only prints the preview
  --reboot-if-required     reboot when the upgrade needs it and the node is drained
  --preview string         apply an earlier preview id
  --no-wait                do not wait for the run to finish
  --token string           API token (default: LEVELRAIL_TOKEN or APP_API_TOKEN env var, then the credentials file)
  --api-url string         control plane base URL (default: LEVELRAIL_API_URL or APP_API_URL env var, then http://localhost:8080)
  --profile string         named credentials profile to read
  --json                   print the result as JSON
  --output string          output format: json, table, or text
  --query string           JMESPath expression to filter the result
  -h, --help               show this help
```

## levelrail-cli nodes providers

Subcommands: list, set-credential

```
Usage:
  levelrail-cli nodes providers list [flags]                                          list known cloud providers and whether each has a stored credential
  levelrail-cli nodes providers connect --provider NAME [--method METHOD] [flags]   connect a provider (tests it first unless --verify=false)
  levelrail-cli nodes providers test --provider NAME [flags]                          run a read-only connection test against the stored credential
  levelrail-cli nodes providers disconnect --provider NAME [flags]                    remove the stored credential
  levelrail-cli nodes providers set-credential --provider NAME --provider-token TOKEN [flags]   store (or replace) a provider's API token without testing

NAME must be "hetzner", "digitalocean", "aws", "azure", "gcp" or "custom".
METHOD is api_token, access_key, assume_role, ambient, service_account_json,
workload_identity_federation or manual; omit it to infer one.

Run "levelrail-cli nodes providers <subcommand> -h" for a subcommand's own flags.
```
