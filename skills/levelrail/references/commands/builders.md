## levelrail-cli builders

Subcommands: add, list, pause, remove, resume, show, test

```
Usage:
  levelrail-cli builders list [flags]                 builders, tier, platform, slots, last seen and recent build time
  levelrail-cli builders add [--name N] [flags]       mint a personal builder join token and print the join command
  levelrail-cli builders show <name> [flags]          one builder with its last 10 builds
  levelrail-cli builders pause <name> [flags]         stop new builds, running ones finish
  levelrail-cli builders resume <name> [flags]        accept new builds again
  levelrail-cli builders test <name> [flags]          run a tiny probe build (no app data) and report latency and arch
  levelrail-cli builders remove <name> [flags]        remove the node and revoke its certificate

Builders are build-only nodes (laptops, home machines, cloud instances). Add one with
"builders add", then run the printed "builder join" line on that machine.
```
