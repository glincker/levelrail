## levelrail-cli views

Subcommands: apply, delete, list, save

```
Usage:
  levelrail-cli views list [--list L] [flags]                                    your saved views and the views shared with your team
  levelrail-cli views save <name> --list L [--filter KEY=VALUE]... [--share private|team] [flags]
                                                                         save a list filter under a name (same name replaces it)
  levelrail-cli views delete <id|name> [--list L] [flags]                        delete a view (owner, or a team admin for a shared view)
  levelrail-cli views apply <id|name> [--list L] [flags]                         print the dashboard path that opens the list with the view's filter

Lists and their filter keys:
  apps: q, status, env, tags, labels
  databases: q, status, engine, labels
  domains: q, status
  builds: q, status, app
  deployments: q, status, app, env
--share team shares the view with the team you are signed in to; only you can change it.
Example: levelrail-cli views save failing --list apps --filter status=failing --share team
```
