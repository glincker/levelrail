## levelrail-cli pages

```
Usage:
  levelrail-cli pages deploy <dir|zip> [--name N] [--domain D] [flags]
  levelrail-cli pages list [flags]
  levelrail-cli pages show <name> [flags]
  levelrail-cli pages delete <name> [flags]
  levelrail-cli pages rollback <name> [version] [flags]
  levelrail-cli pages domains add <name> <domain> [flags]
  levelrail-cli pages domains status <name> <domain> [flags]
  levelrail-cli pages routes show|test|lint <name> [flags]

Publishes a folder or .zip as a static site: no build, no source control.
The upload limit comes from APP_UPLOAD_MAX_BYTES. "deploy" accepts every flag of "levelrail-cli deploy".
```

## levelrail-cli pages routes

Subcommands: lint, show, test

```
Usage:
  levelrail-cli static-sites routes show <app> [flags]
  levelrail-cli static-sites routes test <app> <path> [--method M] [--request-query Q] [flags]
  levelrail-cli static-sites routes lint <app> [--redirects FILE] [--headers FILE] [flags]

show lists the redirect, rewrite and header rules the live deploy serves, with
the problems found when it was published. test runs one request through them
and says which rule or file answers. lint parses local _redirects and
_headers files without deploying.

Run "levelrail-cli static-sites routes <subcommand> -h" for its flags.
```
