## levelrail-cli cleanup

Subcommands: list, mode, preview, run, runs

```
Usage:
  levelrail-cli cleanup list [flags]                          every cleanup target with usage, retention, mode and last run
  levelrail-cli cleanup preview ID [--days N] [flags]         rows and bytes a run would delete (deletes nothing)
  levelrail-cli cleanup run ID [--days N] [--dry-run] [--yes] [flags]
                                                      delete old data; without --dry-run, --yes is required
  levelrail-cli cleanup mode ID off|preview|on [flags]        off, preview (scheduled runs only record) or on
  levelrail-cli cleanup runs [--target ID] [--since DATE] [--format table|json|csv] [flags]
                                                      run history, newest first

Retention is a runtime setting (see "levelrail-cli settings runtime"). --days overrides it for one call.
Viewing needs a read token; preview, run and mode need a root API token.

Run "levelrail-cli cleanup <subcommand> -h" for a subcommand's own flags.
```
