# Governance

Levelrail is a single maintainer-led open source project under the Apache License 2.0 (see [LICENSE](LICENSE)).

## How decisions are made

- The maintainer decides scope, releases and architecture. Architecture decisions are recorded in [adr/](adr/), and a locked decision is changed only by a new ADR.
- Bug reports, feature requests and design questions are discussed in GitHub issues and [Discussions](https://github.com/glincker/levelrail/discussions). Public discussion is open to everyone.
- Security reports follow [.github/SECURITY.md](.github/SECURITY.md) and are never discussed in public first.

## Becoming a maintainer

There is no formal process yet. Sustained, good-quality contributions (reviewed merged pull requests, triaged issues, helpful answers in Discussions) are the path. The current maintainer invites people who have shown that work over time. Maintainers are listed in [MAINTAINERS.md](MAINTAINERS.md).

## Changes to this document

Changes to governance are made by pull request and approved by the maintainer.
