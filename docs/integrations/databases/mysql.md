Create a managed MySQL database with scheduled backups, a slow query log and restore into a new database.

This page covers how to run and back up managed MySQL databases.

## What you get

- A MySQL 8 container with generated settings and its own data volume that survives container recreation.
- Connection details and an injectable connection string for apps.
- Backups as mysqldump backups, with schedules and retention.
- Slow query log read from the container, with a 1000 ms default threshold.

## Set up

1. Prepare the credential. Credentials are generated by Levelrail and exposed through the connection string.
2. In the dashboard, open **Databases > Create database (engine MySQL)**.
3. Check the database status on its Overview tab, then take a first backup against a connected target.

From the CLI:

```bash
levelrail-cli databases create --name main --engine mysql --version 8
levelrail-cli backups schedule set main --target <target-id> --cron "0 3 * * *" --retain 7
```

## Permissions and scopes

| Needed | Why |
| --- | --- |
| Create and manage | A user with write access to databases; public access and deletion are separate decisions in the UI. |

## Endpoint and format

Engine id `mysql`. Default version `8`. TLS: off.

## Security notes

- Credentials are generated by the control plane and stored with the same envelope encryption as app secrets.
- Deleting a database keeps its data volume and its backups unless you explicitly ask for the data to go.
- Nothing you enter here is shown again after you save it.

## Limits and caveats

- Only minor and patch version changes are accepted; a major change is refused with 409.
- No in place major upgrade flow: back up and restore as new on the new version.
- TLS is not enabled by default.

## Troubleshooting

**set-version returns 409.** MySQL accepts only minor and patch changes. Back up, then `backups restore-as-new` onto the new version.

**Slow query results are empty.** The log reads /var/log/mysql/slow.log and is on from creation. Lower APP_DATABASE_SLOW_QUERY_THRESHOLD_MS if the 1000 ms default hides your queries.

**A backup fails with 507.** The control plane data directory is below APP_MIN_BACKUP_DISK_MB free. Free space there.

## FAQ

**Can I restore to a different name?**

Yes. Restore as new creates a new database from a backup, which also serves as the major upgrade path.

**Is MySQL point-in-time restore available?**

No. It is Postgres only.
