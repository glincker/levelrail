Curated monitoring and analytics tools whose environment variables are injected into an app.

| Integration | What it enables |
| --- | --- |
| [Sentry](/integrations/app-integrations/sentry) | Send app errors to Sentry with an injected DSN |
| [GlitchTip](/integrations/app-integrations/glitchtip) | Send app errors to GlitchTip through the Sentry SDK variable |
| [PostHog](/integrations/app-integrations/posthog) | Inject PostHog analytics keys into an app |
| [OneUptime](/integrations/app-integrations/oneuptime) | Export OpenTelemetry data from an app to OneUptime |
| [Plausible](/integrations/app-integrations/plausible) | Inject Plausible web analytics settings into an app |
| [Datadog](/integrations/app-integrations/datadog) | Inject a Datadog API key and site into an app |
| [Axiom](/integrations/app-integrations/axiom) | Inject Axiom token and dataset into an app |
| [Better Stack](/integrations/app-integrations/betterstack) | Inject a Better Stack log source token into an app |
| [LogSnag](/integrations/app-integrations/logsnag) | Inject LogSnag token and project into an app |
| [BugSnag](/integrations/app-integrations/bugsnag) | Inject a BugSnag API key into an app |
| [New Relic](/integrations/app-integrations/newrelic) | Inject a New Relic license key into an app |
