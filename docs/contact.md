**Get help or reach the team**

Pick the channel that fits. There is no dedicated support team or formal SLA yet, so public channels are the fastest way to get an answer.

[Email support](mailto:support@levelrail.com) | [Open an issue](https://github.com/glincker/levelrail/issues)

## Where to go

<CardGroup cols={3}>
  <Card title="Email">
    support@levelrail.com for questions that do not belong in a public thread.
  </Card>
  <Card title="GitHub">
    Issues for bugs and requests, Discussions for questions and ideas.
  </Card>
  <Card title="Discord">
    Chat with other operators and contributors on the GLINR Discord.
  </Card>
  <Card title="Security">
    Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting as described in the security policy.
  </Card>
</CardGroup>
