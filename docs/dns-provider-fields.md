The dashboard form, the CLI flags and the API all read one field registry, served at `GET /api/v1/field-descriptors/dns-providers`. Secrets are write only: they are accepted on create and update and never returned.

| Field | Type | Required | Shown when | CLI flag | Description |
| --- | --- | --- | --- | --- | --- |
| `provider` (provider) | select | yes | always | none | DNS provider, one of cloudflare, route53 or googlecloud (the CLI picks it by subcommand) |
| `token` (cloudflare.token) | secret, write only | yes | `provider` is cloudflare | `--cf-api-token` | Cloudflare API token with Zone:DNS:Edit scope, write only |
| `access_key_id` (route53.access_key_id) | secret, write only | yes | `provider` is route53 | `--aws-access-key-id` | AWS IAM access key ID, write only |
| `secret_access_key` (route53.secret_access_key) | secret, write only | yes | `provider` is route53 | `--aws-secret-access-key` | AWS IAM secret access key, write only |
| `region` (route53.region) | string | no | `provider` is route53 | `--aws-region` | AWS region, resolved automatically when empty |
| `hosted_zone_id` (route53.hosted_zone_id) | string | no | `provider` is route53 | `--hosted-zone-id` | Route53 hosted zone ID, resolved by matching the domain when empty |
| `service_account_json` (googlecloud.service_account_json) | text, write only | yes | `provider` is googlecloud | `--key-file` | service account JSON key, write only (the CLI reads it from a file) |
