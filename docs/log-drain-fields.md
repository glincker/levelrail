The dashboard form, the CLI flags and the API all read one field registry, served at `GET /api/v1/log-drains/field-descriptors`. Secrets are write only: they are accepted on create and update and never returned.

| Field | Type | Required | Shown when | CLI flag | Description |
| --- | --- | --- | --- | --- | --- |
| `type` (type) | select | yes | always | `--type` | sink type, http or syslog |
| `target` (target_http) | string | yes | `type` is http | `--target` | HTTP URL that receives the log stream |
| `target` (target_syslog) | string | no | `type` is syslog | none | syslog network://host:port, empty for local syslog |
| `enabled` (enabled) | bool | no | always | none | forwarding on or paused (CLI: --disabled pauses it) |
