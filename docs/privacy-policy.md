# Privacy policy

Last updated: 2026-10-05.

This policy describes the Levelrail website at levelrail.com. For how the software itself handles your data, secrets, metrics and logs on your own servers, see [Privacy and data handling](/privacy).

## What this website collects

The website's own code does not load analytics scripts, advertising trackers or third-party widgets, and it does not ask you to create an account. We do not sell or share personal data collected through the site.

## Server logs

Like any web host, whoever serves the site's files can see ordinary request information such as your IP address, the page requested and your browser type. This is used to run and secure the service. We do not use it to build profiles.

## Browser storage

The site stores your theme choice (dark or light) in your browser's local storage so it can remember it. See the [cookie notice](/cookies).

## Email

If you email [support@levelrail.com](mailto:support@levelrail.com), we use your message and address only to reply to you and keep a record of the conversation.

## Third-party sites

Links to GitHub, Discord, npm and other sites leave this website. Their own privacy policies apply there.

## Your choices

You can clear local storage in your browser at any time. To ask about data we hold from an email conversation, write to [support@levelrail.com](mailto:support@levelrail.com).

## Changes

We may update this policy. The date at the top shows when it last changed.

## Contact

Questions about this page: [support@levelrail.com](mailto:support@levelrail.com).
