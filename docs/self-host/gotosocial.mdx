A lightweight ActivityPub social network server with Mastodon-compatible clients.

This page describes the Levelrail template for GoToSocial (Social). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gotosocial.org.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gotosocial` | `superseriousbusiness/gotosocial:0.22.3` | 8080 | `gotosocial_data -&#62; /gotosocial/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `gotosocial` | `GTS_DB_ADDRESS` | Preset in the template |
| `gotosocial` | `GTS_DB_TYPE` | Preset in the template |
| `gotosocial` | `GTS_HOST` | Preset in the template |
| `gotosocial` | `GTS_LETSENCRYPT_ENABLED` | Preset in the template |
| `gotosocial` | `GTS_STORAGE_LOCAL_BASE_PATH` | Preset in the template |
| `gotosocial` | `GTS_TRUSTED_PROXIES` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`gotosocial`): gotosocial_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy GoToSocial with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GoToSocial. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gotosocial --name my-gotosocial
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.

All templates are listed in the [self-host gallery](/self-host).
