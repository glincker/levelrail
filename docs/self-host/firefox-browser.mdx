A private Firefox browser running on your server and streamed to a web page.

This page describes the Levelrail template for Firefox (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/jlesage/docker-firefox.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `firefox` | `jlesage/firefox:latest` | 5800 | `firefox_config -&#62; /config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`firefox`): jlesage/firefox:latest.
- Publishes ports directly on the host (`firefox`): 5800:5800.
- Stores data in named volumes (`firefox`): firefox_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Firefox with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Firefox. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy firefox-browser --name my-firefox-browser
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
