Self-hosted file sync and share with real file-level versioning and client-side encryption options.

This page describes the Levelrail template for Seafile (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://manual.seafile.com.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mariadb` | `mariadb:11` | none | `seafile_mariadb_data -&#62; /var/lib/mysql` |
| `memcached` | `memcached:latest` | none | none |
| `seafile` | `seafileltd/seafile-mc:13.0.28` | 80 | `seafile_data -&#62; /shared` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mariadb` | `MYSQL_DATABASE` | Preset in the template |
| `mariadb` | `MYSQL_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_USER` | Generated at deploy |
| `seafile` | `DB_HOST` | Preset in the template |
| `seafile` | `DB_PASSWORD` | Generated at deploy |
| `seafile` | `DB_PORT` | Preset in the template |
| `seafile` | `DB_ROOT_PASSWD` | Generated at deploy |
| `seafile` | `DB_USER` | Generated at deploy |
| `seafile` | `INIT_SEAFILE_ADMIN_EMAIL` | Preset in the template |
| `seafile` | `INIT_SEAFILE_ADMIN_PASSWORD` | Generated at deploy |
| `seafile` | `JWT_PRIVATE_KEY` | Generated at deploy |
| `seafile` | `SEAFILE_SERVER_HOSTNAME` | Preset in the template |
| `seafile` | `SEAFILE_SERVER_PROTOCOL` | Preset in the template |
| `seafile` | `TIME_ZONE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Seafile with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Seafile. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy seafile --name my-seafile
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
