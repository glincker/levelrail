A database-less note-taking app that keeps notes as plain Markdown files.

This page describes the Levelrail template for flatnotes (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/dullage/flatnotes/wiki.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `flatnotes` | `dullage/flatnotes:v5.5.5` | 8080 | `flatnotes_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `flatnotes` | `FLATNOTES_AUTH_TYPE` | Preset in the template |
| `flatnotes` | `FLATNOTES_PASSWORD` | Generated at deploy |
| `flatnotes` | `FLATNOTES_SECRET_KEY` | Generated at deploy |
| `flatnotes` | `FLATNOTES_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`flatnotes`): 8080:8080.
- Passwords and keys are generated at deploy time (`flatnotes`): FLATNOTES_PASSWORD, FLATNOTES_SECRET_KEY.
- Stores data in named volumes (`flatnotes`): flatnotes_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy flatnotes with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select flatnotes. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flatnotes --name my-flatnotes
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
