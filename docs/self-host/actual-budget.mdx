A local-first, envelope-style budgeting app with optional multi-device sync.

This page describes the Levelrail template for Actual Budget (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://actualbudget.org/docs/install/docker/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `actual` | `actualbudget/actual-server:26.9.0` | 5006 | `actual_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Actual Budget with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Actual Budget. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy actual-budget --name my-actual-budget
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
