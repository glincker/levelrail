A simple, self-hosted platform for organizing documentation into books, chapters, and pages.

This page describes the Levelrail template for BookStack (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.bookstackapp.com/docs/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `bookstack` | `lscr.io/linuxserver/bookstack:24.05.2` | 80 | `bookstack_data -&#62; /config` |
| `db` | `mariadb:11` | none | `bookstack_db_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `bookstack` | `APP_URL` | Preset in the template |
| `bookstack` | `DB_DATABASE` | Preset in the template |
| `bookstack` | `DB_HOST` | Preset in the template |
| `bookstack` | `DB_PASSWORD` | Generated at deploy |
| `bookstack` | `DB_USERNAME` | Preset in the template |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy BookStack with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select BookStack. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy bookstack --name my-bookstack
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
