Microsoft's Phi-3 Mini (3.8B), the smallest model in this catalog, good for constrained nodes.

This page describes the Levelrail template for Ollama: Phi-3 Mini (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://ollama.com/library/phi3.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ollama` | `ollama/ollama:0.33.3` | 11434 | `ollama_data -&#62; /root/.ollama` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Ollama: Phi-3 Mini with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ollama: Phi-3 Mini. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ollama-phi --name my-ollama-phi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
