A fast, structured team wiki and knowledge base with real-time collaborative editing.

This page describes the Levelrail template for Outline (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.getoutline.com.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `outline_db_data -&#62; /var/lib/postgresql/data` |
| `outline` | `outlinewiki/outline:0.79.0` | 3000 | `outline_data -&#62; /var/lib/outline/data` |
| `redis` | `redis:7-alpine` | none | `outline_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `outline` | `DATABASE_URL` | Generated at deploy |
| `outline` | `FORCE_HTTPS` | Preset in the template |
| `outline` | `PGSSLMODE` | Preset in the template |
| `outline` | `REDIS_URL` | Preset in the template |
| `outline` | `SECRET_KEY` | Generated at deploy |
| `outline` | `URL` | Preset in the template |
| `outline` | `UTILS_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`outline`): 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `outline`): DATABASE_URL, SECRET_KEY, UTILS_SECRET, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`redis`).
- Stores data in named volumes (`db`, `outline`, `redis`): outline_data, outline_db_data, outline_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Outline with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Outline. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy outline --name my-outline
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
