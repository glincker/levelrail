A document database with an HTTP API, built-in replication and the Fauxton admin console.

This page describes the Levelrail template for CouchDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.couchdb.org/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `couchdb` | `couchdb:3.4` | 5984 | `data -&#62; /opt/couchdb/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `couchdb` | `COUCHDB_PASSWORD` | Generated at deploy |
| `couchdb` | `COUCHDB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy CouchDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select CouchDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy couchdb --name my-couchdb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
