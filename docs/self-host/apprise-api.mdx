A single HTTP endpoint that fans a notification out to 100+ services such as Slack, Discord, and email.

This page describes the Levelrail template for Apprise API (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/caronc/apprise-api.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `apprise-api` | `caronc/apprise:1.5.4` | 8000 | `apprise_config -&#62; /config`<br />`apprise_attach -&#62; /attachments` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Apprise API with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Apprise API. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy apprise-api --name my-apprise-api
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
