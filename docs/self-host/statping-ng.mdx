A status page and uptime monitor for sites, APIs and TCP services with alerts.

This page describes the Levelrail template for Statping-ng (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/statping-ng/statping-ng.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `statping-ng` | `adamboutcher/statping-ng:v0.90.78` | 8080 | `app -&#62; /app` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `statping-ng` | `ADMIN_PASSWORD` | Generated at deploy |
| `statping-ng` | `ADMIN_USER` | Preset in the template |
| `statping-ng` | `DB_CONN` | Preset in the template |
| `statping-ng` | `DESCRIPTION` | Preset in the template |
| `statping-ng` | `NAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`statping-ng`): ADMIN_PASSWORD.
- Stores data in named volumes (`statping-ng`): app.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Statping-ng with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Statping-ng. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy statping-ng --name my-statping-ng
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
