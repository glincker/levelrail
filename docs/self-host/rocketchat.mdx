A full-featured, self-hosted team chat platform with video calls and app integrations.

This page describes the Levelrail template for Rocket.Chat (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.rocket.chat.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mongo` | `mongo:7` | none | `rocketchat_mongo_data -&#62; /data/db` |
| `rocketchat` | `rocketchat/rocket.chat:8.0.1` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `rocketchat` | `MONGO_OPLOG_URL` | Preset in the template |
| `rocketchat` | `MONGO_URL` | Preset in the template |
| `rocketchat` | `ROOT_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Rocket.Chat with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Rocket.Chat. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy rocketchat --name my-rocketchat
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
