An extensible no-code/low-code platform for building internal tools and databases.

This page describes the Levelrail template for NocoBase (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.nocobase.com/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `nocobase` | `nocobase/nocobase:1.9.33` | 13000 | `nocobase_storage -&#62; /app/nocobase/storage` |
| `postgres` | `postgres:17-alpine` | none | `nocobase_postgres_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `nocobase` | `APP_KEY` | Generated at deploy |
| `nocobase` | `DB_DATABASE` | Preset in the template |
| `nocobase` | `DB_DIALECT` | Preset in the template |
| `nocobase` | `DB_HOST` | Preset in the template |
| `nocobase` | `DB_PASSWORD` | Generated at deploy |
| `nocobase` | `DB_PORT` | Preset in the template |
| `nocobase` | `DB_USER` | Preset in the template |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy NocoBase with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select NocoBase. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nocobase --name my-nocobase
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
