A lightweight private npm proxy registry with caching and local package publishing.

This page describes the Levelrail template for Verdaccio (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://verdaccio.org/docs/installation.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `verdaccio` | `verdaccio/verdaccio:5.31.1` | 4873 | `verdaccio_storage -&#62; /verdaccio/storage`<br />`verdaccio_conf -&#62; /verdaccio/conf` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `verdaccio` | `VERDACCIO_PORT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`verdaccio`): 4873:4873.
- Stores data in named volumes (`verdaccio`): verdaccio_conf, verdaccio_storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Verdaccio with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Verdaccio. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy verdaccio --name my-verdaccio
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
