An open-source customer support platform for live chat, email, and social messaging.

This page describes the Levelrail template for Chatwoot (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.chatwoot.com/docs/self-hosted/.

Recommended memory: about 1536 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `chatwoot` | `chatwoot/chatwoot:v4.6.0` | 3000 | `chatwoot_data -&#62; /app/storage` |
| `db` | `postgres:16-alpine` | none | `chatwoot_db_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `chatwoot_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `chatwoot` | `FRONTEND_URL` | Preset in the template |
| `chatwoot` | `POSTGRES_DATABASE` | Preset in the template |
| `chatwoot` | `POSTGRES_HOST` | Preset in the template |
| `chatwoot` | `POSTGRES_PASSWORD` | Generated at deploy |
| `chatwoot` | `POSTGRES_USERNAME` | Generated at deploy |
| `chatwoot` | `RAILS_ENV` | Preset in the template |
| `chatwoot` | `REDIS_URL` | Preset in the template |
| `chatwoot` | `SECRET_KEY_BASE` | Generated at deploy |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`chatwoot`): 3000:3000.
- Passwords and keys are generated at deploy time (`chatwoot`, `db`): POSTGRES_PASSWORD, POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_USERNAME, SECRET_KEY_BASE.
- No health check, so a deploy is judged by the process starting (`db`, `redis`).
- Stores data in named volumes (`chatwoot`, `db`, `redis`): chatwoot_data, chatwoot_db_data, chatwoot_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Chatwoot with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Chatwoot. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy chatwoot --name my-chatwoot
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
