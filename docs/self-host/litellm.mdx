One OpenAI-format gateway in front of 100+ model providers, with keys, budgets, and spend tracking.

This page describes the Levelrail template for LiteLLM Proxy (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.litellm.ai/docs/simple_proxy.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `litellm_db_data -&#62; /var/lib/postgresql/data` |
| `litellm` | `ghcr.io/berriai/litellm:main-stable` | 4000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `litellm` | `DATABASE_URL` | Generated at deploy |
| `litellm` | `LITELLM_MASTER_KEY` | Generated at deploy |
| `litellm` | `STORE_MODEL_IN_DB` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`litellm`): 4000:4000.
- Passwords and keys are generated at deploy time (`db`, `litellm`): DATABASE_URL, LITELLM_MASTER_KEY, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): litellm_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LiteLLM Proxy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LiteLLM Proxy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy litellm --name my-litellm
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
