Open-source home automation that puts local control and privacy first.

This page describes the Levelrail template for Home Assistant (IoT). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.home-assistant.io/docs/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `home-assistant` | `ghcr.io/home-assistant/home-assistant:2025.10.2` | 8123 | `home_assistant_config -&#62; /config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Home Assistant with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Home Assistant. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy home-assistant --name my-home-assistant
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
