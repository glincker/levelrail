A fast, typo-tolerant search engine API you can drop into any app's search bar.

This page describes the Levelrail template for Meilisearch (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.meilisearch.com/docs.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `meilisearch` | `getmeili/meilisearch:v1.11.1` | 7700 | `meilisearch_data -&#62; /meili_data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `meilisearch` | `MEILI_MASTER_KEY` | Generated at deploy |
| `meilisearch` | `MEILI_NO_ANALYTICS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Meilisearch with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Meilisearch. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy meilisearch --name my-meilisearch
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
