An all-in-one OpenTelemetry backend with an OTLP collector, Loki logs, Tempo traces, Prometheus metrics and Grafana in one container. The Grafana admin password is generated at install. OTLP ports are not published on the host, so send telemetry from other services in this project to otel-lgtm:4317 (gRPC) or otel-lgtm:4318 (HTTP).

This page describes the Levelrail template for Grafana OTel LGTM (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://grafana.com/docs/opentelemetry/docker-lgtm/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `otel-lgtm` | `grafana/otel-lgtm:0.8.1` | 3000, 4317, 4318 | `otel_lgtm_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `otel-lgtm` | `GF_SECURITY_ADMIN_PASSWORD` | Generated at deploy |
| `otel-lgtm` | `GF_SECURITY_ADMIN_USER` | Preset in the template |
| `otel-lgtm` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`otel-lgtm`): GF_SECURITY_ADMIN_PASSWORD.
- Stores data in named volumes (`otel-lgtm`): otel_lgtm_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Grafana OTel LGTM with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Grafana OTel LGTM. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy otel-lgtm --name my-otel-lgtm
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
