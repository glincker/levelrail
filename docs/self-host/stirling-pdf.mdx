A self-hosted, all-in-one toolkit for merging, splitting, converting, and editing PDFs.

This page describes the Levelrail template for Stirling PDF (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.stirlingpdf.com.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `stirling-pdf` | `stirlingtools/stirling-pdf:0.36.2` | 8080 | `stirling_pdf_data -&#62; /usr/share/tessdata` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Stirling PDF with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Stirling PDF. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy stirling-pdf --name my-stirling-pdf
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
