A painless self-hosted Git service written in Go, light enough to run on a small VPS.

This page describes the Levelrail template for Gogs (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://gogs.io/docs.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gogs` | `gogs/gogs:0.13.3` | 3000 | `data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Gogs with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Gogs. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gogs --name my-gogs
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
