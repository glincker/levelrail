An all-in-one insight hub that combines website analytics, uptime monitoring and server status in one dashboard.

This page describes the Levelrail template for Tianji (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://tianji.dev/docs/intro.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `tianji` | `moonrailgun/tianji:1.33.9` | 12345 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `tianji` | `ALLOW_OPENAPI` | Preset in the template |
| `tianji` | `ALLOW_REGISTER` | Preset in the template |
| `tianji` | `DATABASE_URL` | Generated at deploy |
| `tianji` | `JWT_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Tianji with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Tianji. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy tianji --name my-tianji
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
