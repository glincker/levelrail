A CMS for building websites, blogs, and ecommerce stores.

This page describes the Levelrail template for Vvveb CMS (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.vvveb.com.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `vvveb` | `vvveb/vvvebcms:latest` | 80 | `vvveb_data -&#62; /var/www/html` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Vvveb CMS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Vvveb CMS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy vvveb --name my-vvveb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
