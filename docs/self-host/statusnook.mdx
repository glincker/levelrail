Deploy a status page and start monitoring endpoints in minutes.

This page describes the Levelrail template for Statusnook (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://statusnook.com.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `statusnook` | `goksan/statusnook:latest` | 8000 | `statusnook_data -&#62; /app/statusnook-data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Statusnook with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Statusnook. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy statusnook --name my-statusnook
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
