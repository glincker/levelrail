Self-hosted file sync, sharing, and collaboration, a full private alternative to consumer cloud drives.

This page describes the Levelrail template for Nextcloud (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.nextcloud.com.

Recommended memory: about 1536 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `nextcloud` | `nextcloud:29.0.4-apache` | 80 | `nextcloud_data -&#62; /var/www/html` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `nextcloud` | `NEXTCLOUD_ADMIN_PASSWORD` | Generated at deploy |
| `nextcloud` | `NEXTCLOUD_ADMIN_USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`nextcloud`): 8080:80.
- Passwords and keys are generated at deploy time (`nextcloud`): NEXTCLOUD_ADMIN_PASSWORD, NEXTCLOUD_ADMIN_USER.
- Stores data in named volumes (`nextcloud`): nextcloud_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Nextcloud with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Nextcloud. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nextcloud --name my-nextcloud
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
