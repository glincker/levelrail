A web-based admin tool for MySQL and MariaDB, built for ad-hoc use against any reachable database.

This page describes the Levelrail template for phpMyAdmin (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.phpmyadmin.net/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `phpmyadmin` | `phpmyadmin:5.2.2` | 80 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `phpmyadmin` | `PMA_ARBITRARY` | Preset in the template |
| `phpmyadmin` | `UPLOAD_LIMIT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy phpMyAdmin with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select phpMyAdmin. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy phpmyadmin --name my-phpmyadmin
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
