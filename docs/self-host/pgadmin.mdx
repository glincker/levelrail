A full-featured web GUI for administering and querying PostgreSQL databases.

This page describes the Levelrail template for pgAdmin (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.pgadmin.org/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `pgadmin` | `dpage/pgadmin4:8.14` | 80 | `pgadmin_data -&#62; /var/lib/pgadmin` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `pgadmin` | `PGADMIN_DEFAULT_EMAIL` | Preset in the template |
| `pgadmin` | `PGADMIN_DEFAULT_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy pgAdmin with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select pgAdmin. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy pgadmin --name my-pgadmin
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
