A headless-browser proxy that solves Cloudflare and DDoS-Guard challenges for other self-hosted tools.

This page describes the Levelrail template for FlareSolverr (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/FlareSolverr/FlareSolverr.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `flaresolverr` | `ghcr.io/flaresolverr/flaresolverr:v3.5.0` | 8191 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `flaresolverr` | `LOG_LEVEL` | Preset in the template |
| `flaresolverr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy FlareSolverr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FlareSolverr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flaresolverr --name my-flaresolverr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
