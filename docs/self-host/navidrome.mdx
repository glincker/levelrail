Stream your own music collection from a Subsonic-compatible server to any device, anywhere.

This page describes the Levelrail template for Navidrome (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.navidrome.org/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `navidrome` | `deluan/navidrome:0.54.1` | 4533 | `navidrome_data -&#62; /data`<br />`navidrome_music -&#62; /music` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `navidrome` | `ND_LOGLEVEL` | Preset in the template |
| `navidrome` | `ND_SCANSCHEDULE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`navidrome`): 4533:4533.
- Stores data in named volumes (`navidrome`): navidrome_data, navidrome_music.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Navidrome with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Navidrome. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy navidrome --name my-navidrome
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
