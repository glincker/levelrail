A portable file server with resumable uploads, a media player, and search, in a single small image.

This page describes the Levelrail template for copyparty (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/9001/copyparty.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `copyparty` | `copyparty/ac:1.20.24` | 3923 | `copyparty_files -&#62; /w`<br />`copyparty_config -&#62; /cfg` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `copyparty` | `ADMIN_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`copyparty`): 3923:3923.
- Passwords and keys are generated at deploy time (`copyparty`): ADMIN_PASSWORD.
- Stores data in named volumes (`copyparty`): copyparty_config, copyparty_files.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy copyparty with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select copyparty. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy copyparty --name my-copyparty
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
