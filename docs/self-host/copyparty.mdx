A portable file server with resumable uploads, a media player, and search, in a single small image.

This page describes the Levelrail template for copyparty (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/9001/copyparty.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `copyparty` | `copyparty/ac:1.20.24` | 3923 | `copyparty_files -&#62; /w`<br />`copyparty_config -&#62; /cfg` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy copyparty with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select copyparty. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get copyparty --output json | jq -r .compose > copyparty.compose.yaml
# edit copyparty.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-copyparty --file copyparty.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
