A GUI for browsing keys, running commands, and profiling performance on any Redis instance.

This page describes the Levelrail template for RedisInsight (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://redis.io/docs/latest/operate/redisinsight/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `redisinsight` | `redis/redisinsight:2.70` | 5540 | `redisinsight_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `redisinsight` | `RI_APP_HOST` | Preset in the template |
| `redisinsight` | `RI_APP_PORT` | Preset in the template |
| `redisinsight` | `RI_ENCRYPTION_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`redisinsight`): 5540:5540.
- Passwords and keys are generated at deploy time (`redisinsight`): RI_ENCRYPTION_KEY.
- Stores data in named volumes (`redisinsight`): redisinsight_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy RedisInsight with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select RedisInsight. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redisinsight --name my-redisinsight
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
