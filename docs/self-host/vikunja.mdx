An open-source task and project manager for teams that outgrew sticky notes.

This page describes the Levelrail template for Vikunja (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://vikunja.io/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `vikunja_db_data -&#62; /var/lib/postgresql/data` |
| `vikunja` | `vikunja/vikunja:0.24.1` | 3456 | `vikunja_data -&#62; /app/vikunja/files` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `vikunja` | `VIKUNJA_DATABASE_DATABASE` | Preset in the template |
| `vikunja` | `VIKUNJA_DATABASE_HOST` | Preset in the template |
| `vikunja` | `VIKUNJA_DATABASE_PASSWORD` | Generated at deploy |
| `vikunja` | `VIKUNJA_DATABASE_TYPE` | Preset in the template |
| `vikunja` | `VIKUNJA_DATABASE_USER` | Preset in the template |
| `vikunja` | `VIKUNJA_SERVICE_JWTSECRET` | Generated at deploy |
| `vikunja` | `VIKUNJA_SERVICE_PUBLICURL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Vikunja with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Vikunja. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy vikunja --name my-vikunja
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
