Polls a UniFi controller and exposes network, client and device statistics as Prometheus metrics. The install form carries up.conf as an editable file and asks for a read-only controller login.

This page describes the Levelrail template for UnPoller (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://unpoller.com/docs/install/docker.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `unpoller` | `ghcr.io/unpoller/unpoller:v5.9.5` | 9130 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- You must provide one or more secrets before it can deploy (`unpoller`): /etc/unpoller/up.conf.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy UnPoller with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select UnPoller. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get unpoller --output json | jq -r .compose > unpoller.compose.yaml
# edit unpoller.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-unpoller --file unpoller.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
