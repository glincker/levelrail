Continuous code quality and security analysis across 30+ languages, with quality gates for every pull request.

This page describes the Levelrail template for SonarQube Community (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.sonarsource.com/sonarqube-community-build.

Recommended memory: about 3072 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `sonarqube_db_data -&#62; /var/lib/postgresql/data` |
| `sonarqube` | `sonarqube:community` | 9000 | `sonarqube_data -&#62; /opt/sonarqube/data`<br />`sonarqube_extensions -&#62; /opt/sonarqube/extensions`<br />`sonarqube_logs -&#62; /opt/sonarqube/logs` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `sonarqube` | `SONAR_JDBC_PASSWORD` | Generated at deploy |
| `sonarqube` | `SONAR_JDBC_URL` | Preset in the template |
| `sonarqube` | `SONAR_JDBC_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`sonarqube`): 9000:9000.
- Passwords and keys are generated at deploy time (`db`, `sonarqube`): POSTGRES_PASSWORD, SONAR_JDBC_PASSWORD.
- Stores data in named volumes (`db`, `sonarqube`): sonarqube_data, sonarqube_db_data, sonarqube_extensions, sonarqube_logs.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy SonarQube Community with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SonarQube Community. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sonarqube --name my-sonarqube
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
