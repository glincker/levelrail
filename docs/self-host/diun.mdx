Watches your running containers and notifies you the moment a new image tag is published.

This page describes the Levelrail template for Diun (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://crazymax.dev/diun/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `diun` | `crazymax/diun:4.29.0` | none | `diun_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `diun` | `DIUN_PROVIDERS_DOCKER` | Preset in the template |
| `diun` | `DIUN_PROVIDERS_DOCKER_WATCHBYDEFAULT` | Preset in the template |
| `diun` | `DIUN_WATCH_SCHEDULE` | Preset in the template |
| `diun` | `DIUN_WATCH_WORKERS` | Preset in the template |
| `diun` | `LOG_LEVEL` | Preset in the template |
| `diun` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Diun with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Diun. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy diun --name my-diun
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
