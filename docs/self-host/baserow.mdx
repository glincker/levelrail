A no-code database and spreadsheet hybrid you can build internal tools and apps on top of.

This page describes the Levelrail template for Baserow (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://baserow.io/docs/installation%2Finstall-with-docker.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `baserow` | `baserow/baserow:2.3.3` | 80 | `baserow_data -&#62; /baserow/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `baserow` | `BASEROW_PUBLIC_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Baserow with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Baserow. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy baserow --name my-baserow
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
