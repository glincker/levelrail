Scan, index, and archive your paper documents into a searchable digital library.

This page describes the Levelrail template for Paperless-ngx (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.paperless-ngx.com.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `paperless` | `paperlessngx/paperless-ngx:2.14.5` | 8000 | `paperless_data -&#62; /usr/src/paperless/data`<br />`paperless_media -&#62; /usr/src/paperless/media` |
| `redis` | `redis:7.4` | none | `paperless_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `paperless` | `PAPERLESS_REDIS` | Preset in the template |
| `paperless` | `PAPERLESS_SECRET_KEY` | Generated at deploy |
| `paperless` | `PAPERLESS_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Paperless-ngx with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Paperless-ngx. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy paperless-ngx --name my-paperless-ngx
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
