A self-hosted bookmark, note, and read-it-later manager with full-text search and tagging.

This page describes the Levelrail template for Karakeep (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.karakeep.app.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `karakeep` | `ghcr.io/karakeep-app/karakeep:0.33.2` | 3000 | `karakeep_data -&#62; /data` |
| `meilisearch` | `getmeili/meilisearch:v1.15.0` | none | `karakeep_meili_data -&#62; /meili_data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `karakeep` | `DATA_DIR` | Preset in the template |
| `karakeep` | `MEILI_ADDR` | Preset in the template |
| `karakeep` | `MEILI_MASTER_KEY` | Generated at deploy |
| `karakeep` | `NEXTAUTH_SECRET` | Generated at deploy |
| `karakeep` | `NEXTAUTH_URL` | Preset in the template |
| `meilisearch` | `MEILI_MASTER_KEY` | Generated at deploy |
| `meilisearch` | `MEILI_NO_ANALYTICS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`karakeep`): 3000:3000.
- Passwords and keys are generated at deploy time (`karakeep`, `meilisearch`): MEILI_MASTER_KEY, MEILI_MASTER_KEY, NEXTAUTH_SECRET.
- No health check, so a deploy is judged by the process starting (`meilisearch`).
- Stores data in named volumes (`karakeep`, `meilisearch`): karakeep_data, karakeep_meili_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Karakeep with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Karakeep. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy karakeep --name my-karakeep
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
