A self-hosted uptime monitor with a clean dashboard for HTTP, TCP, DNS, and ping checks.

This page describes the Levelrail template for Uptime Kuma (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/louislam/uptime-kuma/wiki.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `kuma` | `louislam/uptime-kuma:1.23.13` | 3001 | `data -&#62; /app/data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Uptime Kuma with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Uptime Kuma. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy uptime-kuma --name my-uptime-kuma
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
