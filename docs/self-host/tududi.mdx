A self-hosted task and project manager with areas, notes and recurring tasks.

This page describes the Levelrail template for Tududi (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/chrisvel/tududi.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `tududi_db -&#62; /var/lib/postgresql/data` |
| `tududi` | `chrisvel/tududi:2.1.5` | 3002 | `tududi_uploads -&#62; /app/backend/uploads` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `tududi` | `DATABASE_URL` | Generated at deploy |
| `tududi` | `TUDUDI_ALLOWED_ORIGINS` | Preset in the template |
| `tududi` | `TUDUDI_SESSION_SECRET` | Generated at deploy |
| `tududi` | `TUDUDI_USER_EMAIL` | Preset in the template |
| `tududi` | `TUDUDI_USER_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `tududi`): DATABASE_URL, TUDUDI_SESSION_SECRET, TUDUDI_USER_PASSWORD, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `tududi`): tududi_db, tududi_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Tududi with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Tududi. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy tududi --name my-tududi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
