A privacy-respecting metasearch engine that aggregates results from dozens of search services.

This page describes the Levelrail template for SearXNG (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.searxng.org.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `redis` | `redis:7-alpine` | none | `searxng_redis_data -&#62; /data` |
| `searxng` | `searxng/searxng:2026.9.23-3cd69d30e` | 8080 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `searxng` | `SEARXNG_REDIS_URL` | Preset in the template |
| `searxng` | `SEARXNG_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`searxng`): 8080:8080.
- Passwords and keys are generated at deploy time (`searxng`): SEARXNG_SECRET.
- No health check, so a deploy is judged by the process starting (`redis`).
- Stores data in named volumes (`redis`): searxng_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy SearXNG with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SearXNG. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy searxng --name my-searxng
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
