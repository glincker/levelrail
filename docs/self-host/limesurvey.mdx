A mature, self-hosted online survey tool for building and analyzing anonymous surveys.

This page describes the Levelrail template for LimeSurvey (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.limesurvey.org/manual/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `limesurvey` | `adamzammit/limesurvey:latest` | 80 | `limesurvey_upload_data -&#62; /var/www/html/upload`<br />`limesurvey_config_data -&#62; /var/www/html/application/config` |
| `mariadb` | `mariadb:11` | none | `limesurvey_mariadb_data -&#62; /var/lib/mysql` |
| `redis` | `redis:7-alpine` | none | none |

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`limesurvey`): adamzammit/limesurvey:latest.
- Publishes ports directly on the host (`limesurvey`): 8080:80.
- Passwords and keys are generated at deploy time (`limesurvey`, `mariadb`): LIMESURVEY_ADMIN_PASSWORD, LIMESURVEY_DB_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`limesurvey`, `mariadb`): limesurvey_config_data, limesurvey_mariadb_data, limesurvey_upload_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LimeSurvey with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LimeSurvey. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy limesurvey --name my-limesurvey
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
