A free and open machine translation API that runs entirely on your own hardware.

This page describes the Levelrail template for LibreTranslate (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/LibreTranslate/LibreTranslate.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `libretranslate` | `libretranslate/libretranslate:v1.9.6` | 5000 | `libretranslate_data -&#62; /home/libretranslate/.local` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy LibreTranslate with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LibreTranslate. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy libretranslate --name my-libretranslate
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
