A distributed file and object store with an S3 gateway, built for billions of small files.

This page describes the Levelrail template for SeaweedFS (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/seaweedfs/seaweedfs/wiki.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `seaweedfs` | `chrislusf/seaweedfs:3.99` | 9333, 8888, 8333 | `seaweedfs_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy SeaweedFS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SeaweedFS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy seaweedfs --name my-seaweedfs
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
