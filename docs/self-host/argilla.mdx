A collaboration tool for labelling and curating datasets for language model work.

This page describes the Levelrail template for Argilla (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.argilla.io/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `argilla` | `argilla/argilla-server:v2.8.0` | 6900 | `argilla_data -&#62; /var/lib/argilla` |
| `db` | `postgres:16-alpine` | none | `db_data -&#62; /var/lib/postgresql/data` |
| `elasticsearch` | `docker.elastic.co/elasticsearch/elasticsearch:8.12.2` | none | `elastic_data -&#62; /usr/share/elasticsearch/data` |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |
| `worker` | `argilla/argilla-server:v2.8.0` | none | `argilla_data -&#62; /var/lib/argilla` |

## Security and requirements

Level: **Standard**.

What this template needs:

- You must provide one or more secrets before it can deploy (`redis`): command[2].
- Passwords and keys are generated at deploy time (`argilla`, `db`, `worker`): API_KEY, ARGILLA_DATABASE_URL, ARGILLA_REDIS_URL, PASSWORD, ARGILLA_DATABASE_URL, ARGILLA_REDIS_URL, POSTGRES_PASSWORD.
- Stores data in named volumes (`argilla`, `db`, `elasticsearch`, `redis`, `worker`): argilla_data, db_data, elastic_data, redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy Argilla with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Argilla. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get argilla --output json | jq -r .compose > argilla.compose.yaml
# edit argilla.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-argilla --file argilla.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
