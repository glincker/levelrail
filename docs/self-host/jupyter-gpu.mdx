JupyterLab with a CUDA-ready data science stack for training and experimenting with models.

This page describes the Levelrail template for Jupyter GPU Notebook (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/iot-salzburg/gpu-jupyter.

Recommended memory: about 4096 MiB.

<Warning>This template reserves an NVIDIA GPU, so it needs a node with a GPU and the NVIDIA container runtime.</Warning>

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `jupyter` | `cschranz/gpu-jupyter:v1.11_cuda-13.0_ubuntu-24.04_python-only` | 8888 | `jupyter_work -&#62; /home/jovyan/work` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `jupyter` | `JUPYTER_TOKEN` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`jupyter`): 8888:8888.
- Passwords and keys are generated at deploy time (`jupyter`): JUPYTER_TOKEN.
- Stores data in named volumes (`jupyter`): jupyter_work.
- Reserves an NVIDIA GPU (`jupyter`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Jupyter GPU Notebook with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Jupyter GPU Notebook. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy jupyter-gpu --name my-jupyter-gpu
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
