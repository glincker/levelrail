A minimalist, fast RSS/Atom feed reader with no bloat and a keyboard-driven UI.

This page describes the Levelrail template for Miniflux (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://miniflux.app/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `miniflux_db_data -&#62; /var/lib/postgresql/data` |
| `miniflux` | `ghcr.io/miniflux/miniflux:2.2.4` | 8080 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `miniflux` | `ADMIN_PASSWORD` | Generated at deploy |
| `miniflux` | `ADMIN_USERNAME` | Generated at deploy |
| `miniflux` | `DATABASE_URL` | Generated at deploy |
| `miniflux` | `RUN_MIGRATIONS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Miniflux with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Miniflux. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy miniflux --name my-miniflux
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
