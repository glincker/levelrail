Basecamp's open-source group chat app: rooms, direct messages, and file sharing, self-hosted as one container.

This page describes the Levelrail template for Campfire (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/basecamp/once-campfire.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `campfire` | `ghcr.io/basecamp/once-campfire:main` | 80 | `campfire_storage -&#62; /rails/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `campfire` | `DISABLE_SSL` | Preset in the template |
| `campfire` | `SECRET_KEY_BASE` | Generated at deploy |
| `campfire` | `SKIP_TELEMETRY` | Preset in the template |
| `campfire` | `SSL_DOMAIN` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Campfire with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Campfire. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy campfire --name my-campfire
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
