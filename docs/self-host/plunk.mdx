An email platform for transactional mail, marketing campaigns and automations that sends through your own AWS SES account.

This page describes the Levelrail template for Plunk (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.useplunk.com/self-hosting/introduction.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `plunk` | `driaug/plunk:1.3.6` | 3000 | none |
| `redis` | `redis:7.4-alpine` | none | `redis -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `plunk` | `API_URI` | Preset in the template |
| `plunk` | `APP_URI` | Preset in the template |
| `plunk` | `AWS_ACCESS_KEY_ID` | You must provide |
| `plunk` | `AWS_REGION` | You must provide |
| `plunk` | `AWS_SECRET_ACCESS_KEY` | You must provide |
| `plunk` | `AWS_SES_CONFIGURATION_SET` | You must provide |
| `plunk` | `DATABASE_URL` | Generated at deploy |
| `plunk` | `DISABLE_SIGNUPS` | Preset in the template |
| `plunk` | `JWT_SECRET` | Generated at deploy |
| `plunk` | `NEXT_PUBLIC_API_URI` | Preset in the template |
| `plunk` | `NODE_OPTIONS` | Preset in the template |
| `plunk` | `REDIS_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy Plunk with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Plunk. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get plunk --output json | jq -r .compose > plunk.compose.yaml
# edit plunk.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-plunk --file plunk.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
