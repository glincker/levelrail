A media server for comics, manga, and digital books with a clean reading interface.

This page describes the Levelrail template for Komga (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://komga.org/docs/installation/docker.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `komga` | `gotson/komga:1.26.3` | 25600 | `komga_config -&#62; /config`<br />`komga_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Komga with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Komga. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy komga --name my-komga
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
