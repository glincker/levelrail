A self-hosted single sign-on and identity provider with OIDC, passkeys, user invitations and self-service profiles, backed by Postgres. Create the first admin from the invitation link printed in the container log.

This page describes the Levelrail template for VoidAuth (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://voidauth.app/.

Recommended memory: about 384 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17.11-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `voidauth` | `voidauth/voidauth:1.19.1` | 3000 | `config -&#62; /app/config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `voidauth` | `APP_URL` | Preset in the template |
| `voidauth` | `DB_ADAPTER` | Preset in the template |
| `voidauth` | `DB_HOST` | Preset in the template |
| `voidauth` | `DB_PASSWORD` | Generated at deploy |
| `voidauth` | `STORAGE_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `voidauth`): DB_PASSWORD, STORAGE_KEY, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `voidauth`): config, pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy VoidAuth with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select VoidAuth. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy voidauth --name my-voidauth
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
