A self-hosted time tracking tool for freelancers and teams, with invoicing and reporting.

This page describes the Levelrail template for Kimai (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.kimai.org/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mysql:8` | none | `kimai_db_data -&#62; /var/lib/mysql` |
| `kimai` | `kimai/kimai2:apache` | 8001 | `kimai_data -&#62; /opt/kimai/var` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `kimai` | `ADMINMAIL` | Preset in the template |
| `kimai` | `ADMINPASS` | Generated at deploy |
| `kimai` | `DATABASE_URL` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Kimai with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Kimai. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy kimai --name my-kimai
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
