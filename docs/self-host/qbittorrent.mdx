A free, self-hosted BitTorrent client with a full web UI for remote download management.

This page describes the Levelrail template for qBittorrent (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/qbittorrent/qBittorrent/wiki.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `qbittorrent` | `lscr.io/linuxserver/qbittorrent:5.0.3` | 8080, 6881 | `qbittorrent_config -&#62; /config`<br />`qbittorrent_downloads -&#62; /downloads` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy qBittorrent with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select qBittorrent. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy qbittorrent --name my-qbittorrent
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
