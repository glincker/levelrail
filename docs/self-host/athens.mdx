A Go module proxy that caches modules from upstream so builds stay fast and repeatable. Point GOPROXY at it from your CI or developer machines.

This page describes the Levelrail template for Athens (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gomods.io/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `athens` | `gomods/athens:v0.20.0` | 3000 | `storage -&#62; /var/lib/athens` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `athens` | `ATHENS_DISK_STORAGE_ROOT` | Preset in the template |
| `athens` | `ATHENS_PORT` | Preset in the template |
| `athens` | `ATHENS_STORAGE_TYPE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`athens`): storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Athens with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Athens. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy athens --name my-athens
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
