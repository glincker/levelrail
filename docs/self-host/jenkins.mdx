The long-running automation server for building, testing, and deploying with thousands of plugins.

This page describes the Levelrail template for Jenkins (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.jenkins.io/doc.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `jenkins` | `jenkins/jenkins:2.583` | 8080, 50000 | `jenkins_home -&#62; /var/jenkins_home` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Jenkins with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Jenkins. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy jenkins --name my-jenkins
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
