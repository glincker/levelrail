A simple web UI for browsing, uploading, and sharing files from your own storage.

This page describes the Levelrail template for File Browser (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://filebrowser.org.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `filebrowser` | `filebrowser/filebrowser:v2.31.2` | 80 | `filebrowser_data -&#62; /srv`<br />`filebrowser_db -&#62; /database` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy File Browser with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select File Browser. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy filebrowser --name my-filebrowser
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
