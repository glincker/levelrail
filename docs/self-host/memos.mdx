A lightweight, privacy-first note-taking service for jotting down quick thoughts.

This page describes the Levelrail template for Memos (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.usememos.com/docs.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `memos` | `neosmemo/memos:stable` | 5230 | `memos_data -&#62; /var/opt/memos` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Memos with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Memos. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy memos --name my-memos
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
