A modern web UI for running Ansible, Terraform, and shell tasks with schedules, history, and access control.

This page describes the Levelrail template for Semaphore UI (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.semaphoreui.com.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `semaphore` | `semaphoreui/semaphore:v2.19.14` | 3000 | `semaphore_data -&#62; /var/lib/semaphore`<br />`semaphore_config -&#62; /etc/semaphore` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `semaphore` | `SEMAPHORE_ACCESS_KEY_ENCRYPTION` | Generated at deploy |
| `semaphore` | `SEMAPHORE_ADMIN` | Preset in the template |
| `semaphore` | `SEMAPHORE_ADMIN_EMAIL` | Preset in the template |
| `semaphore` | `SEMAPHORE_ADMIN_NAME` | Preset in the template |
| `semaphore` | `SEMAPHORE_ADMIN_PASSWORD` | Generated at deploy |
| `semaphore` | `SEMAPHORE_DB_DIALECT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Semaphore UI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Semaphore UI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy semaphore --name my-semaphore
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
