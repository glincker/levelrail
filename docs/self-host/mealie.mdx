A self-hosted recipe manager and meal planner with a clean web UI and API.

This page describes the Levelrail template for Mealie (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.mealie.io.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mealie` | `ghcr.io/mealie-recipes/mealie:v3.28.0` | 9000 | `mealie_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mealie` | `BASE_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Mealie with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Mealie. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mealie --name my-mealie
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
