Source-of-truth IPAM and DCIM for tracking IP space, racks, devices, and cabling.

This page describes the Levelrail template for NetBox (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/netbox-community/netbox-docker.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17-alpine` | none | `netbox_db_data -&#62; /var/lib/postgresql/data` |
| `netbox` | `netboxcommunity/netbox:v4.6-5.0.2` | 8080 | `netbox_media -&#62; /opt/netbox/netbox/media`<br />`netbox_reports -&#62; /opt/netbox/netbox/reports`<br />`netbox_scripts -&#62; /opt/netbox/netbox/scripts` |
| `redis` | `redis:7-alpine` | none | `netbox_redis_data -&#62; /data` |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy NetBox with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select NetBox. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy netbox --name my-netbox
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
