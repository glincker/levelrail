A documentation site generator with a searchable Material theme. This serves your Markdown files live; put them in the docs volume and edit the generated config to set the site name and navigation.

This page describes the Levelrail template for Material for MkDocs (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://squidfunk.github.io/mkdocs-material/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mkdocs-material` | `squidfunk/mkdocs-material:9.8.0` | 8000 | `docs -&#62; /docs/docs` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`mkdocs-material`): docs.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Material for MkDocs with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Material for MkDocs. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mkdocs-material --name my-mkdocs-material
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
