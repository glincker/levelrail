Network-wide ad and tracker blocking with a DNS server and a friendly admin dashboard.

This page describes the Levelrail template for AdGuard Home (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/AdguardTeam/AdGuardHome/wiki/Docker.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `adguard` | `adguard/adguardhome:v0.107.55` | 3000 | `adguard_work -&#62; /opt/adguardhome/work`<br />`adguard_conf -&#62; /opt/adguardhome/conf` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy AdGuard Home with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select AdGuard Home. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy adguard-home --name my-adguard-home
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
