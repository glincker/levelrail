A privacy-friendly, open-source web analytics platform that never tracks individual visitors.

This page describes the Levelrail template for GoatCounter (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.goatcounter.com/help.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `goatcounter` | `arp242/goatcounter:2.7` | 8080 | `goatcounter_data -&#62; /home/goatcounter/goatcounter-data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy GoatCounter with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GoatCounter. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy goatcounter --name my-goatcounter
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
