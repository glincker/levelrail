S3-compatible object storage you run yourself, with a built-in web console.

This page describes the Levelrail template for MinIO (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://min.io/docs/minio/linux/index.html.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `minio` | `quay.io/minio/aistor/minio:RELEASE.2026-09-19T17-05-25Z.hotfix.4ef74f03d6f2` | 9000, 9001 | `minio_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `minio` | `MINIO_ROOT_PASSWORD` | Generated at deploy |
| `minio` | `MINIO_ROOT_USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy MinIO with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MinIO. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy minio --name my-minio
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
