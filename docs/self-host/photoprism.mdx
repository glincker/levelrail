An AI-powered photo management app that indexes and organizes your library as you own it.

This page describes the Levelrail template for PhotoPrism (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.photoprism.app/getting-started/docker-compose/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `photoprism` | `photoprism/photoprism:260728` | 2342 | `photoprism_originals -&#62; /photoprism/originals`<br />`photoprism_storage -&#62; /photoprism/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `photoprism` | `PHOTOPRISM_ADMIN_PASSWORD` | Generated at deploy |
| `photoprism` | `PHOTOPRISM_DISABLE_TLS` | Preset in the template |
| `photoprism` | `PHOTOPRISM_SITE_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`photoprism`): 2342:2342.
- Passwords and keys are generated at deploy time (`photoprism`): PHOTOPRISM_ADMIN_PASSWORD.
- Stores data in named volumes (`photoprism`): photoprism_originals, photoprism_storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy PhotoPrism with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select PhotoPrism. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy photoprism --name my-photoprism
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
