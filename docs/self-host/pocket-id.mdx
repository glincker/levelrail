A simple, secure OIDC provider that authenticates with passkeys instead of passwords.

This page describes the Levelrail template for Pocket ID (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://pocket-id.org/docs/setup/installation.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `pocket-id` | `ghcr.io/pocket-id/pocket-id:v1.13` | 1411 | `pocket_id_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `pocket-id` | `APP_URL` | Preset in the template |
| `pocket-id` | `TRUST_PROXY` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`pocket-id`): 1411:1411.
- Stores data in named volumes (`pocket-id`): pocket_id_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Pocket ID with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Pocket ID. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy pocket-id --name my-pocket-id
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
