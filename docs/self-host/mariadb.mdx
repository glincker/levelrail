The MariaDB database server on the official image, with a persistent volume, generated root and user passwords, and an application database. It is not published on the host, so reach it from other services in this project at mariadb:3306.

This page describes the Levelrail template for MariaDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://mariadb.com/kb/en/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mariadb` | `mariadb:11.4.13` | 3306 | `mariadb_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mariadb` | `MARIADB_DATABASE` | Preset in the template |
| `mariadb` | `MARIADB_PASSWORD` | Generated at deploy |
| `mariadb` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MARIADB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`mariadb`): MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- Stores data in named volumes (`mariadb`): mariadb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MariaDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MariaDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mariadb --name my-mariadb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
