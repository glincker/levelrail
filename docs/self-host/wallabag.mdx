A read-it-later app that saves web articles in a clean, distraction-free format.

This page describes the Levelrail template for Wallabag (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://doc.wallabag.org.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `wallabag` | `wallabag/wallabag:2.6.14` | 80 | `wallabag_data -&#62; /var/www/wallabag/data`<br />`wallabag_images -&#62; /var/www/wallabag/web/assets/images` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `wallabag` | `SYMFONY__ENV__DOMAIN_NAME` | Preset in the template |
| `wallabag` | `SYMFONY__ENV__SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Wallabag with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Wallabag. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy wallabag --name my-wallabag
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
