A localization management platform where developers and translators work in one shared UI.

This page describes the Levelrail template for Tolgee (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://tolgee.io/platform.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `tolgee_db_data -&#62; /var/lib/postgresql/data` |
| `tolgee` | `tolgee/tolgee:v3.224.7` | 8080 | `tolgee_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Generated at deploy |
| `tolgee` | `SPRING_DATASOURCE_PASSWORD` | Generated at deploy |
| `tolgee` | `SPRING_DATASOURCE_URL` | Preset in the template |
| `tolgee` | `SPRING_DATASOURCE_USERNAME` | Generated at deploy |
| `tolgee` | `TOLGEE_AUTHENTICATION_ENABLED` | Preset in the template |
| `tolgee` | `TOLGEE_AUTHENTICATION_INITIAL_PASSWORD` | Generated at deploy |
| `tolgee` | `TOLGEE_AUTHENTICATION_INITIAL_USERNAME` | Preset in the template |
| `tolgee` | `TOLGEE_AUTHENTICATION_JWT_SECRET` | Generated at deploy |
| `tolgee` | `TOLGEE_POSTGRES_AUTOSTART_ENABLED` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Tolgee with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Tolgee. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy tolgee --name my-tolgee
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
