A companion for Sonarr, Radarr and your download client that removes stalled, failed and malicious downloads and cleans up leftovers. GPL-3.0 licensed. Open the web UI and add your arr apps and download client under Settings.

This page describes the Levelrail template for Cleanuparr (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://cleanuparr.github.io/Cleanuparr/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cleanuparr` | `ghcr.io/cleanuparr/cleanuparr:2.10.12` | 11011 | `config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `cleanuparr` | `PGID` | Preset in the template |
| `cleanuparr` | `PORT` | Preset in the template |
| `cleanuparr` | `PUID` | Preset in the template |
| `cleanuparr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`cleanuparr`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Cleanuparr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Cleanuparr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy cleanuparr --name my-cleanuparr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
