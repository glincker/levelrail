An open-source survey and experience-management platform you run on your own infrastructure.

This page describes the Levelrail template for Formbricks (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://formbricks.com/docs/self-hosting/setup/docker.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `pgvector/pgvector:pg16` | none | `formbricks_db_data -&#62; /var/lib/postgresql/data` |
| `formbricks` | `ghcr.io/formbricks/formbricks:4.5.0` | 3000 | `formbricks_uploads -&#62; /apps/web/uploads` |
| `redis` | `redis:7-alpine` | none | `formbricks_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `formbricks` | `CRON_SECRET` | Generated at deploy |
| `formbricks` | `DATABASE_URL` | Generated at deploy |
| `formbricks` | `ENCRYPTION_KEY` | Generated at deploy |
| `formbricks` | `NEXTAUTH_SECRET` | Generated at deploy |
| `formbricks` | `NEXTAUTH_URL` | Preset in the template |
| `formbricks` | `REDIS_URL` | Preset in the template |
| `formbricks` | `WEBAPP_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Formbricks with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Formbricks. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy formbricks --name my-formbricks
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
