Test and compare prompts, models and agents with a local web UI for browsing evaluation results. Runs the viewer with results stored on a volume.

This page describes the Levelrail template for Promptfoo (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.promptfoo.dev/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `promptfoo` | `ghcr.io/promptfoo/promptfoo:0.125.1` | 3000 | `data -&#62; /home/promptfoo/.promptfoo` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`promptfoo`).
- Stores data in named volumes (`promptfoo`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Promptfoo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Promptfoo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy promptfoo --name my-promptfoo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
