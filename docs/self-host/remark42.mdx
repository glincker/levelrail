A privacy friendly comment engine for blogs and static sites, with social login and anonymous comments. Comments are stored in a file database on a volume.

This page describes the Levelrail template for Remark42 (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/umputun/remark42.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `remark42` | `umputun/remark42:v1.18.0` | 8080 | `data -&#62; /srv/var` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `remark42` | `AUTH_ANON` | Preset in the template |
| `remark42` | `BACKUP_PATH` | Preset in the template |
| `remark42` | `REMARK_URL` | Preset in the template |
| `remark42` | `SECRET` | Generated at deploy |
| `remark42` | `SITE` | Preset in the template |
| `remark42` | `STORE_BOLT_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`remark42`): SECRET.
- Stores data in named volumes (`remark42`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Remark42 with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Remark42. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy remark42 --name my-remark42
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
