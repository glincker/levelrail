A complete DevOps platform for source control, code review, issues, and CI/CD in one place.

This page describes the Levelrail template for GitLab CE (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gitlab.com/install/docker/installation/.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gitlab` | `gitlab/gitlab-ce:19.3.1-ce.0` | 80 | `gitlab_config -&#62; /etc/gitlab`<br />`gitlab_logs -&#62; /var/log/gitlab`<br />`gitlab_data -&#62; /var/opt/gitlab` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `gitlab` | `GITLAB_OMNIBUS_CONFIG` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`gitlab`): 80:80.
- Stores data in named volumes (`gitlab`): gitlab_config, gitlab_data, gitlab_logs.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy GitLab CE with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GitLab CE. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gitlab-ce --name my-gitlab-ce
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
