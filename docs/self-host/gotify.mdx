A simple push notification server with a REST API and web UI, for sending messages to your devices.

This page describes the Levelrail template for Gotify (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://gotify.net/docs/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gotify` | `gotify/server:2.6.1` | 80 | `gotify_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `gotify` | `GOTIFY_DEFAULTUSER_NAME` | Preset in the template |
| `gotify` | `GOTIFY_DEFAULTUSER_PASS` | Generated at deploy |
| `gotify` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Gotify with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Gotify. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gotify --name my-gotify
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
