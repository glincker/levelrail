A tidy web front end for yt-dlp: paste a link, pick a format, and download video or audio.

This page describes the Levelrail template for MeTube (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/alexta69/metube.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `metube` | `ghcr.io/alexta69/metube:latest` | 8081 | `metube_downloads -&#62; /downloads` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy MeTube with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MeTube. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy metube --name my-metube
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
