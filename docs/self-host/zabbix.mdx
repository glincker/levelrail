Enterprise-grade network, server, and application monitoring with alerting and trend graphs.

This page describes the Levelrail template for Zabbix (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.zabbix.com/documentation/current/en/manual/installation/containers.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `zabbix_db_data -&#62; /var/lib/postgresql/data` |
| `zabbix-server` | `zabbix/zabbix-server-pgsql:alpine-7.4-latest` | none | `zabbix_server_data -&#62; /var/lib/zabbix` |
| `zabbix-web` | `zabbix/zabbix-web-nginx-pgsql:alpine-7.4-latest` | 8080 | none |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`zabbix-web`): 8080:8080.
- Passwords and keys are generated at deploy time (`db`, `zabbix-server`, `zabbix-web`): POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`zabbix-server`).
- Stores data in named volumes (`db`, `zabbix-server`): zabbix_db_data, zabbix_server_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Zabbix with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Zabbix. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy zabbix --name my-zabbix
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
