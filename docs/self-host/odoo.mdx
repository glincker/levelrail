An all-in-one business suite covering CRM, sales, inventory, accounting, and a website builder.

This page describes the Levelrail template for Odoo (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.odoo.com/documentation.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `odoo_db_data -&#62; /var/lib/postgresql/data` |
| `odoo` | `odoo:18` | 8069 | `odoo_web_data -&#62; /var/lib/odoo`<br />`odoo_addons -&#62; /mnt/extra-addons` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `odoo` | `HOST` | Preset in the template |
| `odoo` | `PASSWORD` | Generated at deploy |
| `odoo` | `USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Odoo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Odoo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy odoo --name my-odoo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
