A workflow automation tool that connects apps with triggers and actions.

This page describes the Levelrail template for Automatisch (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://automatisch.io/docs.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `automatisch` | `automatischio/automatisch:0.15.0` | 3000 | `storage -&#62; /automatisch/storage` |
| `db` | `postgres:16-alpine` | none | `postgres_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |
| `worker` | `automatischio/automatisch:0.15.0` | none | `storage -&#62; /automatisch/storage` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`automatisch`, `db`, `redis`, `worker`): APP_SECRET_KEY, ENCRYPTION_KEY, POSTGRES_PASSWORD, REDIS_PASSWORD, WEBHOOK_SECRET_KEY, POSTGRES_PASSWORD, REDIS_PASSWORD.
- Stores data in named volumes (`automatisch`, `db`, `redis`, `worker`): postgres_data, redis_data, storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Automatisch with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Automatisch. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy automatisch --name my-automatisch
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
