A vector similarity search engine for storing, searching, and managing embeddings.

This page describes the Levelrail template for Qdrant (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://qdrant.tech/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `qdrant` | `qdrant/qdrant:v1.12.4` | 6333 | `qdrant_data -&#62; /qdrant/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `qdrant` | `QDRANT__SERVICE__API_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Qdrant with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Qdrant. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy qdrant --name my-qdrant
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
