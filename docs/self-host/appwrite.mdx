An open-source backend-as-a-service with auth, databases, storage, and functions behind one API.

This page describes the Levelrail template for Appwrite (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://appwrite.io/docs.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `appwrite` | `appwrite/appwrite:1.7.4` | 80 | `appwrite_uploads -&#62; /storage/uploads`<br />`appwrite_cache -&#62; /storage/cache`<br />`appwrite_config -&#62; /storage/config`<br />`appwrite_certificates -&#62; /storage/certificates` |
| `appwrite-console` | `appwrite/console:6.1.28` | 80 | none |
| `db` | `mariadb:10.11` | none | `appwrite_db_data -&#62; /var/lib/mysql` |
| `redis` | `redis:7.2.4-alpine` | none | `appwrite_redis_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`appwrite`, `appwrite-console`): 8081:80, 80:80.
- Passwords and keys are generated at deploy time (`appwrite`, `db`): MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD, MYSQL_USER, _APP_DB_PASS, _APP_DB_USER, _APP_OPENSSL_KEY_V1.
- No health check, so a deploy is judged by the process starting (`redis`).
- Stores data in named volumes (`appwrite`, `db`, `redis`): appwrite_cache, appwrite_certificates, appwrite_config, appwrite_db_data, appwrite_redis_data, appwrite_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Appwrite with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Appwrite. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy appwrite --name my-appwrite
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
