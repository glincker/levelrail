A self-hosted feature flag and experimentation platform with a built-in UI and REST/gRPC APIs.

This page describes the Levelrail template for Flipt (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.flipt.io/docs.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `flipt` | `docker.flipt.io/flipt/flipt:v1.60.0` | 8080 | `flipt_data -&#62; /var/opt/flipt` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Flipt with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Flipt. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flipt --name my-flipt
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
