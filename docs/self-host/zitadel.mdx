An identity and access management server with single sign on and OIDC.

This page describes the Levelrail template for ZITADEL (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://zitadel.com/docs.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17-alpine` | none | `zitadel_db_data -&#62; /var/lib/postgresql/data` |
| `zitadel` | `ghcr.io/zitadel/zitadel:v4.16.0` | 8080 | none |

## Security and requirements

Level: **Standard**.

What this template needs:

- You must provide one or more secrets before it can deploy (`zitadel`): command[2].
- Passwords and keys are generated at deploy time (`db`, `zitadel`): POSTGRES_PASSWORD, ZITADEL_DATABASE_POSTGRES_ADMIN_PASSWORD, ZITADEL_DATABASE_POSTGRES_USER_PASSWORD.
- Stores data in named volumes (`db`): zitadel_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy ZITADEL with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ZITADEL. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get zitadel --output json | jq -r .compose > zitadel.compose.yaml
# edit zitadel.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-zitadel --file zitadel.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
