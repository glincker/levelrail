Share a password or API key through a link that self-destructs after the first view, backed by Redis.

This page describes the Levelrail template for One-Time Secret (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.onetimesecret.com.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `app` | `onetimesecret/onetimesecret:v0.26.14` | 3000 | none |
| `redis` | `redis:7-alpine` | none | `redis -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `app` | `AUTH_AUTOVERIFY` | Preset in the template |
| `app` | `AUTH_SIGNUP` | Preset in the template |
| `app` | `COLONEL` | Preset in the template |
| `app` | `HOST` | Preset in the template |
| `app` | `RACK_ENV` | Preset in the template |
| `app` | `REDIS_URL` | Preset in the template |
| `app` | `SECRET` | Generated at deploy |
| `app` | `SSL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`app`): SECRET.
- Stores data in named volumes (`redis`): redis.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy One-Time Secret with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select One-Time Secret. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy onetimesecret --name my-onetimesecret
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
