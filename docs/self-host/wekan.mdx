An open-source Kanban board with swimlanes, checklists and webhooks, a self-hosted alternative to Trello.

This page describes the Levelrail template for Wekan (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/wekan/wekan/wiki.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mongo` | `mongo:7` | none | `mongo -&#62; /data/db` |
| `wekan` | `wekanteam/wekan:v12.45` | 8080 | `attachments -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `wekan` | `MONGO_URL` | Preset in the template |
| `wekan` | `ROOT_URL` | Preset in the template |
| `wekan` | `WRITABLE_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`mongo`, `wekan`): attachments, mongo.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Wekan with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Wekan. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy wekan --name my-wekan
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
