Stateless high performance API gateway on the official image. The install form carries krakend.json as an editable file, so it starts with a working route table instead of exiting on a missing config.

This page describes the Levelrail template for KrakenD (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.krakend.io/docs/.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `krakend` | `krakend:3.0.3` | 8080 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`krakend`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy KrakenD with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select KrakenD. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy krakend --name my-krakend
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
