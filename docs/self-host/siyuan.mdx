A privacy-first, self-hosted personal knowledge management app with block-based markdown notes.

This page describes the Levelrail template for SiYuan (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/siyuan-note/siyuan.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `siyuan` | `b3log/siyuan:v3.8.6` | 6806 | `siyuan_workspace -&#62; /siyuan/workspace` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `siyuan` | `PGID` | Preset in the template |
| `siyuan` | `PUID` | Preset in the template |
| `siyuan` | `SIYUAN_ACCESS_AUTH_CODE` | Generated at deploy |
| `siyuan` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`siyuan`): 6806:6806.
- Passwords and keys are generated at deploy time (`siyuan`): SIYUAN_ACCESS_AUTH_CODE.
- Stores data in named volumes (`siyuan`): siyuan_workspace.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy SiYuan with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SiYuan. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy siyuan --name my-siyuan
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
