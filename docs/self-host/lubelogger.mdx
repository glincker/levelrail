A self-hosted vehicle maintenance and fuel mileage tracker with reminders and document storage. MIT licensed. On first open, register the first user, which becomes the root account.

This page describes the Levelrail template for LubeLogger (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.lubelogger.com/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `lubelogger` | `ghcr.io/hargata/lubelogger:v1.7.4` | 8080 | `data -&#62; /App/data`<br />`config -&#62; /App/config`<br />`keys -&#62; /root/.aspnet/DataProtection-Keys` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `lubelogger` | `LANG` | Preset in the template |
| `lubelogger` | `LC_ALL` | Preset in the template |
| `lubelogger` | `LUBELOGGER_ALLOWED_FILE_EXTENSIONS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`lubelogger`): config, data, keys.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LubeLogger with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LubeLogger. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy lubelogger --name my-lubelogger
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
