A headless Chrome browser exposed as an HTTP/WebSocket API for scraping and PDF rendering.

This page describes the Levelrail template for Browserless (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.browserless.io.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `browserless` | `ghcr.io/browserless/chromium:v2.8.0` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `browserless` | `TOKEN` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Browserless with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Browserless. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy browserless --name my-browserless
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
