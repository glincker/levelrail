An open-source human resources management suite: PTO, recruitment, performance, and an employee directory.

This page describes the Levelrail template for OrangeHRM (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.orangehrm.com/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mariadb` | `mariadb:11` | none | `orangehrm_mariadb_data -&#62; /var/lib/mysql` |
| `orangehrm` | `orangehrm/orangehrm:latest` | 80 | `orangehrm_data -&#62; /orangehrm` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mariadb` | `MYSQL_DATABASE` | Preset in the template |
| `mariadb` | `MYSQL_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_USER` | Preset in the template |
| `orangehrm` | `ORANGEHRM_DATABASE_HOST` | Preset in the template |
| `orangehrm` | `ORANGEHRM_DATABASE_NAME` | Preset in the template |
| `orangehrm` | `ORANGEHRM_DATABASE_PASSWORD` | Generated at deploy |
| `orangehrm` | `ORANGEHRM_DATABASE_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy OrangeHRM with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select OrangeHRM. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy orangehrm --name my-orangehrm
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
