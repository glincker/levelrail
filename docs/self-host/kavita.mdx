A fast, feature-rich reader server for manga, comics, and ebooks.

This page describes the Levelrail template for Kavita (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://wiki.kavitareader.com/installation/docker/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `kavita` | `jvmilazz0/kavita:0.9.1` | 5000 | `kavita_config -&#62; /kavita/config`<br />`kavita_data -&#62; /manga` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Kavita with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Kavita. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy kavita --name my-kavita
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
