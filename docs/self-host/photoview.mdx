A fast, simple photo gallery that indexes an existing folder tree without importing or duplicating files.

This page describes the Levelrail template for Photoview (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://photoview.github.io/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `photoview` | `photoview/photoview:2.4.0` | 80 | `photoview_data -&#62; /data`<br />`photoview_photos -&#62; /photos`<br />`photoview_cache -&#62; /app/cache` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `photoview` | `PHOTOVIEW_DATABASE_DRIVER` | Preset in the template |
| `photoview` | `PHOTOVIEW_LISTEN_IP` | Preset in the template |
| `photoview` | `PHOTOVIEW_LISTEN_PORT` | Preset in the template |
| `photoview` | `PHOTOVIEW_SQLITE_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Photoview with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Photoview. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy photoview --name my-photoview
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
