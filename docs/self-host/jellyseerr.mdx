A request manager for Jellyfin, Plex, and Emby libraries, wired to Sonarr and Radarr.

This page describes the Levelrail template for Jellyseerr (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.jellyseerr.dev.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `jellyseerr` | `fallenbagel/jellyseerr:2.7.3` | 5055 | `jellyseerr_config -&#62; /app/config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Jellyseerr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Jellyseerr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy jellyseerr --name my-jellyseerr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
