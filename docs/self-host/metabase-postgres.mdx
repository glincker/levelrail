Metabase business intelligence with its own application data kept in a bundled Postgres database instead of the built in file, so dashboards and questions survive upgrades and scale past a single user. Create the admin on first open.

This page describes the Levelrail template for Metabase with Postgres (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.metabase.com/docs/latest/installation-and-operation/configuring-application-database.

Recommended memory: about 1536 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17.11-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `metabase` | `metabase/metabase:v0.65.4.1` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `metabase` | `JAVA_OPTS` | Preset in the template |
| `metabase` | `MB_DB_DBNAME` | Preset in the template |
| `metabase` | `MB_DB_HOST` | Preset in the template |
| `metabase` | `MB_DB_PASS` | Generated at deploy |
| `metabase` | `MB_DB_PORT` | Preset in the template |
| `metabase` | `MB_DB_TYPE` | Preset in the template |
| `metabase` | `MB_DB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `metabase`): MB_DB_PASS, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Metabase with Postgres with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Metabase with Postgres. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy metabase-postgres --name my-metabase-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
