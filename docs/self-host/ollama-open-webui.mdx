A local LLM runtime paired with a ChatGPT-style web interface, for running open models on your own hardware.

This page describes the Levelrail template for Ollama + Open WebUI (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.openwebui.com/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ollama-api` | `ollama/ollama:latest` | none | `ollama_data -&#62; /root/.ollama` |
| `open-webui` | `ghcr.io/open-webui/open-webui:main` | 8080 | `open_webui_data -&#62; /app/backend/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `open-webui` | `OLLAMA_BASE_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`ollama-api`): ollama/ollama:latest.
- Publishes ports directly on the host (`open-webui`): 8080:8080.
- Stores data in named volumes (`ollama-api`, `open-webui`): ollama_data, open_webui_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Ollama + Open WebUI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ollama + Open WebUI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ollama-open-webui --name my-ollama-open-webui
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
