Dashboards and exploration for metrics, logs, and traces from any data source.

This page describes the Levelrail template for Grafana (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://grafana.com/docs/grafana/latest/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `grafana` | `grafana/grafana:11.2.0` | 3000 | `grafana_data -&#62; /var/lib/grafana` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `grafana` | `GF_SECURITY_ADMIN_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Grafana with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Grafana. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy grafana --name my-grafana
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
