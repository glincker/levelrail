GitLab Community Edition: Git hosting, CI/CD, issues, and a container registry in one Omnibus image.

This page describes the Levelrail template for GitLab (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gitlab.com/ee/install/docker.html.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gitlab` | `gitlab/gitlab-ce:17.5.2-ce.0` | 80, 22 | `gitlab_config -&#62; /etc/gitlab`<br />`gitlab_logs -&#62; /var/log/gitlab`<br />`gitlab_data -&#62; /var/opt/gitlab` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `gitlab` | `GITLAB_OMNIBUS_CONFIG` | Preset in the template |
| `gitlab` | `GITLAB_ROOT_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy GitLab with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GitLab. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gitlab --name my-gitlab
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
