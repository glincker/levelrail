A Minecraft Java server (vanilla, Paper, Fabric or Forge via the server type field) that downloads the selected version on first boot (default 1.21.11, tested on the Java 21 image). You must accept the Minecraft EULA yourself by entering TRUE; it is never accepted for you. Players connect to TCP 25565 (no web address is created for it): the port binds privately by default, so set a public bind in the app's Network settings and open TCP 25565 in the host and cloud firewall. RCON is on with a generated password but its port is not published; use the app's exec shell and run rcon-cli. The JVM heap is the memory field and the container limit defaults to 2560M, 25 percent above the 2G heap. Defaults suit 2 CPUs and 12 GB of RAM shared with other apps. Image is multi-arch (amd64 and arm64).

This page describes the Levelrail template for Minecraft Server (Games). It deploys the services below as one Docker Compose app on your own server. Project site: https://docker-minecraft-server.readthedocs.io/.

Recommended memory: about 2560 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `minecraft` | `itzg/minecraft-server:2026.10.1-java21` | 25565 | `minecraft_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`minecraft`): 25565:25565.
- You must provide one or more secrets before it can deploy (`minecraft`): EULA.
- Passwords and keys are generated at deploy time (`minecraft`): RCON_PASSWORD.
- Stores data in named volumes (`minecraft`): minecraft_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy Minecraft Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Minecraft Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get minecraft --output json | jq -r .compose > minecraft.compose.yaml
# edit minecraft.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-minecraft --file minecraft.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
