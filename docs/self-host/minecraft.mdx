A vanilla Minecraft Java server that downloads and runs the selected version on first boot.

This page describes the Levelrail template for Minecraft Server (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/itzg/docker-minecraft-server.

Recommended memory: about 3072 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `minecraft` | `itzg/minecraft-server:java21` | 25565 | `minecraft_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `minecraft` | `DIFFICULTY` | Preset in the template |
| `minecraft` | `EULA` | Preset in the template |
| `minecraft` | `MAX_PLAYERS` | Preset in the template |
| `minecraft` | `MEMORY` | Preset in the template |
| `minecraft` | `TYPE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Minecraft Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Minecraft Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy minecraft --name my-minecraft
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
