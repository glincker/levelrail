A minimalist, keyboard-friendly kanban board for personal and team task tracking.

This page describes the Levelrail template for Kanboard (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.kanboard.org.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `kanboard` | `kanboard/kanboard:v1.2.54` | 80 | `kanboard_data -&#62; /var/www/app/data`<br />`kanboard_plugins -&#62; /var/www/app/plugins` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Kanboard with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Kanboard. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy kanboard --name my-kanboard
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
