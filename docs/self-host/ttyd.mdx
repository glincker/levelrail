Shares a terminal over the web. Starts a shell inside its own container behind a generated password, handy for demos and short lived admin tasks.

This page describes the Levelrail template for ttyd (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/tsl0922/ttyd#readme.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ttyd` | `tsl0922/ttyd:1.7.7` | 7681 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `ttyd` | `TTYD_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`ttyd`): TTYD_PASSWORD.
- No health check, so a deploy is judged by the process starting (`ttyd`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy ttyd with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ttyd. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ttyd --name my-ttyd
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
