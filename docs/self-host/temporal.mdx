Durable workflow execution: write long-running business logic as code and let Temporal survive failures.

This page describes the Levelrail template for Temporal (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.temporal.io.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `temporal_db_data -&#62; /var/lib/postgresql/data` |
| `temporal` | `temporalio/auto-setup:1.29.7` | 7233 | none |
| `temporal-ui` | `temporalio/ui:2.54.1` | 8080 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `temporal` | `DB` | Preset in the template |
| `temporal` | `DB_PORT` | Preset in the template |
| `temporal` | `POSTGRES_PWD` | Generated at deploy |
| `temporal` | `POSTGRES_SEEDS` | Preset in the template |
| `temporal` | `POSTGRES_USER` | Preset in the template |
| `temporal-ui` | `TEMPORAL_ADDRESS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`temporal`, `temporal-ui`): 7233:7233, 8080:8080.
- Passwords and keys are generated at deploy time (`db`, `temporal`): POSTGRES_PASSWORD, POSTGRES_PWD.
- No health check, so a deploy is judged by the process starting (`temporal-ui`).
- Stores data in named volumes (`db`): temporal_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Temporal with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Temporal. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy temporal --name my-temporal
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
