Durable workflow execution: write long-running business logic as code and let Temporal survive failures.

This page describes the Levelrail template for Temporal (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.temporal.io.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `temporal_db_data -&#62; /var/lib/postgresql/data` |
| `temporal` | `temporalio/auto-setup:1.29.7` | 7233 | none |
| `temporal-ui` | `temporalio/ui:2.54.1` | 8080 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `temporal` | `DB` | Preset in the template |
| `temporal` | `DB_PORT` | Preset in the template |
| `temporal` | `POSTGRES_PWD` | Generated at deploy |
| `temporal` | `POSTGRES_SEEDS` | Preset in the template |
| `temporal` | `POSTGRES_USER` | Preset in the template |
| `temporal-ui` | `TEMPORAL_ADDRESS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Temporal with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Temporal. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy temporal --name my-temporal
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
