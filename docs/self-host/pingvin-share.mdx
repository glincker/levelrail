A self-hosted, ad-free alternative to WeTransfer for sending files with expiring links.

This page describes the Levelrail template for Pingvin Share (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/stonith404/pingvin-share.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `pingvin-share` | `stonith404/pingvin-share:v1.13.0` | 3000 | `pingvin_data -&#62; /opt/app/backend/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `pingvin-share` | `CORS_ALLOW_ORIGIN` | Preset in the template |
| `pingvin-share` | `JWT_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`pingvin-share`): 3000:3000.
- Passwords and keys are generated at deploy time (`pingvin-share`): JWT_SECRET.
- Stores data in named volumes (`pingvin-share`): pingvin_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Pingvin Share with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Pingvin Share. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy pingvin-share --name my-pingvin-share
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
