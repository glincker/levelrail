A unified homepage and tabbed dashboard for linking every self-hosted app behind one interface.

This page describes the Levelrail template for Organizr (Dashboard). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.organizr.app/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `organizr` | `organizr/organizr:latest` | 80 | `organizr_data -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `organizr` | `branch` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Organizr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Organizr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy organizr --name my-organizr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
