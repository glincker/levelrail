A personal CRM that remembers the people in your life, with notes, reminders, activities and relationships.

This page describes the Levelrail template for Monica (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/monicahq/monica/blob/main/docs/installation/docker.md.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mariadb` | `mariadb:11.8` | none | `mariadb -&#62; /var/lib/mysql` |
| `monica` | `monica:4.1.2-apache` | 80 | `storage -&#62; /var/www/html/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mariadb` | `MYSQL_DATABASE` | Preset in the template |
| `mariadb` | `MYSQL_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_USER` | Preset in the template |
| `monica` | `APP_ENV` | Preset in the template |
| `monica` | `APP_KEY` | Generated at deploy |
| `monica` | `APP_URL` | Preset in the template |
| `monica` | `DB_CONNECTION` | Preset in the template |
| `monica` | `DB_DATABASE` | Preset in the template |
| `monica` | `DB_HOST` | Preset in the template |
| `monica` | `DB_PASSWORD` | Generated at deploy |
| `monica` | `DB_PORT` | Preset in the template |
| `monica` | `DB_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`mariadb`, `monica`): APP_KEY, DB_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`mariadb`, `monica`): mariadb, storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Monica with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Monica. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy monica --name my-monica
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
