An open source notification infrastructure for email, SMS, push and in-app messages.

This page describes the Levelrail template for Novu (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.novu.co/community/self-hosting-novu/overview.

Recommended memory: about 3072 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `api` | `ghcr.io/novuhq/novu/api:3.18.0` | 3000 | none |
| `mongodb` | `mongo:8.0.17` | none | `mongo_data -&#62; /data/db` |
| `novu` | `ghcr.io/novuhq/novu/dashboard:3.18.0` | 4000 | none |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`api`, `mongodb`, `worker`, `ws`): JWT_SECRET, MONGO_URL, NOVU_SECRET_KEY, STORE_ENCRYPTION_KEY, JWT_SECRET, MONGO_URL, STORE_ENCRYPTION_KEY, MONGO_INITDB_ROOT_PASSWORD, MONGO_URL, STORE_ENCRYPTION_KEY.
- Stores data in named volumes (`mongodb`, `redis`): mongo_data, redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Novu with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Novu. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy novu --name my-novu
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
