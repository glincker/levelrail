A reactive Python notebook that is reproducible, git-friendly, and shareable as an app.

This page describes the Levelrail template for marimo (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://marimo.io/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `marimo` | `ghcr.io/marimo-team/marimo:latest-sql` | 8080 | `marimo_data -&#62; /app` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy marimo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select marimo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get marimo --output json | jq -r .compose > marimo.compose.yaml
# edit marimo.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-marimo --file marimo.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
