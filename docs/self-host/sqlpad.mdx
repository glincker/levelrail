Web based SQL editor for running queries against many databases, with saved queries, charts and sharing. The admin account is created from the install form.

This page describes the Levelrail template for SQLPad (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://getsqlpad.com/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `sqlpad` | `sqlpad/sqlpad:7.5.7` | 3000 | `data -&#62; /var/lib/sqlpad` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `sqlpad` | `SQLPAD_ADMIN` | Preset in the template |
| `sqlpad` | `SQLPAD_ADMIN_PASSWORD` | Generated at deploy |
| `sqlpad` | `SQLPAD_APP_LOG_LEVEL` | Preset in the template |
| `sqlpad` | `SQLPAD_DB_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`sqlpad`): SQLPAD_ADMIN_PASSWORD.
- No health check, so a deploy is judged by the process starting (`sqlpad`).
- Stores data in named volumes (`sqlpad`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy SQLPad with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SQLPad. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sqlpad --name my-sqlpad
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
