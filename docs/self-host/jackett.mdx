A proxy that translates queries from your media apps into torrent tracker searches.

This page describes the Levelrail template for Jackett (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/Jackett/Jackett#readme.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `jackett` | `lscr.io/linuxserver/jackett:0.24.2663` | 9117 | `jackett_config -&#62; /config`<br />`jackett_downloads -&#62; /downloads` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `jackett` | `PGID` | Preset in the template |
| `jackett` | `PUID` | Preset in the template |
| `jackett` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Jackett with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Jackett. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy jackett --name my-jackett
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
