A low-code platform for building internal tools and admin panels on top of your own data.

This page describes the Levelrail template for Appsmith (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.appsmith.com.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `appsmith` | `appsmith/appsmith-ce:v2.4.2` | 80 | `appsmith_data -&#62; /appsmith-stacks` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Appsmith with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Appsmith. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy appsmith --name my-appsmith
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
