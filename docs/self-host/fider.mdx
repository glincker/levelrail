A feedback platform for collecting and prioritizing user feature requests.

This page describes the Levelrail template for Fider (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://fider.io.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `database` | `postgres:12` | none | `fider_pg_data -&#62; /var/lib/postgresql/data` |
| `fider` | `getfider/fider:stable` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `database` | `POSTGRES_DB` | Preset in the template |
| `database` | `POSTGRES_PASSWORD` | Generated at deploy |
| `database` | `POSTGRES_USER` | Preset in the template |
| `fider` | `BASE_URL` | Preset in the template |
| `fider` | `DATABASE_URL` | Generated at deploy |
| `fider` | `EMAIL_NOREPLY` | Preset in the template |
| `fider` | `JWT_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`fider`): 3000:3000.
- Passwords and keys are generated at deploy time (`database`, `fider`): DATABASE_URL, JWT_SECRET, POSTGRES_PASSWORD.
- Stores data in named volumes (`database`): fider_pg_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Fider with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Fider. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy fider --name my-fider
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
