A web UI for scheduling, encrypting, and restoring PostgreSQL backups.

This page describes the Levelrail template for PG Back Web (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/eduardolat/pgbackweb.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `pgbackweb` | `eduardolat/pgbackweb:0.5.2` | 8085 | `pgbackweb_data -&#62; /backups` |
| `pgbackweb-db` | `postgres:17-alpine` | none | `pgbackweb_postgres_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `pgbackweb` | `PBW_ENCRYPTION_KEY` | Generated at deploy |
| `pgbackweb` | `PBW_POSTGRES_CONN_STRING` | Generated at deploy |
| `pgbackweb-db` | `POSTGRES_DB` | Preset in the template |
| `pgbackweb-db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `pgbackweb-db` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`pgbackweb`): 8085:8085.
- Passwords and keys are generated at deploy time (`pgbackweb`, `pgbackweb-db`): PBW_ENCRYPTION_KEY, PBW_POSTGRES_CONN_STRING, POSTGRES_PASSWORD.
- Stores data in named volumes (`pgbackweb`, `pgbackweb-db`): pgbackweb_data, pgbackweb_postgres_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy PG Back Web with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select PG Back Web. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy pgbackweb --name my-pgbackweb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
