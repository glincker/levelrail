Small standalone WebDAV server with per user permissions. The install form carries config.yml as an editable file and a generated admin password.

This page describes the Levelrail template for WebDAV Server (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/hacdias/webdav#readme.

Recommended memory: about 32 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `webdav` | `hacdias/webdav:v5.17.3` | 6060 | `data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`webdav`).
- Stores data in named volumes (`webdav`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy WebDAV Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select WebDAV Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy webdav --name my-webdav
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
