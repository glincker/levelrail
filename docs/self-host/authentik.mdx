An identity provider and SSO platform with flows, policies, and support for OIDC, SAML, LDAP, and proxy auth.

This page describes the Levelrail template for authentik (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.goauthentik.io.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `authentik` | `ghcr.io/goauthentik/server:2026.8.3` | 9000 | `authentik_media -&#62; /media` |
| `db` | `postgres:16-alpine` | none | `authentik_db_data -&#62; /var/lib/postgresql/data` |
| `worker` | `ghcr.io/goauthentik/server:2026.8.3` | none | `authentik_media -&#62; /media` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`authentik`): 9000:9000.
- Passwords and keys are generated at deploy time (`authentik`, `db`, `worker`): AUTHENTIK_BOOTSTRAP_PASSWORD, AUTHENTIK_POSTGRESQL__PASSWORD, AUTHENTIK_SECRET_KEY, AUTHENTIK_POSTGRESQL__PASSWORD, AUTHENTIK_SECRET_KEY, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`worker`).
- Stores data in named volumes (`authentik`, `db`, `worker`): authentik_db_data, authentik_media.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy authentik with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select authentik. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy authentik --name my-authentik
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
