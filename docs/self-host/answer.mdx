A Q&A platform for building a community knowledge base, in the style of a self-hosted Stack Overflow.

This page describes the Levelrail template for Apache Answer (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://answer.apache.org/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `answer` | `apache/answer:1.4.2` | 80 | `answer_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Apache Answer with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Apache Answer. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy answer --name my-answer
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
