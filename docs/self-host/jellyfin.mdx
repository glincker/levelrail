A free media server for streaming your own movies, shows, and music to any device.

This page describes the Levelrail template for Jellyfin (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://jellyfin.org/docs/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `jellyfin` | `lscr.io/linuxserver/jellyfin:10.11.8` | 8096 | `jellyfin_config -&#62; /config`<br />`jellyfin_media -&#62; /data/media` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Jellyfin with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Jellyfin. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy jellyfin --name my-jellyfin
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
