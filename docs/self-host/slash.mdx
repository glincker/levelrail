A self-hosted link shortener and bookmark sharing platform with tags and full-text search.

This page describes the Levelrail template for Slash (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/yourselfhosted/slash.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `slash` | `yourselfhosted/slash:0.5.3` | 5231 | `slash_data -&#62; /var/opt/slash` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Slash with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Slash. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy slash --name my-slash
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
