Trace, evaluate, and debug LLM applications with prompt management and cost analytics.

This page describes the Levelrail template for Langfuse (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://langfuse.com/self-hosting.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `clickhouse` | `clickhouse/clickhouse-server:24.12-alpine` | none | `langfuse_clickhouse_data -&#62; /var/lib/clickhouse` |
| `db` | `postgres:16-alpine` | none | `langfuse_db_data -&#62; /var/lib/postgresql/data` |
| `langfuse-web` | `langfuse/langfuse:3.225.11` | 3000 | none |
| `langfuse-worker` | `langfuse/langfuse-worker:3.225.11` | none | none |
| `minio` | `ghcr.io/coollabsio/minio:RELEASE.2025-10-15T17-29-55Z` | none | `langfuse_minio_data -&#62; /data` |
| `redis` | `redis:7-alpine` | none | `langfuse_redis_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`langfuse-web`): 3000:3000.
- Passwords and keys are generated at deploy time (`clickhouse`, `db`, `langfuse-web`, `langfuse-worker`, `minio`): CLICKHOUSE_PASSWORD, CLICKHOUSE_PASSWORD, DATABASE_URL, ENCRYPTION_KEY, LANGFUSE_S3_EVENT_UPLOAD_SECRET_ACCESS_KEY, NEXTAUTH_SECRET, SALT, CLICKHOUSE_PASSWORD, DATABASE_URL, ENCRYPTION_KEY, LANGFUSE_S3_EVENT_UPLOAD_SECRET_ACCESS_KEY, SALT, MINIO_ROOT_PASSWORD, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`clickhouse`, `langfuse-worker`, `minio`, `redis`).
- Stores data in named volumes (`clickhouse`, `db`, `minio`, `redis`): langfuse_clickhouse_data, langfuse_db_data, langfuse_minio_data, langfuse_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Langfuse with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Langfuse. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy langfuse --name my-langfuse
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
