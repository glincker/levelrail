Trace, evaluate, and debug LLM applications with prompt management and cost analytics.

This page describes the Levelrail template for Langfuse (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://langfuse.com/self-hosting.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `clickhouse` | `clickhouse/clickhouse-server:24.12-alpine` | none | `langfuse_clickhouse_data -&#62; /var/lib/clickhouse` |
| `db` | `postgres:16-alpine` | none | `langfuse_db_data -&#62; /var/lib/postgresql/data` |
| `langfuse-web` | `langfuse/langfuse:3.225.11` | 3000 | none |
| `langfuse-worker` | `langfuse/langfuse-worker:3.225.11` | none | none |
| `minio` | `ghcr.io/coollabsio/minio:RELEASE.2025-10-15T17-29-55Z` | none | `langfuse_minio_data -&#62; /data` |
| `redis` | `redis:7-alpine` | none | `langfuse_redis_data -&#62; /data` |

## Deploy Langfuse with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Langfuse. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy langfuse --name my-langfuse
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
