A MariaDB 11.8 server paired with the Adminer web console, already wired together. The database is not published on the host, so other services in this project reach it at db:3306. Sign in to Adminer with server db, user root and the generated root password.

This page describes the Levelrail template for MariaDB with Adminer (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.adminer.org/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `adminer` | `adminer:5.5.1` | 8080 | none |
| `db` | `mariadb:11.8.9` | none | `mariadb_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `adminer` | `ADMINER_DEFAULT_SERVER` | Preset in the template |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`): MARIADB_ROOT_PASSWORD.
- Stores data in named volumes (`db`): mariadb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MariaDB with Adminer with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MariaDB with Adminer. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mariadb-adminer --name my-mariadb-adminer
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
