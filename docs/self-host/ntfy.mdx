A simple pub-sub push notification service you can send alerts to from any script or app.

This page describes the Levelrail template for ntfy (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.ntfy.sh.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ntfy` | `binwiederhier/ntfy:v2.11.0` | 80 | `ntfy_cache -&#62; /var/cache/ntfy`<br />`ntfy_data -&#62; /etc/ntfy` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy ntfy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ntfy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ntfy --name my-ntfy
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
