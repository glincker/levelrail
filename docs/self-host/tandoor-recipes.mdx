A recipe manager and meal planner with shopping lists and shared cookbooks.

This page describes the Levelrail template for Tandoor Recipes (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.tandoor.dev/install/docker/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `tandoor_db_data -&#62; /var/lib/postgresql/data` |
| `tandoor` | `vabene1111/recipes:2.6.15` | 80 | `tandoor_data -&#62; /opt/recipes/mediafiles`<br />`tandoor_static -&#62; /opt/recipes/staticfiles` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `tandoor` | `ALLOWED_HOSTS` | Preset in the template |
| `tandoor` | `DB_ENGINE` | Preset in the template |
| `tandoor` | `POSTGRES_DB` | Preset in the template |
| `tandoor` | `POSTGRES_HOST` | Preset in the template |
| `tandoor` | `POSTGRES_PASSWORD` | Generated at deploy |
| `tandoor` | `POSTGRES_PORT` | Preset in the template |
| `tandoor` | `POSTGRES_USER` | Preset in the template |
| `tandoor` | `SECRET_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Tandoor Recipes with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Tandoor Recipes. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy tandoor-recipes --name my-tandoor-recipes
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
