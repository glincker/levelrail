A cross-platform system monitor showing CPU, memory, disk, and network at a glance.

This page describes the Levelrail template for Glances (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://nicolargo.github.io/glances/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `glances` | `nicolargo/glances:3.4.0-full` | 61208 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `glances` | `GLANCES_OPT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Glances with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Glances. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy glances --name my-glances
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
