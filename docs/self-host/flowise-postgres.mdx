Flowise with a Postgres record manager, a Redis cache, and a Qdrant vector store, for production RAG flows.

This page describes the Levelrail template for Flowise (Postgres + Qdrant) (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.flowiseai.com.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cache` | `redis:7-alpine` | none | `flowise_pg_redis_data -&#62; /data` |
| `flowise` | `flowiseai/flowise:3.1.4` | 3000 | `flowise_pg_data -&#62; /root/.flowise` |
| `qdrant` | `qdrant/qdrant:v1.19.1` | none | `flowise_pg_qdrant_data -&#62; /qdrant/storage` |
| `recordmanager` | `postgres:16-alpine` | none | `flowise_pg_recordmanager_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `flowise` | `APIKEY_PATH` | Preset in the template |
| `flowise` | `BLOB_STORAGE_PATH` | Preset in the template |
| `flowise` | `DATABASE_PATH` | Preset in the template |
| `flowise` | `FLOWISE_PASSWORD` | Generated at deploy |
| `flowise` | `FLOWISE_USERNAME` | Generated at deploy |
| `flowise` | `LOG_PATH` | Preset in the template |
| `flowise` | `PORT` | Preset in the template |
| `flowise` | `SECRETKEY_PATH` | Preset in the template |
| `qdrant` | `QDRANT__SERVICE__API_KEY` | Generated at deploy |
| `recordmanager` | `POSTGRES_DB` | Preset in the template |
| `recordmanager` | `POSTGRES_PASSWORD` | Generated at deploy |
| `recordmanager` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Flowise (Postgres + Qdrant) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Flowise (Postgres + Qdrant). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flowise-postgres --name my-flowise-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
