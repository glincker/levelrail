Flowise with a Postgres record manager, a Redis cache, and a Qdrant vector store, for production RAG flows.

This page describes the Levelrail template for Flowise (Postgres + Qdrant) (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.flowiseai.com.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cache` | `redis:7-alpine` | none | `flowise_pg_redis_data -&#62; /data` |
| `flowise` | `flowiseai/flowise:3.1.4` | 3000 | `flowise_pg_data -&#62; /home/node/.flowise` |
| `qdrant` | `qdrant/qdrant:v1.19.1` | none | `flowise_pg_qdrant_data -&#62; /qdrant/storage` |
| `recordmanager` | `postgres:16-alpine` | none | `flowise_pg_recordmanager_data -&#62; /var/lib/postgresql/data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`flowise`): 3000:3000.
- Passwords and keys are generated at deploy time (`flowise`, `qdrant`, `recordmanager`): DATABASE_PASSWORD, EXPRESS_SESSION_SECRET, FLOWISE_PASSWORD, FLOWISE_USERNAME, JWT_AUTH_TOKEN_SECRET, JWT_REFRESH_TOKEN_SECRET, TOKEN_HASH_SECRET, POSTGRES_PASSWORD, QDRANT__SERVICE__API_KEY.
- Stores data in named volumes (`cache`, `flowise`, `qdrant`, `recordmanager`): flowise_pg_data, flowise_pg_qdrant_data, flowise_pg_recordmanager_data, flowise_pg_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Flowise (Postgres + Qdrant) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Flowise (Postgres + Qdrant). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flowise-postgres --name my-flowise-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
