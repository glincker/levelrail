Ask questions of your data and share dashboards, no SQL required.

This page describes the Levelrail template for Metabase (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.metabase.com/docs/latest/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `metabase` | `metabase/metabase:v0.50.8` | 3000 | `metabase_data -&#62; /metabase-data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `metabase` | `MB_DB_FILE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Metabase with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Metabase. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy metabase --name my-metabase
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
