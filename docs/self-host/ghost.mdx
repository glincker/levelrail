A fast, modern publishing platform for blogs and newsletters, with built-in memberships.

This page describes the Levelrail template for Ghost (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://ghost.org/docs/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mysql:8.4` | none | `ghost_db_data -&#62; /var/lib/mysql` |
| `ghost` | `ghost:5` | 2368 | `ghost_data -&#62; /var/lib/ghost/content` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `ghost` | `database__client` | Preset in the template |
| `ghost` | `database__connection__database` | Preset in the template |
| `ghost` | `database__connection__host` | Preset in the template |
| `ghost` | `database__connection__password` | Generated at deploy |
| `ghost` | `database__connection__user` | Preset in the template |
| `ghost` | `url` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Ghost with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ghost. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ghost --name my-ghost
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
