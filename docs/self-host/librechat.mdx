A self-hosted ChatGPT-style interface for many model providers, with agents, search, and multi-user login.

This page describes the Levelrail template for LibreChat (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.librechat.ai/docs.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `librechat` | `ghcr.io/danny-avila/librechat:v0.8.7` | 3080 | `librechat_images -&#62; /app/client/public/images` |
| `meilisearch` | `getmeili/meilisearch:v1.54.0` | none | `librechat_meili_data -&#62; /meili_data` |
| `mongo` | `mongo:7` | none | `librechat_mongo_data -&#62; /data/db` |

| `librechat` | `DOMAIN_CLIENT` | Preset in the template |

| `librechat` | `MEILI_HOST` | Preset in the template |
| `librechat` | `MEILI_MASTER_KEY` | Generated at deploy |
| `librechat` | `MONGO_URI` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy LibreChat with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LibreChat. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy librechat --name my-librechat
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
