Grafana backed by Postgres instead of its default embedded SQLite, for multi-instance or external-DB setups.

This page describes the Levelrail template for Grafana (Postgres) (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://grafana.com/docs/grafana/latest/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `grafana_postgres_db_data -&#62; /var/lib/postgresql/data` |
| `grafana` | `grafana/grafana:11.2.0` | 3000 | `grafana_postgres_data -&#62; /var/lib/grafana` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `grafana` | `GF_DATABASE_HOST` | Preset in the template |
| `grafana` | `GF_DATABASE_NAME` | Preset in the template |
| `grafana` | `GF_DATABASE_PASSWORD` | Generated at deploy |
| `grafana` | `GF_DATABASE_TYPE` | Preset in the template |
| `grafana` | `GF_DATABASE_USER` | Preset in the template |
| `grafana` | `GF_SECURITY_ADMIN_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Grafana (Postgres) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Grafana (Postgres). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy grafana-postgres --name my-grafana-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
