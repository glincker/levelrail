A web admin console for MongoDB, bundled with its own MongoDB 7 instance and basic auth.

This page describes the Levelrail template for Mongo Express (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/mongo-express/mongo-express.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mongo` | `mongo:7` | none | `mongo_data -&#62; /data/db` |
| `mongo-express` | `mongo-express:1.0.2-20-alpine3.19` | 8081 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mongo` | `MONGO_INITDB_ROOT_PASSWORD` | Generated at deploy |
| `mongo` | `MONGO_INITDB_ROOT_USERNAME` | Preset in the template |
| `mongo-express` | `ME_CONFIG_BASICAUTH_PASSWORD` | Generated at deploy |
| `mongo-express` | `ME_CONFIG_BASICAUTH_USERNAME` | Generated at deploy |
| `mongo-express` | `ME_CONFIG_MONGODB_ENABLE_ADMIN` | Preset in the template |
| `mongo-express` | `ME_CONFIG_MONGODB_URL` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Mongo Express with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Mongo Express. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mongo-express --name my-mongo-express
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
