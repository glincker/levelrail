Project management with work packages, Gantt charts and boards.

This page describes the Levelrail template for OpenProject (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.openproject.org/docs/installation-and-operations/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cache` | `memcached:1.6-alpine` | none | none |
| `cron` | `openproject/openproject:17.9.7-slim` | none | `opdata -&#62; /var/openproject/assets` |
| `db` | `postgres:17-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `seeder` | `openproject/openproject:17.9.7-slim` | none | `opdata -&#62; /var/openproject/assets` |
| `web` | `openproject/openproject:17.9.7-slim` | 8080 | `opdata -&#62; /var/openproject/assets` |
| `worker` | `openproject/openproject:17.9.7-slim` | none | `opdata -&#62; /var/openproject/assets` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`cron`, `db`, `seeder`, `web`, `worker`): DATABASE_URL, SECRET_KEY_BASE, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`seeder`).
- Stores data in named volumes (`cron`, `db`, `seeder`, `web`, `worker`): opdata, pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy OpenProject with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select OpenProject. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy openproject --name my-openproject
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
