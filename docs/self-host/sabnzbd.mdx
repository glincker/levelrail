A Usenet binary downloader with a web interface, RSS and post-processing. GPL-2.0 licensed. On first open, run the setup wizard to add your Usenet provider; if you serve it on a domain, add that host name under Config, Special, host_whitelist.

This page describes the Levelrail template for SABnzbd (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://sabnzbd.org/wiki/.

Recommended memory: about 384 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `sabnzbd` | `lscr.io/linuxserver/sabnzbd:5.1.3` | 8080 | `config -&#62; /config`<br />`downloads -&#62; /downloads` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `sabnzbd` | `PGID` | Preset in the template |
| `sabnzbd` | `PUID` | Preset in the template |
| `sabnzbd` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`sabnzbd`): config, downloads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy SABnzbd with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SABnzbd. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sabnzbd --name my-sabnzbd
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
