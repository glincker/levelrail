A feature-rich, self-hosted start page with widgets, status checks, and full visual customization.

This page describes the Levelrail template for Dashy (Dashboard). It deploys the services below as one Docker Compose app on your own server. Project site: https://dashy.to/docs.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `dashy` | `lissy93/dashy:4.7.8` | 8080 | `dashy_config -&#62; /app/user-data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Dashy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Dashy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy dashy --name my-dashy
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
