A web UI for inspecting topics, consumers and messages in Apache Kafka clusters.

This page describes the Levelrail template for Kafka UI (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.kafka-ui.provectus.io.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `kafka-ui` | `provectuslabs/kafka-ui:v0.7.2` | 8080 | `kafka_ui_config -&#62; /etc/kafkaui` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `kafka-ui` | `AUTH_TYPE` | Preset in the template |
| `kafka-ui` | `DYNAMIC_CONFIG_ENABLED` | Preset in the template |
| `kafka-ui` | `SPRING_SECURITY_USER_NAME` | Preset in the template |
| `kafka-ui` | `SPRING_SECURITY_USER_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`kafka-ui`): SPRING_SECURITY_USER_PASSWORD.
- Stores data in named volumes (`kafka-ui`): kafka_ui_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Kafka UI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Kafka UI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy kafka-ui --name my-kafka-ui
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
