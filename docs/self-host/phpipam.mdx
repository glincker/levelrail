An open source IP address management app for tracking subnets, addresses, VLANs and devices, backed by MariaDB. Finish the database install from the first page with the generated root password.

This page describes the Levelrail template for phpIPAM (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://phpipam.net/documents/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11.8.9` | none | `mariadb_data -&#62; /var/lib/mysql` |
| `phpipam` | `phpipam/phpipam-www:v1.9.0` | 80 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `phpipam` | `IPAM_DATABASE_HOST` | Preset in the template |
| `phpipam` | `IPAM_DATABASE_NAME` | Preset in the template |
| `phpipam` | `IPAM_DATABASE_PASS` | Generated at deploy |
| `phpipam` | `IPAM_DATABASE_USER` | Preset in the template |
| `phpipam` | `IPAM_DATABASE_WEBHOST` | Preset in the template |
| `phpipam` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `phpipam`): IPAM_DATABASE_PASS, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`db`): mariadb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy phpIPAM with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select phpIPAM. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy phpipam --name my-phpipam
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
