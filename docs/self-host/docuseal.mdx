A free, open-source document signing tool, a lighter alternative to DocuSign.

This page describes the Levelrail template for DocuSeal (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.docuseal.co/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `docuseal` | `docuseal/docuseal:latest` | 3000 | `docuseal_data -&#62; /data` |
| `postgresql` | `postgres:16-alpine` | none | `docuseal_postgresql_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `docuseal` | `DATABASE_URL` | Generated at deploy |
| `docuseal` | `HOST` | Preset in the template |
| `postgresql` | `POSTGRES_DB` | Preset in the template |
| `postgresql` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgresql` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`docuseal`): docuseal/docuseal:latest.
- Publishes ports directly on the host (`docuseal`): 3000:3000.
- Passwords and keys are generated at deploy time (`docuseal`, `postgresql`): DATABASE_URL, POSTGRES_PASSWORD.
- Stores data in named volumes (`docuseal`, `postgresql`): docuseal_data, docuseal_postgresql_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy DocuSeal with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select DocuSeal. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy docuseal --name my-docuseal
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
