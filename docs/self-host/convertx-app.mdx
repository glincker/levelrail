A self-hosted online file converter supporting over a thousand formats.

This page describes the Levelrail template for ConvertX (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/C4illin/ConvertX.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `convertx` | `ghcr.io/c4illin/convertx:latest` | 3000 | `convertx_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `convertx` | `ACCOUNT_REGISTRATION` | Preset in the template |
| `convertx` | `AUTO_DELETE_EVERY_N_HOURS` | Preset in the template |
| `convertx` | `HTTP_ALLOWED` | Preset in the template |
| `convertx` | `JWT_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`convertx`): ghcr.io/c4illin/convertx:latest.
- Publishes ports directly on the host (`convertx`): 3000:3000.
- Passwords and keys are generated at deploy time (`convertx`): JWT_SECRET.
- Stores data in named volumes (`convertx`): convertx_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy ConvertX with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ConvertX. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy convertx-app --name my-convertx-app
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
