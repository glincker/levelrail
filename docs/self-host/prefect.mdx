Python-native workflow orchestration with scheduling, retries, and a dashboard for every flow run.

This page describes the Levelrail template for Prefect (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.prefect.io.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `prefect_db_data -&#62; /var/lib/postgresql/data` |
| `prefect` | `prefecthq/prefect:3-latest` | 4200 | `prefect_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `prefect` | `PREFECT_API_DATABASE_CONNECTION_URL` | Generated at deploy |
| `prefect` | `PREFECT_HOME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Prefect with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Prefect. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy prefect --name my-prefect
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
