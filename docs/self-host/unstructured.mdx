An API that turns PDFs, Word files, and other documents into clean data for RAG pipelines.

This page describes the Levelrail template for Unstructured (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/Unstructured-IO/unstructured-api.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `unstructured` | `downloads.unstructured.io/unstructured-io/unstructured-api:latest` | 8000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `unstructured` | `UNSTRUCTURED_API_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`unstructured`): downloads.unstructured.io/unstructured-io/unstructured-api:latest.
- Publishes ports directly on the host (`unstructured`): 8000:8000.
- Passwords and keys are generated at deploy time (`unstructured`): UNSTRUCTURED_API_KEY.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Unstructured with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Unstructured. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy unstructured --name my-unstructured
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
