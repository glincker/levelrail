A private chat workspace over your documents, with built-in RAG and support for local or hosted models.

This page describes the Levelrail template for AnythingLLM (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.anythingllm.com.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `anythingllm` | `mintplexlabs/anythingllm:1.16.2` | 3001 | `anythingllm_storage -&#62; /app/server/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `anythingllm` | `JWT_SECRET` | Generated at deploy |
| `anythingllm` | `SERVER_PORT` | Preset in the template |
| `anythingllm` | `STORAGE_DIR` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`anythingllm`): 3001:3001.
- Passwords and keys are generated at deploy time (`anythingllm`): JWT_SECRET.
- Stores data in named volumes (`anythingllm`): anythingllm_storage.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy AnythingLLM with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select AnythingLLM. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy anythingllm --name my-anythingllm
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
