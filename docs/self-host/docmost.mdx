An open-source, Notion-style collaborative wiki and documentation workspace.

This page describes the Levelrail template for Docmost (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docmost.com/docs.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `docmost_db_data -&#62; /var/lib/postgresql/data` |
| `docmost` | `docmost/docmost:0.96.0` | 3000 | `docmost_data -&#62; /app/data/storage` |
| `redis` | `redis:7.2-alpine` | none | `docmost_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `docmost` | `APP_SECRET` | Generated at deploy |
| `docmost` | `APP_URL` | Preset in the template |
| `docmost` | `DATABASE_URL` | Generated at deploy |
| `docmost` | `REDIS_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Docmost with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Docmost. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy docmost --name my-docmost
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
