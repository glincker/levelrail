PostgreSQL with the TimescaleDB extension for time series data, with a persistent volume and a generated password. The core is Apache-2.0 and some features fall under the Timescale License. It is not published on the host, so reach it from other services in this project at timescaledb:5432.

This page describes the Levelrail template for TimescaleDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.timescale.com/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `timescaledb` | `timescale/timescaledb:2.30.2-pg17` | 5432 | `tsdata -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `timescaledb` | `POSTGRES_DB` | Preset in the template |
| `timescaledb` | `POSTGRES_PASSWORD` | Generated at deploy |
| `timescaledb` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`timescaledb`): POSTGRES_PASSWORD.
- Stores data in named volumes (`timescaledb`): tsdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy TimescaleDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select TimescaleDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy timescaledb --name my-timescaledb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
