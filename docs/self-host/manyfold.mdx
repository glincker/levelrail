A self-hosted manager for 3D printing model libraries with tags, previews and sharing, backed by Postgres and Redis. Create the first admin on first open.

This page describes the Levelrail template for Manyfold (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://manyfold.app/get-started/docker.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17.11-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `manyfold` | `ghcr.io/manyfold3d/manyfold:0.154.1` | 3214 | `libraries -&#62; /libraries` |
| `redis` | `redis:7.4.7-alpine` | none | `redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `manyfold` | `DATABASE_ADAPTER` | Preset in the template |
| `manyfold` | `DATABASE_HOST` | Preset in the template |
| `manyfold` | `DATABASE_NAME` | Preset in the template |
| `manyfold` | `DATABASE_PASSWORD` | Generated at deploy |
| `manyfold` | `DATABASE_PORT` | Preset in the template |
| `manyfold` | `DATABASE_USER` | Preset in the template |
| `manyfold` | `PGID` | Preset in the template |
| `manyfold` | `PUID` | Preset in the template |
| `manyfold` | `REDIS_URL` | Preset in the template |
| `manyfold` | `SECRET_KEY_BASE` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `manyfold`): DATABASE_PASSWORD, SECRET_KEY_BASE, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `manyfold`, `redis`): libraries, pgdata, redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Manyfold with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Manyfold. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy manyfold --name my-manyfold
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
