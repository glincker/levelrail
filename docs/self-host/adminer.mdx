A single-file database admin tool for MySQL, PostgreSQL, SQLite, and more.

This page describes the Levelrail template for Adminer (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.adminer.org.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `adminer` | `adminer:5` | 8080 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Adminer with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Adminer. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy adminer --name my-adminer
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
