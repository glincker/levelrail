An open-source project management tool for tracking issues and cycles, an alternative to Linear and Jira.

This page describes the Levelrail template for Plane (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.plane.so/self-hosting/methods/docker-compose.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `api` | `makeplane/plane-backend:v1.3.0` | none | `plane_logs_api -&#62; /code/plane/logs` |
| `plane-db` | `postgres:15.7-alpine` | none | `plane_db_data -&#62; /var/lib/postgresql/data` |
| `plane-minio` | `ghcr.io/coollabsio/minio:RELEASE.2025-10-15T17-29-55Z` | none | `plane_uploads -&#62; /export` |
| `plane-mq` | `rabbitmq:3.13.6-management-alpine` | none | `plane_mq_data -&#62; /var/lib/rabbitmq` |

| `proxy` | `makeplane/plane-proxy:v1.3.0` | 80 | `plane_proxy_config -&#62; /config`<br />`plane_proxy_data -&#62; /data` |
| `web` | `makeplane/plane-frontend:v1.3.0` | none | none |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`proxy`): 8080:80.
- Passwords and keys are generated at deploy time (`api`, `plane-db`, `plane-minio`, `plane-mq`): AMQP_URL, AWS_SECRET_ACCESS_KEY, DATABASE_URL, SECRET_KEY, MINIO_ROOT_PASSWORD, POSTGRES_PASSWORD, RABBITMQ_DEFAULT_PASS.
- No health check, so a deploy is judged by the process starting (`api`).
- Stores data in named volumes (`api`, `plane-db`, `plane-minio`, `plane-mq`, `plane-redis`, `proxy`): plane_db_data, plane_logs_api, plane_mq_data, plane_proxy_config, plane_proxy_data, plane_redis_data, plane_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Plane with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Plane. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy plane --name my-plane
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
