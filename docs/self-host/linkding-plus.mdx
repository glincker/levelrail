Linkding's extended image with full-page snapshot archiving bundled in, for bookmarks that must survive link rot.

This page describes the Levelrail template for Linkding Plus (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://linkding.link.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `linkding-plus` | `sissbruecker/linkding:1.47.0-plus` | 9090 | `linkding_plus_data -&#62; /etc/linkding/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `linkding-plus` | `LD_SUPERUSER_NAME` | Generated at deploy |
| `linkding-plus` | `LD_SUPERUSER_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`linkding-plus`): 9090:9090.
- Passwords and keys are generated at deploy time (`linkding-plus`): LD_SUPERUSER_NAME, LD_SUPERUSER_PASSWORD.
- Stores data in named volumes (`linkding-plus`): linkding_plus_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Linkding Plus with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Linkding Plus. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy linkding-plus --name my-linkding-plus
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
