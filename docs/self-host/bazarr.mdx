Companion to Sonarr and Radarr that finds and downloads subtitles for your media library.

This page describes the Levelrail template for Bazarr (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://wiki.bazarr.media.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `bazarr` | `lscr.io/linuxserver/bazarr:1.5.1` | 6767 | `bazarr_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `bazarr` | `PGID` | Preset in the template |
| `bazarr` | `PUID` | Preset in the template |
| `bazarr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Bazarr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Bazarr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy bazarr --name my-bazarr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
