A modern web client and server for the Soulseek peer to peer network, with a REST API.

This page describes the Levelrail template for slskd (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/slskd/slskd.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `slskd` | `slskd/slskd:0.26.2` | 5030 | `app -&#62; /app` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `slskd` | `SLSKD_PASSWORD` | Generated at deploy |
| `slskd` | `SLSKD_REMOTE_CONFIGURATION` | Preset in the template |
| `slskd` | `SLSKD_SLSK_PASSWORD` | You must provide |
| `slskd` | `SLSKD_SLSK_USERNAME` | You must provide |
| `slskd` | `SLSKD_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- You must provide one or more secrets before it can deploy (`slskd`): SLSKD_SLSK_PASSWORD, SLSKD_SLSK_USERNAME.
- Passwords and keys are generated at deploy time (`slskd`): SLSKD_PASSWORD.
- Stores data in named volumes (`slskd`): app.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy slskd with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select slskd. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get slskd --output json | jq -r .compose > slskd.compose.yaml
# edit slskd.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-slskd --file slskd.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
