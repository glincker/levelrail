A free, self-hosted backup tool for Postgres, MySQL, and MongoDB databases.

This page describes the Levelrail template for Databasus (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://databasus.com/installation.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `databasus` | `databasus/databasus:v3.16.2` | 4005 | `databasus_data -&#62; /databasus-data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Databasus with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Databasus. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy databasus --name my-databasus
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
