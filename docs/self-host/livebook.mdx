Interactive and collaborative code notebooks for Elixir with a built in package manager and visualizations. A generated password protects the editor.

This page describes the Levelrail template for Livebook (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://livebook.dev/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `livebook` | `ghcr.io/livebook-dev/livebook:0.19.10` | 8080 | `data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `livebook` | `LIVEBOOK_IP` | Preset in the template |
| `livebook` | `LIVEBOOK_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`livebook`): LIVEBOOK_PASSWORD.
- No health check, so a deploy is judged by the process starting (`livebook`).
- Stores data in named volumes (`livebook`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Livebook with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Livebook. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy livebook --name my-livebook
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
