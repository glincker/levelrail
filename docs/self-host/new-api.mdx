An LLM gateway and AI asset management system that unifies many model providers.

This page describes the Levelrail template for New API (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.newapi.pro/en/getting-started/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `new-api` | `calciumion/new-api:v0.9.2.0` | 3000 | none |
| `postgres` | `postgres:16-alpine` | none | `postgres_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `new-api` | `ERROR_LOG_ENABLED` | Preset in the template |
| `new-api` | `REDIS_CONN_STRING` | Preset in the template |
| `new-api` | `SESSION_SECRET` | Generated at deploy |
| `new-api` | `SQL_DSN` | Generated at deploy |
| `new-api` | `TZ` | Preset in the template |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`new-api`): 3000:3000.
- Passwords and keys are generated at deploy time (`new-api`, `postgres`): POSTGRES_PASSWORD, SESSION_SECRET, SQL_DSN.
- Stores data in named volumes (`postgres`, `redis`): postgres_data, redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy New API with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select New API. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy new-api --name my-new-api
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
