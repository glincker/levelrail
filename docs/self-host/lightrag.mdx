Graph based retrieval augmented generation server with a web UI and API. Runs on local file storage; point it at a model provider with the LLM and embedding settings.

This page describes the Levelrail template for LightRAG (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/HKUDS/LightRAG/blob/main/lightrag/api/README.md.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `lightrag` | `ghcr.io/hkuds/lightrag:v1.5.7` | 9621 | `rag -&#62; /app/data/rag_storage`<br />`inputs -&#62; /app/data/inputs` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`lightrag`): LIGHTRAG_API_KEY.
- No health check, so a deploy is judged by the process starting (`lightrag`).
- Stores data in named volumes (`lightrag`): inputs, rag.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LightRAG with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LightRAG. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy lightrag --name my-lightrag
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
