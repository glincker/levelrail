A privacy-first personal finance app for tracking net worth, budgets, and investments across every account.

This page describes the Levelrail template for Sure (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/we-promise/sure.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `postgresql` | `postgres:16-alpine` | none | `sure_postgresql_data -&#62; /var/lib/postgresql/data` |
| `valkey` | `valkey/valkey:8-alpine` | none | `sure_valkey_data -&#62; /data` |
| `web` | `ghcr.io/we-promise/sure:0.6.7` | 3000 | `sure_app_storage -&#62; /rails/storage` |
| `worker` | `ghcr.io/we-promise/sure:0.6.7` | none | `sure_app_storage -&#62; /rails/storage` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`web`): 3000:3000.
- Passwords and keys are generated at deploy time (`postgresql`, `web`, `worker`): POSTGRES_PASSWORD, POSTGRES_PASSWORD, SECRET_KEY_BASE.
- No health check, so a deploy is judged by the process starting (`worker`).
- Stores data in named volumes (`postgresql`, `valkey`, `web`, `worker`): sure_app_storage, sure_postgresql_data, sure_valkey_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Sure with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Sure. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sure --name my-sure
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
