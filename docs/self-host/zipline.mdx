A self-hosted file and screenshot host with a share-first upload flow and its own URL shortener.

This page describes the Levelrail template for Zipline (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://zipline.diced.sh/docs.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `zipline_db_data -&#62; /var/lib/postgresql/data` |
| `zipline` | `ghcr.io/diced/zipline:3.7.9` | 3000 | `zipline_uploads -&#62; /zipline/uploads` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `zipline` | `CORE_DATABASE_URL` | Generated at deploy |
| `zipline` | `CORE_RETURN_HTTPS` | Preset in the template |
| `zipline` | `CORE_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`zipline`): 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `zipline`): CORE_DATABASE_URL, CORE_SECRET, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `zipline`): zipline_db_data, zipline_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Zipline with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Zipline. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy zipline --name my-zipline
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
