A minimal Python HTTP service wired to a Postgres database, the reference pairing for a FastAPI backend.

This page describes the Levelrail template for FastAPI + PostgreSQL (Starter Kits). It deploys the services below as one Docker Compose app on your own server. Project site: https://fastapi.tiangolo.com/deployment/docker/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `api` | `python:3.12-alpine` | 8000 | none |
| `db` | `postgres:16-alpine` | none | `fastapi_postgres_db_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `api` | `DATABASE_URL` | Generated at deploy |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`api`): 8000:8000.
- Passwords and keys are generated at deploy time (`api`, `db`): DATABASE_URL, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): fastapi_postgres_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy FastAPI + PostgreSQL with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FastAPI + PostgreSQL. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy fastapi-postgres-starter --name my-fastapi-postgres-starter
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
