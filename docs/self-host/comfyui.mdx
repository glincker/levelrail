A node-graph editor for building and running Stable Diffusion and other image generation pipelines.

This page describes the Levelrail template for ComfyUI (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.comfy.org.

Recommended memory: about 8192 MiB.

<Warning>This template reserves an NVIDIA GPU, so it needs a node with a GPU and the NVIDIA container runtime.</Warning>

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `comfyui` | `ghcr.io/ai-dock/comfyui:latest-cuda` | 8188 | `comfyui_workspace -&#62; /workspace` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `comfyui` | `WEB_ENABLE_AUTH` | Preset in the template |
| `comfyui` | `WEB_PASSWORD` | Generated at deploy |
| `comfyui` | `WEB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`comfyui`): 8188:8188.
- Passwords and keys are generated at deploy time (`comfyui`): WEB_PASSWORD.
- Stores data in named volumes (`comfyui`): comfyui_workspace.
- Reserves an NVIDIA GPU (`comfyui`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy ComfyUI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ComfyUI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy comfyui --name my-comfyui
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
