A Matrix homeserver backed by Postgres, for self-hosted federated chat and voice/video signaling.

This page describes the Levelrail template for Matrix Synapse (Postgres) (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://element-hq.github.io/synapse/latest/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `postgres` | `postgres:16-alpine` | none | `synapse_postgres_data -&#62; /var/lib/postgresql/data` |
| `synapse` | `matrixdotorg/synapse:latest` | 8008 | `synapse_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_INITDB_ARGS` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |
| `synapse` | `ADMIN_PASSWORD` | Generated at deploy |
| `synapse` | `ADMIN_USERNAME` | Generated at deploy |
| `synapse` | `DB_PASSWORD` | Generated at deploy |
| `synapse` | `ENABLE_REGISTRATION` | Preset in the template |
| `synapse` | `SYNAPSE_PUBLIC_BASEURL` | Preset in the template |
| `synapse` | `SYNAPSE_REPORT_STATS` | Preset in the template |
| `synapse` | `SYNAPSE_SERVER_NAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Matrix Synapse (Postgres) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Matrix Synapse (Postgres). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy matrix-synapse-postgres --name my-matrix-synapse-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
