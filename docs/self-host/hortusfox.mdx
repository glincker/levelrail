A collaborative plant management app for home gardens and plant collections.

This page describes the Levelrail template for HortusFox (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/danielbrendel/hortusfox-web.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `app` | `ghcr.io/danielbrendel/hortusfox-web:v6.4` | 80 | `app_images -&#62; /var/www/html/public/img`<br />`app_logs -&#62; /var/www/html/app/logs`<br />`app_backup -&#62; /var/www/html/public/backup`<br />`app_themes -&#62; /var/www/html/public/themes`<br />`app_migrate -&#62; /var/www/html/app/migrations` |
| `db` | `mariadb:11` | none | `db_data -&#62; /var/lib/mysql` |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`app`, `db`): APP_ADMIN_PASSWORD, DB_PASSWORD, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- Stores data in named volumes (`app`, `db`): app_backup, app_images, app_logs, app_migrate, app_themes, db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy HortusFox with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select HortusFox. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy hortusfox --name my-hortusfox
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
