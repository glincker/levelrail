A headless content platform for managing structured content behind a clean API, without a big CMS footprint.

This page describes the Levelrail template for Cockpit CMS (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://getcockpit.com/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cockpit-cms` | `cockpithq/cockpit:core-latest` | 80 | `cockpitcms_config -&#62; /var/www/html/config`<br />`cockpitcms_storage -&#62; /var/www/html/storage`<br />`cockpitcms_spaces -&#62; /var/www/html/.spaces` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Cockpit CMS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Cockpit CMS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy cockpit-cms --name my-cockpit-cms
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
