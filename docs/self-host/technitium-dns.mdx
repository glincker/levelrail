A full-featured authoritative and recursive DNS server with DNS-over-HTTPS/TLS and a web console.

This page describes the Levelrail template for Technitium DNS Server (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://technitium.com/dns/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `technitium-dns` | `technitium/dns-server:15.5.1` | 5380 | `technitium_config -&#62; /etc/dns` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `technitium-dns` | `DNS_SERVER_ADMIN_PASSWORD` | Generated at deploy |
| `technitium-dns` | `DNS_SERVER_DOMAIN` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Technitium DNS Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Technitium DNS Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy technitium-dns --name my-technitium-dns
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
