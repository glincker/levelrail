A privacy-focused front end for Google search results, with no tracking, ads, or JavaScript required.

This page describes the Levelrail template for Whoogle Search (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/benbusby/whoogle-search.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `whoogle` | `benbusby/whoogle-search:0.9.3` | 5000 | `whoogle_data -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `whoogle` | `WHOOGLE_CONFIG_COUNTRY` | Preset in the template |
| `whoogle` | `WHOOGLE_CONFIG_LANGUAGE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Whoogle Search with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Whoogle Search. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy whoogle --name my-whoogle
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
