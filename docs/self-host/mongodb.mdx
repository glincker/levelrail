The MongoDB document database on the official image, with a persistent volume and a generated root user and password. It is not published on the host, so reach it from other services in this project at mongodb:27017.

This page describes the Levelrail template for MongoDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.mongodb.com/docs/manual/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mongodb` | `mongo:8.0.34` | 27017 | `mongodb_data -&#62; /data/db`<br />`mongodb_config -&#62; /data/configdb` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mongodb` | `MONGO_INITDB_ROOT_PASSWORD` | Generated at deploy |
| `mongodb` | `MONGO_INITDB_ROOT_USERNAME` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`mongodb`): MONGO_INITDB_ROOT_PASSWORD, MONGO_INITDB_ROOT_USERNAME.
- Stores data in named volumes (`mongodb`): mongodb_config, mongodb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MongoDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MongoDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mongodb --name my-mongodb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
