A self-hosted CouchDB backend for the Obsidian LiveSync plugin, syncing your notes across devices.

This page describes the Levelrail template for Obsidian LiveSync (CouchDB) (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/vrtmrz/obsidian-livesync/blob/main/docs/setup_own_server.md.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `couchdb` | `couchdb:3.5.2` | 5984 | `couchdb_data -&#62; /opt/couchdb/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `couchdb` | `COUCHDB_PASSWORD` | Generated at deploy |
| `couchdb` | `COUCHDB_USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Obsidian LiveSync (CouchDB) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Obsidian LiveSync (CouchDB). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy obsidian-livesync --name my-obsidian-livesync
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
