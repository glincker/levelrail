A continuous localization system for translating software with a web-based editor and review flow.

This page describes the Levelrail template for Weblate (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.weblate.org.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `weblate_db_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `weblate_redis_data -&#62; /data` |
| `weblate` | `weblate/weblate:5.15` | 8080 | `weblate_data -&#62; /app/data`<br />`weblate_cache -&#62; /app/cache` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `redis` | `REDIS_PASSWORD` | Generated at deploy |
| `weblate` | `POSTGRES_DATABASE` | Preset in the template |
| `weblate` | `POSTGRES_HOST` | Preset in the template |
| `weblate` | `POSTGRES_PASSWORD` | Generated at deploy |
| `weblate` | `POSTGRES_USER` | Preset in the template |
| `weblate` | `REDIS_HOST` | Preset in the template |
| `weblate` | `REDIS_PASSWORD` | Generated at deploy |
| `weblate` | `REDIS_PORT` | Preset in the template |
| `weblate` | `WEBLATE_ADMIN_PASSWORD` | Generated at deploy |
| `weblate` | `WEBLATE_SITE_DOMAIN` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Weblate with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Weblate. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy weblate --name my-weblate
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
