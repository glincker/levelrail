A customizable start page dashboard for your self-hosted services with drag-and-drop widgets.

This page describes the Levelrail template for Homarr (Dashboard). It deploys the services below as one Docker Compose app on your own server. Project site: https://homarr.dev/docs/getting-started/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `homarr` | `ghcr.io/ajnart/homarr:0.15.10` | 7575 | `homarr_configs -&#62; /app/data/configs`<br />`homarr_icons -&#62; /app/public/icons`<br />`homarr_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `homarr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Homarr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Homarr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy homarr --name my-homarr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
