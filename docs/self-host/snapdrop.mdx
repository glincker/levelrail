Local network file sharing in the browser, inspired by AirDrop.

This page describes the Levelrail template for Snapdrop (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/RobinLinus/snapdrop.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `snapdrop` | `lscr.io/linuxserver/snapdrop:latest` | 80 | `snapdrop_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `snapdrop` | `PGID` | Preset in the template |
| `snapdrop` | `PUID` | Preset in the template |
| `snapdrop` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Snapdrop with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Snapdrop. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy snapdrop --name my-snapdrop
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
