Find a time that works for everyone with polls for scheduling meetings and events.

This page describes the Levelrail template for Rallly (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://support.rallly.co/self-hosting/introduction.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `rallly_db_data -&#62; /var/lib/postgresql/data` |
| `rallly` | `lukevella/rallly:4.15.2` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Generated at deploy |
| `rallly` | `DATABASE_URL` | Generated at deploy |
| `rallly` | `NEXT_PUBLIC_BASE_URL` | Preset in the template |
| `rallly` | `SECRET_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Rallly with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Rallly. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy rallly --name my-rallly
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
