Uptime Kuma with a MariaDB sidecar provisioned, for the setups that opt out of its default SQLite file.

This page describes the Levelrail template for Uptime Kuma (MariaDB) (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/louislam/uptime-kuma/wiki.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mariadb` | `mariadb:11` | none | `uptime_kuma_mariadb_data -&#62; /var/lib/mysql` |
| `uptime-kuma` | `louislam/uptime-kuma:2` | 3001 | `uptime_kuma_mariadb_app_data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mariadb` | `MYSQL_DATABASE` | Preset in the template |
| `mariadb` | `MYSQL_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_USER` | Generated at deploy |
| `uptime-kuma` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`uptime-kuma`): 3001:3001.
- Passwords and keys are generated at deploy time (`mariadb`): MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD, MYSQL_USER.
- Stores data in named volumes (`mariadb`, `uptime-kuma`): uptime_kuma_mariadb_app_data, uptime_kuma_mariadb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Uptime Kuma (MariaDB) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Uptime Kuma (MariaDB). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy uptime-kuma-mariadb --name my-uptime-kuma-mariadb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
