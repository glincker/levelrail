A multilingual grammar, style and spell checking server with an HTTP API at /v2/check. LGPL-2.1 licensed. Runs the community server image in one container without the optional n-gram data. There is no web login, so keep the address private or put it behind an access rule.

This page describes the Levelrail template for LanguageTool (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://dev.languagetool.org/http-server.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `languagetool` | `erikvl87/languagetool:6.8` | 8010 | `ngrams -&#62; /ngrams` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `languagetool` | `Java_Xms` | Preset in the template |
| `languagetool` | `Java_Xmx` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`languagetool`): ngrams.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LanguageTool with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LanguageTool. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy languagetool --name my-languagetool
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
