A lean server that turns text into embeddings with popular open models, on CPU with no extra setup.

This page describes the Levelrail template for Text Embeddings Inference (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://huggingface.co/docs/text-embeddings-inference.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `tei` | `ghcr.io/huggingface/text-embeddings-inference:cpu-1.8` | 80 | `tei_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`tei`): 8080:80.
- Stores data in named volumes (`tei`): tei_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Text Embeddings Inference with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Text Embeddings Inference. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy text-embeddings-inference --name my-text-embeddings-inference
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
