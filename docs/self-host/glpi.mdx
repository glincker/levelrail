An IT asset and service management platform with helpdesk ticketing built in.

This page describes the Levelrail template for GLPI (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://glpi-project.org/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `glpi` | `glpi/glpi:11.0.11` | 80 | `glpi_data -&#62; /var/glpi` |
| `glpi-db` | `mysql:8.4` | none | `glpi_mysql_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `glpi` | `GLPI_DB_HOST` | Preset in the template |
| `glpi` | `GLPI_DB_NAME` | Preset in the template |
| `glpi` | `GLPI_DB_PASSWORD` | Generated at deploy |
| `glpi` | `GLPI_DB_USER` | Preset in the template |
| `glpi-db` | `MYSQL_DATABASE` | Preset in the template |
| `glpi-db` | `MYSQL_PASSWORD` | Generated at deploy |
| `glpi-db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `glpi-db` | `MYSQL_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`glpi`): 8080:80.
- Passwords and keys are generated at deploy time (`glpi`, `glpi-db`): GLPI_DB_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`glpi`, `glpi-db`): glpi_data, glpi_mysql_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy GLPI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GLPI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy glpi --name my-glpi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
