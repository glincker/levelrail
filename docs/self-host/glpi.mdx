An IT asset and service management platform with helpdesk ticketing built in.

This page describes the Levelrail template for GLPI (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://glpi-project.org/documentation/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `glpi` | `glpi/glpi:11.0.11` | 80 | `glpi_data -&#62; /var/glpi` |
| `glpi-db` | `mysql:8.4` | none | `glpi_mysql_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `glpi` | `GLPI_DB_HOST` | Preset in the template |
| `glpi` | `GLPI_DB_NAME` | Preset in the template |
| `glpi` | `GLPI_DB_PASSWORD` | Generated at deploy |
| `glpi` | `GLPI_DB_USER` | Preset in the template |
| `glpi-db` | `MYSQL_DATABASE` | Preset in the template |
| `glpi-db` | `MYSQL_PASSWORD` | Generated at deploy |
| `glpi-db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `glpi-db` | `MYSQL_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy GLPI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GLPI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy glpi --name my-glpi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
