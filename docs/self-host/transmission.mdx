A fast, lightweight BitTorrent client with a simple web interface.

This page describes the Levelrail template for Transmission (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.linuxserver.io/images/docker-transmission/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `transmission` | `lscr.io/linuxserver/transmission:4.0.6` | 9091 | `transmission_config -&#62; /config`<br />`transmission_downloads -&#62; /downloads`<br />`transmission_watch -&#62; /watch` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `transmission` | `PASS` | Generated at deploy |
| `transmission` | `PGID` | Preset in the template |
| `transmission` | `PUID` | Preset in the template |
| `transmission` | `USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Transmission with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Transmission. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy transmission --name my-transmission
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
