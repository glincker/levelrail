A fast, static, highly customizable start page for all your self-hosted services.

This page describes the Levelrail template for Homepage (Dashboard). It deploys the services below as one Docker Compose app on your own server. Project site: https://gethomepage.dev/latest/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `homepage` | `ghcr.io/gethomepage/homepage:v0.10.4` | 3000 | `homepage_config -&#62; /app/config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Homepage with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Homepage. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy homepage --name my-homepage
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
