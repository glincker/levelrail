A tiny file server with uploads, downloads, search and WebDAV over one login. Apache-2.0 licensed. The admin password is generated for you.

This page describes the Levelrail template for Dufs (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/sigoden/dufs.

Recommended memory: about 32 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `dufs` | `sigoden/dufs:v0.47.0` | 5000 | `data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `dufs` | `DUFS_ALLOW_ALL` | Preset in the template |
| `dufs` | `DUFS_AUTH` | Generated at deploy |
| `dufs` | `DUFS_SERVE_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`dufs`): DUFS_AUTH.
- Stores data in named volumes (`dufs`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Dufs with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Dufs. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy dufs --name my-dufs
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
