A privacy-first wealth tracker for stocks, ETFs, and crypto, with portfolio analytics and no ads.

This page describes the Levelrail template for Ghostfolio (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/ghostfolio/ghostfolio.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `ghostfolio_db_data -&#62; /var/lib/postgresql/data` |
| `ghostfolio` | `ghostfolio/ghostfolio:3.72.0` | 3333 | none |
| `redis` | `redis:7-alpine` | none | `ghostfolio_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `ghostfolio` | `ACCESS_TOKEN_SALT` | Generated at deploy |
| `ghostfolio` | `DATABASE_URL` | Generated at deploy |
| `ghostfolio` | `JWT_SECRET_KEY` | Generated at deploy |
| `ghostfolio` | `REDIS_HOST` | Preset in the template |
| `ghostfolio` | `REDIS_PORT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Ghostfolio with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ghostfolio. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ghostfolio --name my-ghostfolio
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
