A web UI for managing Nginx reverse-proxy hosts, redirects, and Let's Encrypt certificates.

This page describes the Levelrail template for Nginx Proxy Manager (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://nginxproxymanager.com/guide/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `npm` | `jc21/nginx-proxy-manager:2.12.3` | 81 | `npm_data -&#62; /data`<br />`npm_letsencrypt -&#62; /etc/letsencrypt` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `npm` | `DB_SQLITE_FILE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Nginx Proxy Manager with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Nginx Proxy Manager. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nginx-proxy-manager --name my-nginx-proxy-manager
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
