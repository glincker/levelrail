The SSR-plus-database pairing behind most Next.js apps, wired with a healthchecked Postgres.

This page describes the Levelrail template for Next.js + PostgreSQL (Starter Kits). It deploys the services below as one Docker Compose app on your own server. Project site: https://nextjs.org/docs/app/building-your-application/deploying.

Recommended memory: about 384 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `nextjs_postgres_db_data -&#62; /var/lib/postgresql/data` |
| `web` | `node:22-alpine` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `web` | `DATABASE_URL` | Generated at deploy |
| `web` | `NEXT_TELEMETRY_DISABLED` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`web`): 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `web`): DATABASE_URL, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): nextjs_postgres_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Next.js + PostgreSQL with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Next.js + PostgreSQL. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nextjs-postgres-starter --name my-nextjs-postgres-starter
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
