An OpenAI-compatible speech server: Whisper transcription and text-to-speech behind one API.

This page describes the Levelrail template for Speaches (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://speaches.ai.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `speaches` | `ghcr.io/speaches-ai/speaches:0.8.3-cpu` | 8000 | `speaches_models -&#62; /home/ubuntu/.cache/huggingface/hub` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `speaches` | `ENABLE_UI` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Speaches with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Speaches. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy speaches --name my-speaches
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
