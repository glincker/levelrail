Private relay server that carries Syncthing traffic between devices that cannot connect directly. Exposes a small status page.

This page describes the Levelrail template for Syncthing Relay Server (Networking). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.syncthing.net/users/strelaysrv.html.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `syncthing-relay` | `syncthing/relaysrv:2.1.7` | 22070, 22067 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`syncthing-relay`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Syncthing Relay Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Syncthing Relay Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy syncthing-relay --name my-syncthing-relay
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
