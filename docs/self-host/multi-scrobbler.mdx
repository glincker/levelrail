Scrobbles your listening history from sources like Spotify, Jellyfin, Plex and Navidrome to destinations like Last.fm, ListenBrainz and Maloja. MIT licensed. Add sources and clients through the web UI or the config files under the data volume.

This page describes the Levelrail template for Multi-Scrobbler (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://foxxmd.github.io/multi-scrobbler/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `multi-scrobbler` | `ghcr.io/foxxmd/multi-scrobbler:0.20.3` | 9078 | `config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`multi-scrobbler`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Multi-Scrobbler with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Multi-Scrobbler. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy multi-scrobbler --name my-multi-scrobbler
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
