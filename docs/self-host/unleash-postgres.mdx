An open-source feature flag platform with gradual rollouts, A/B testing, and a permission model.

This page describes the Levelrail template for Unleash (Postgres) (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.getunleash.io/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `postgres` | `postgres:16-alpine` | none | `unleash_postgres_data -&#62; /var/lib/postgresql/data` |
| `unleash` | `unleashorg/unleash-server:latest` | 4242 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |
| `unleash` | `DATABASE_SSL` | Preset in the template |
| `unleash` | `DATABASE_URL` | Generated at deploy |
| `unleash` | `LOG_LEVEL` | Preset in the template |
| `unleash` | `UNLEASH_DEFAULT_ADMIN_PASSWORD` | Generated at deploy |
| `unleash` | `UNLEASH_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Unleash (Postgres) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Unleash (Postgres). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy unleash-postgres --name my-unleash-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
