A self-hosted file management and sharing system with multiple storage backends.

This page describes the Levelrail template for Cloudreve (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.cloudreve.org/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cloudreve` | `cloudreve/cloudreve:4.10.1` | 5212 | `cloudreve_data -&#62; /cloudreve/data` |
| `postgres` | `postgres:16-alpine` | none | `postgres_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `cloudreve` | `CR_CONF_Database.Host` | Preset in the template |
| `cloudreve` | `CR_CONF_Database.Name` | Preset in the template |
| `cloudreve` | `CR_CONF_Database.Password` | Generated at deploy |
| `cloudreve` | `CR_CONF_Database.Port` | Preset in the template |
| `cloudreve` | `CR_CONF_Database.Type` | Preset in the template |
| `cloudreve` | `CR_CONF_Database.User` | Preset in the template |
| `cloudreve` | `CR_CONF_Redis.Password` | Generated at deploy |
| `cloudreve` | `CR_CONF_Redis.Server` | Preset in the template |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy Cloudreve with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Cloudreve. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get cloudreve --output json | jq -r .compose > cloudreve.compose.yaml
# edit cloudreve.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-cloudreve --file cloudreve.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
