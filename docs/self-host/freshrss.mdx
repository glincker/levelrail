A lightweight, self-hosted RSS aggregator with multi-user support and a mobile-friendly API.

This page describes the Levelrail template for FreshRSS (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://freshrss.github.io/FreshRSS/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `freshrss_db_data -&#62; /var/lib/mysql` |
| `freshrss` | `freshrss/freshrss:1.25.0` | 80 | `freshrss_data -&#62; /var/www/FreshRSS/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `freshrss` | `DB_BASE` | Preset in the template |
| `freshrss` | `DB_HOST` | Preset in the template |
| `freshrss` | `DB_PASSWORD` | Generated at deploy |
| `freshrss` | `DB_TYPE` | Preset in the template |
| `freshrss` | `DB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`freshrss`): 8080:80.
- Passwords and keys are generated at deploy time (`db`, `freshrss`): DB_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `freshrss`): freshrss_data, freshrss_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy FreshRSS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FreshRSS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy freshrss --name my-freshrss
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
