A lightweight, self-hosted RSS aggregator with multi-user support and a mobile-friendly API.

This page describes the Levelrail template for FreshRSS (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://freshrss.github.io/FreshRSS/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `freshrss_db_data -&#62; /var/lib/mysql` |
| `freshrss` | `freshrss/freshrss:1.25.0` | 80 | `freshrss_data -&#62; /var/www/FreshRSS/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `freshrss` | `DB_BASE` | Preset in the template |
| `freshrss` | `DB_HOST` | Preset in the template |
| `freshrss` | `DB_PASSWORD` | Generated at deploy |
| `freshrss` | `DB_TYPE` | Preset in the template |
| `freshrss` | `DB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy FreshRSS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FreshRSS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy freshrss --name my-freshrss
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
