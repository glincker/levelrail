A self-hosted platform for cloud development environments, backed by Postgres. This runs the Coder server only, with no Docker socket, so add workspace templates that use remote infrastructure. Create the first admin on first open.

This page describes the Levelrail template for Coder (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://coder.com/docs.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `coder` | `ghcr.io/coder/coder:v2.39.1` | 7080 | none |
| `db` | `postgres:17.11-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `coder` | `CODER_ACCESS_URL` | Preset in the template |
| `coder` | `CODER_HTTP_ADDRESS` | Preset in the template |
| `coder` | `CODER_PG_CONNECTION_URL` | Generated at deploy |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`coder`, `db`): CODER_PG_CONNECTION_URL, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`coder`).
- Stores data in named volumes (`db`): pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Coder with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Coder. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy coder --name my-coder
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
