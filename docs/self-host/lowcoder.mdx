An open-source low-code platform for building internal apps, dashboards, and workflows with drag-and-drop.

This page describes the Levelrail template for Lowcoder (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.lowcoder.cloud.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `lowcoder` | `lowcoderorg/lowcoder-ce:2.7.6` | 3000 | `lowcoder_data -&#62; /lowcoder-stacks` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `lowcoder` | `LOWCODER_DB_ENCRYPTION_PASSWORD` | Generated at deploy |
| `lowcoder` | `LOWCODER_DB_ENCRYPTION_SALT` | Generated at deploy |
| `lowcoder` | `LOWCODER_EMAIL_SIGNUP_ENABLED` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Lowcoder with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Lowcoder. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy lowcoder --name my-lowcoder
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
