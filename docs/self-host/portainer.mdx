A web UI for managing containers, images, volumes, and networks.

This page describes the Levelrail template for Portainer (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.portainer.io.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `portainer` | `portainer/portainer-ce:2.21.0` | 9443 | `portainer_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Portainer with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Portainer. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy portainer --name my-portainer
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
