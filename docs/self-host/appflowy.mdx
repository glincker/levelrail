A self-hosted, open-source workspace for notes and collaborative knowledge, an alternative to Notion.

This page describes the Levelrail template for AppFlowy (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.appflowy.io/docs/documentation/appflowy-cloud.

Recommended memory: about 1536 MiB.

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `admin_frontend` | `appflowyinc/admin_frontend:0.9.149` | 3000 | none |
| `appflowy_cloud` | `appflowyinc/appflowy_cloud:0.9.149` | none | none |
| `gotrue` | `appflowyinc/gotrue:0.9.149` | none | none |
| `minio` | `ghcr.io/coollabsio/minio:RELEASE.2025-10-15T17-29-55Z` | none | `appflowy_minio_data -&#62; /data` |
| `postgres` | `pgvector/pgvector:pg16` | none | `appflowy_postgres_data -&#62; /var/lib/postgresql/data` |
| `redis` | `redis:7-alpine` | none | `appflowy_redis_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`admin_frontend`): 3000:3000.
- Passwords and keys are generated at deploy time (`appflowy_cloud`, `gotrue`, `minio`, `postgres`): APPFLOWY_DATABASE_URL, APPFLOWY_GOTRUE_JWT_SECRET, APPFLOWY_S3_SECRET_KEY, DATABASE_URL, GOTRUE_ADMIN_PASSWORD, GOTRUE_JWT_SECRET, MINIO_ROOT_PASSWORD, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`admin_frontend`).
- Stores data in named volumes (`minio`, `postgres`, `redis`): appflowy_minio_data, appflowy_postgres_data, appflowy_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy AppFlowy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select AppFlowy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy appflowy --name my-appflowy
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
