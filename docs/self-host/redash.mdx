Connect data sources, write SQL and build shareable dashboards. Runs the Redash web server, a query worker and a scheduler with a bundled PostgreSQL and Redis, persistent volumes and generated secrets. Create the first admin account on first visit.

This page describes the Levelrail template for Redash (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://redash.io/help/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `postgres` | `postgres:17.11-alpine` | none | `redash_pgdata -&#62; /var/lib/postgresql/data` |
| `redash` | `redash/redash:25.8.0` | 5000 | none |
| `redis` | `redis:7.4.5` | none | `redash_redis -&#62; /data` |
| `scheduler` | `redash/redash:25.8.0` | none | none |
| `worker` | `redash/redash:25.8.0` | none | none |

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`postgres`, `redash`, `scheduler`, `worker`): POSTGRES_PASSWORD, REDASH_COOKIE_SECRET, REDASH_DATABASE_URL, REDASH_SECRET_KEY.
- No health check, so a deploy is judged by the process starting (`scheduler`, `worker`).
- Stores data in named volumes (`postgres`, `redis`): redash_pgdata, redash_redis.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Redash with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Redash. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redash --name my-redash
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
