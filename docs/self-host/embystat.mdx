Watch statistics and insight dashboards for your Emby or Jellyfin server.

This page describes the Levelrail template for EmbyStat (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/mregni/EmbyStat.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `embystat` | `lscr.io/linuxserver/embystat:latest` | 6555 | `embystat_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `embystat` | `PGID` | Preset in the template |
| `embystat` | `PUID` | Preset in the template |
| `embystat` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy EmbyStat with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select EmbyStat. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy embystat --name my-embystat
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
