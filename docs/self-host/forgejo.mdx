A lightweight, community-governed Git forge with issues, pull requests, and CI runners.

This page describes the Levelrail template for Forgejo (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://forgejo.org/docs/latest/admin/installation-docker/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `forgejo` | `codeberg.org/forgejo/forgejo:9.0.3` | 3000 | `forgejo_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `forgejo` | `FORGEJO__security__SECRET_KEY` | Generated at deploy |
| `forgejo` | `FORGEJO__server__ROOT_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Forgejo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Forgejo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy forgejo --name my-forgejo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
