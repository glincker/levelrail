Fast local text to speech over the Wyoming protocol, used by Home Assistant voice assistants. Downloads the chosen voice on first start.

This page describes the Levelrail template for Wyoming Piper (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/rhasspy/wyoming-piper#readme.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `wyoming-piper` | `rhasspy/wyoming-piper:2.5.2` | 10200 | `data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`wyoming-piper`).
- Stores data in named volumes (`wyoming-piper`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Wyoming Piper with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Wyoming Piper. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy wyoming-piper --name my-wyoming-piper
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
