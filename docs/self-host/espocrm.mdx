An open-source CRM for managing sales, support, and customer relationships end to end.

This page describes the Levelrail template for EspoCRM (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.espocrm.com.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `espocrm` | `espocrm/espocrm:10` | 80 | `espocrm_data -&#62; /var/www/html/data`<br />`espocrm_custom -&#62; /var/www/html/custom` |
| `espocrm-db` | `mariadb:12.3` | none | `espocrm_db_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `espocrm` | `ESPOCRM_ADMIN_PASSWORD` | Generated at deploy |
| `espocrm` | `ESPOCRM_ADMIN_USERNAME` | Preset in the template |
| `espocrm` | `ESPOCRM_DATABASE_HOST` | Preset in the template |
| `espocrm` | `ESPOCRM_DATABASE_NAME` | Preset in the template |
| `espocrm` | `ESPOCRM_DATABASE_PASSWORD` | Generated at deploy |
| `espocrm` | `ESPOCRM_DATABASE_PLATFORM` | Preset in the template |
| `espocrm` | `ESPOCRM_DATABASE_USER` | Generated at deploy |
| `espocrm` | `ESPOCRM_SITE_URL` | Preset in the template |
| `espocrm-db` | `MARIADB_DATABASE` | Preset in the template |
| `espocrm-db` | `MARIADB_PASSWORD` | Generated at deploy |
| `espocrm-db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `espocrm-db` | `MARIADB_USER` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`espocrm`): 8080:80.
- Passwords and keys are generated at deploy time (`espocrm`, `espocrm-db`): ESPOCRM_ADMIN_PASSWORD, ESPOCRM_DATABASE_PASSWORD, ESPOCRM_DATABASE_USER, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD, MARIADB_USER.
- Stores data in named volumes (`espocrm`, `espocrm-db`): espocrm_custom, espocrm_data, espocrm_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy EspoCRM with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select EspoCRM. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy espocrm --name my-espocrm
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
