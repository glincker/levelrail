Matches torrent releases from your indexers against filters and pushes hits straight to your download client.

This page describes the Levelrail template for autobrr (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://autobrr.com/installation/docker.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `autobrr` | `ghcr.io/autobrr/autobrr:v1.87.0` | 7474 | `autobrr_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `autobrr` | `AUTOBRR__HOST` | Preset in the template |
| `autobrr` | `AUTOBRR__PORT` | Preset in the template |
| `autobrr` | `AUTOBRR__SESSION_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy autobrr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select autobrr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy autobrr --name my-autobrr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
