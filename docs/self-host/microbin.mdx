A tiny self-hosted pastebin and file sharing server with expiring links.

This page describes the Levelrail template for MicroBin (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://microbin.eu.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `microbin` | `danielszabo99/microbin:2.1.4` | 8080 | `microbin_data -&#62; /app/microbin_data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `microbin` | `MICROBIN_ADMIN_PASSWORD` | Generated at deploy |
| `microbin` | `MICROBIN_ADMIN_USERNAME` | Preset in the template |
| `microbin` | `MICROBIN_DATA_DIR` | Preset in the template |
| `microbin` | `MICROBIN_PUBLIC_PATH` | Preset in the template |
| `microbin` | `MICROBIN_UPLOADER_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`microbin`): MICROBIN_ADMIN_PASSWORD, MICROBIN_UPLOADER_PASSWORD.
- Stores data in named volumes (`microbin`): microbin_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MicroBin with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MicroBin. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy microbin --name my-microbin
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
