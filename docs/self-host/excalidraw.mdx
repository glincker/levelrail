A self-hosted virtual whiteboard for sketching diagrams that feel hand-drawn.

This page describes the Levelrail template for Excalidraw (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/excalidraw/excalidraw#docker.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `excalidraw` | `excalidraw/excalidraw:latest` | 80 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`excalidraw`): excalidraw/excalidraw:latest.
- Publishes ports directly on the host (`excalidraw`): 8080:80.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Excalidraw with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Excalidraw. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy excalidraw --name my-excalidraw
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
