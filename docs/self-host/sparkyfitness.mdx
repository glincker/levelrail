A fitness tracker for nutrition, exercise, and body measurements.

This page describes the Levelrail template for SparkyFitness (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://codewithcj.github.io/SparkyFitness/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `postgres` | `postgres:16-alpine` | none | `postgres_data -&#62; /var/lib/postgresql/data` |
| `sparkyfitness-frontend` | `codewithcj/sparkyfitness:v1.6.1` | 80 | none |
| `sparkyfitness-server` | `codewithcj/sparkyfitness_server:v1.6.1` | none | none |

## Deploy SparkyFitness with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SparkyFitness. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sparkyfitness --name my-sparkyfitness
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
