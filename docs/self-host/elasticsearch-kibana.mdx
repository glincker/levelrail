Elasticsearch paired with Kibana for log and document search with a visual dashboard. Kibana has no login, so anyone who can open it controls the data: before attaching a domain, enable Basic Auth or the auth gate on it. Elasticsearch is reachable only from services in this project at elasticsearch:9200 and is not published on the host.

This page describes the Levelrail template for Elasticsearch + Kibana (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.elastic.co/docs/deploy-manage/deploy/self-managed/install-kibana-with-docker.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `elasticsearch` | `elasticsearch:9.1.2` | 9200 | `es_data -&#62; /usr/share/elasticsearch/data` |
| `kibana` | `kibana:9.1.2` | 5601 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `elasticsearch` | `ES_JAVA_OPTS` | Preset in the template |
| `elasticsearch` | `discovery.type` | Preset in the template |
| `elasticsearch` | `xpack.security.enabled` | Preset in the template |
| `kibana` | `ELASTICSEARCH_HOSTS` | Preset in the template |
| `kibana` | `SERVER_PUBLICBASEURL` | Preset in the template |
| `kibana` | `XPACK_ENCRYPTEDSAVEDOBJECTS_ENCRYPTIONKEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`kibana`): XPACK_ENCRYPTEDSAVEDOBJECTS_ENCRYPTIONKEY.
- Stores data in named volumes (`elasticsearch`): es_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Elasticsearch + Kibana with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Elasticsearch + Kibana. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy elasticsearch-kibana --name my-elasticsearch-kibana
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
