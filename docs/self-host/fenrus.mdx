Self-hosted dashboard that groups your apps as tiles with live status widgets, themes and per user pages.

This page describes the Levelrail template for Fenrus (Dashboard). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/revenz/Fenrus#readme.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `fenrus` | `revenz/fenrus:26.10@sha256:7728749bb98c3b0862c853ebf9f741d7e43fddcd84a1ddb8ac73d03ae9741f99` | 3000 | `data -&#62; /app/data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`fenrus`).
- Stores data in named volumes (`fenrus`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Fenrus with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Fenrus. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy fenrus --name my-fenrus
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
