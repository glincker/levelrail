A self-hosted media tracker for movies, TV, anime, manga, games, and books.

This page describes the Levelrail template for Yamtrack (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/FuzzyGrim/Yamtrack/wiki.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `redis` | `redis:7-alpine` | none | none |
| `yamtrack` | `ghcr.io/fuzzygrim/yamtrack:0.26.3` | 8000 | `yamtrack_data -&#62; /yamtrack/db` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `yamtrack` | `REDIS_URL` | Preset in the template |
| `yamtrack` | `SECRET` | Generated at deploy |
| `yamtrack` | `URLS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Yamtrack with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Yamtrack. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy yamtrack --name my-yamtrack
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
