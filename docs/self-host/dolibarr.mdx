An open-source ERP and CRM for small businesses: invoicing, contacts, stock, and accounting in one app.

This page describes the Levelrail template for Dolibarr (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://wiki.dolibarr.org.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `dolibarr_db_data -&#62; /var/lib/mysql` |
| `dolibarr` | `dolibarr/dolibarr:23.0.4` | 80 | `dolibarr_documents -&#62; /var/www/documents`<br />`dolibarr_custom -&#62; /var/www/html/custom` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MARIADB_DATABASE` | Preset in the template |
| `db` | `MARIADB_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_USER` | Preset in the template |
| `dolibarr` | `DOLI_ADMIN_LOGIN` | Preset in the template |
| `dolibarr` | `DOLI_ADMIN_PASSWORD` | Generated at deploy |
| `dolibarr` | `DOLI_DB_HOST` | Preset in the template |
| `dolibarr` | `DOLI_DB_NAME` | Preset in the template |
| `dolibarr` | `DOLI_DB_PASSWORD` | Generated at deploy |
| `dolibarr` | `DOLI_DB_USER` | Preset in the template |
| `dolibarr` | `DOLI_URL_ROOT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`dolibarr`): 8080:80.
- Passwords and keys are generated at deploy time (`db`, `dolibarr`): DOLI_ADMIN_PASSWORD, DOLI_DB_PASSWORD, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `dolibarr`): dolibarr_custom, dolibarr_db_data, dolibarr_documents.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Dolibarr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Dolibarr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy dolibarr --name my-dolibarr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
