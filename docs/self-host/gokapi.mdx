A lightweight self-hosted file sharing server with expiring links and download limits. Runs in one container on a small data folder. On first open, the setup page asks you to create the admin login.

This page describes the Levelrail template for Gokapi (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://gokapi.readthedocs.io/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gokapi` | `ghcr.io/forceu/gokapi:v1.9.6` | 53842 | `gokapi_data -&#62; /app/data`<br />`gokapi_config -&#62; /app/config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `gokapi` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`gokapi`): gokapi_config, gokapi_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Gokapi with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Gokapi. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gokapi --name my-gokapi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
