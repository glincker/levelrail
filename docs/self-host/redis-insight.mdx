A GUI for exploring keys, running commands, and profiling workloads on any Redis-compatible server.

This page describes the Levelrail template for Redis Insight (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://redis.io/docs/latest/operate/redisinsight/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `redisinsight` | `redis/redisinsight:2.70` | 5540 | `redisinsight_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `redisinsight` | `RI_APP_HOST` | Preset in the template |
| `redisinsight` | `RI_APP_PORT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Redis Insight with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Redis Insight. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redis-insight --name my-redis-insight
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
