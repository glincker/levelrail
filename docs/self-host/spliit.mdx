A free way to split expenses with friends and groups, no accounts needed. Share a group link and everyone adds expenses. MIT licensed, backed by Postgres.

This page describes the Levelrail template for Spliit (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/spliit-app/spliit.

Recommended memory: about 384 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `spliit` | `ghcr.io/spliit-app/spliit:1.30.0` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `spliit` | `POSTGRES_PRISMA_URL` | Generated at deploy |
| `spliit` | `POSTGRES_URL_NON_POOLING` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `spliit`): POSTGRES_PASSWORD, POSTGRES_PRISMA_URL, POSTGRES_URL_NON_POOLING.
- Stores data in named volumes (`db`): pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Spliit with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Spliit. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy spliit --name my-spliit
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
