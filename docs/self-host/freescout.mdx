A free, self-hosted help desk and shared mailbox, a lighter alternative to Zendesk or Help Scout.

This page describes the Levelrail template for FreeScout (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/freescout-helpdesk/freescout/wiki.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `freescout` | `ghcr.io/nfrastack/container-freescout:latest` | 80 | `freescout_data -&#62; /data`<br />`freescout_logs -&#62; /www/logs` |
| `mariadb` | `mariadb:11` | none | `freescout_db_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `freescout` | `ADMIN_EMAIL` | Preset in the template |
| `freescout` | `ADMIN_PASS` | Generated at deploy |
| `freescout` | `DB_HOST` | Preset in the template |
| `freescout` | `DB_NAME` | Preset in the template |
| `freescout` | `DB_PASS` | Generated at deploy |
| `freescout` | `DB_USER` | Preset in the template |
| `freescout` | `DISPLAY_ERRORS` | Preset in the template |
| `freescout` | `SITE_URL` | Preset in the template |
| `freescout` | `TIMEZONE` | Preset in the template |
| `mariadb` | `MARIADB_DATABASE` | Preset in the template |
| `mariadb` | `MARIADB_PASSWORD` | Generated at deploy |
| `mariadb` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MARIADB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy FreeScout with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FreeScout. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy freescout --name my-freescout
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
