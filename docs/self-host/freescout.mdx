A free, self-hosted help desk and shared mailbox, a lighter alternative to Zendesk or Help Scout.

This page describes the Levelrail template for FreeScout (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/freescout-helpdesk/freescout/wiki.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `freescout` | `ghcr.io/nfrastack/container-freescout:latest` | 80 | `freescout_data -&#62; /data`<br />`freescout_logs -&#62; /www/logs` |
| `mariadb` | `mariadb:11` | none | `freescout_db_data -&#62; /var/lib/mysql` |

| `freescout` | `DB_HOST` | Preset in the template |
| `freescout` | `DB_NAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`freescout`): ghcr.io/nfrastack/container-freescout:latest.
- Publishes ports directly on the host (`freescout`): 8080:80.
- Passwords and keys are generated at deploy time (`freescout`, `mariadb`): ADMIN_PASS, DB_PASS, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- Stores data in named volumes (`freescout`, `mariadb`): freescout_data, freescout_db_data, freescout_logs.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy FreeScout with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select FreeScout. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy freescout --name my-freescout
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
