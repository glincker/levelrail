Lightweight, privacy-friendly, cookie-free web analytics with no consent banner required.

This page describes the Levelrail template for Plausible Analytics (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://plausible.io/docs/self-hosting.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `clickhouse` | `clickhouse/clickhouse-server:24.12-alpine` | none | `plausible_clickhouse_data -&#62; /var/lib/clickhouse` |
| `db` | `postgres:16-alpine` | none | `plausible_db_data -&#62; /var/lib/postgresql/data` |
| `plausible` | `ghcr.io/plausible/community-edition:v3.0.1` | 8000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `clickhouse` | `CLICKHOUSE_SKIP_USER_SETUP` | Preset in the template |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `plausible` | `BASE_URL` | Preset in the template |
| `plausible` | `CLICKHOUSE_DATABASE_URL` | Preset in the template |
| `plausible` | `DATABASE_URL` | Generated at deploy |
| `plausible` | `SECRET_KEY_BASE` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`plausible`): 8000:8000.
- Passwords and keys are generated at deploy time (`db`, `plausible`): DATABASE_URL, SECRET_KEY_BASE, POSTGRES_PASSWORD.
- Stores data in named volumes (`clickhouse`, `db`): plausible_clickhouse_data, plausible_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Plausible Analytics with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Plausible Analytics. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy plausible --name my-plausible
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
