An open-source vector database with hybrid search, built-in modules, and a GraphQL and REST API.

This page describes the Levelrail template for Weaviate (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://weaviate.io/developers/weaviate.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `weaviate` | `semitechnologies/weaviate:1.39.6` | 8080 | `weaviate_data -&#62; /var/lib/weaviate` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `weaviate` | `AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED` | Preset in the template |
| `weaviate` | `AUTHENTICATION_APIKEY_ALLOWED_KEYS` | Generated at deploy |
| `weaviate` | `AUTHENTICATION_APIKEY_ENABLED` | Preset in the template |
| `weaviate` | `AUTHENTICATION_APIKEY_USERS` | Preset in the template |
| `weaviate` | `CLUSTER_HOSTNAME` | Preset in the template |
| `weaviate` | `DEFAULT_VECTORIZER_MODULE` | Preset in the template |
| `weaviate` | `PERSISTENCE_DATA_PATH` | Preset in the template |
| `weaviate` | `QUERY_DEFAULTS_LIMIT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Weaviate with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Weaviate. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy weaviate --name my-weaviate
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
