A long-established CMS with a large extension ecosystem for business sites, portals, and communities.

This page describes the Levelrail template for Joomla (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.joomla.org.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `joomla_db_data -&#62; /var/lib/mysql` |
| `joomla` | `joomla:5-apache` | 80 | `joomla_data -&#62; /var/www/html` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MARIADB_DATABASE` | Preset in the template |
| `db` | `MARIADB_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_USER` | Preset in the template |
| `joomla` | `JOOMLA_DB_HOST` | Preset in the template |
| `joomla` | `JOOMLA_DB_NAME` | Preset in the template |
| `joomla` | `JOOMLA_DB_PASSWORD` | Generated at deploy |
| `joomla` | `JOOMLA_DB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Joomla with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Joomla. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy joomla --name my-joomla
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
