Organize, read, annotate, and sync your entire book collection from one place.

This page describes the Levelrail template for Grimmory (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/grimmory-tools/grimmory.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `grimmory_db_data -&#62; /var/lib/mysql` |
| `grimmory` | `grimmory/grimmory:nightly-20260403-3a371f7` | 80 | `grimmory_data -&#62; /app/data`<br />`grimmory_books -&#62; /books` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MARIADB_DATABASE` | Preset in the template |
| `db` | `MARIADB_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_USER` | Generated at deploy |
| `grimmory` | `DATABASE_PASSWORD` | Generated at deploy |
| `grimmory` | `DATABASE_URL` | Preset in the template |
| `grimmory` | `DATABASE_USERNAME` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`grimmory`): 80:80.
- Passwords and keys are generated at deploy time (`db`, `grimmory`): DATABASE_PASSWORD, DATABASE_USERNAME, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD, MARIADB_USER.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `grimmory`): grimmory_books, grimmory_data, grimmory_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Grimmory with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Grimmory. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy grimmory --name my-grimmory
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
