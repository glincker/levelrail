An open-source API development platform, a self-hosted alternative to Postman, backed by Postgres.

This page describes the Levelrail template for Hoppscotch (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.hoppscotch.io.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:15-alpine` | none | `hoppscotch_db_data -&#62; /var/lib/postgresql/data` |
| `hoppscotch` | `hoppscotch/hoppscotch:2026.2.1` | 80 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `hoppscotch` | `DATABASE_URL` | Generated at deploy |
| `hoppscotch` | `DATA_ENCRYPTION_KEY` | Generated at deploy |
| `hoppscotch` | `ENABLE_SUBPATH_BASED_ACCESS` | Preset in the template |
| `hoppscotch` | `VITE_ALLOWED_AUTH_PROVIDERS` | Preset in the template |
| `hoppscotch` | `VITE_BASE_URL` | Preset in the template |
| `hoppscotch` | `WHITELISTED_ORIGINS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Hoppscotch with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Hoppscotch. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy hoppscotch --name my-hoppscotch
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
