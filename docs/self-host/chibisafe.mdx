A file vault for uploading and sharing files from the cloud.

This page describes the Levelrail template for Chibisafe (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://chibisafe.app/docs/intro.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `chibisafe` | `chibisafe/chibisafe:v6.5.5` | 8001 | none |
| `chibisafe-server` | `chibisafe/chibisafe-server:v6.5.5` | none | `chibisafe_database -&#62; /app/database`<br />`chibisafe_uploads -&#62; /app/uploads`<br />`chibisafe_logs -&#62; /app/logs` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `chibisafe` | `BASE_API_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`chibisafe`): 8001:8001.
- Stores data in named volumes (`chibisafe-server`): chibisafe_database, chibisafe_logs, chibisafe_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Chibisafe with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Chibisafe. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy chibisafe --name my-chibisafe
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
