An indexer manager that syncs your torrent and Usenet indexers across the whole Arr stack.

This page describes the Levelrail template for Prowlarr (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://wiki.servarr.com/prowlarr.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `prowlarr` | `lscr.io/linuxserver/prowlarr:2.6.5` | 9696 | `prowlarr_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `prowlarr` | `PGID` | Preset in the template |
| `prowlarr` | `PUID` | Preset in the template |
| `prowlarr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Prowlarr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Prowlarr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy prowlarr --name my-prowlarr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
