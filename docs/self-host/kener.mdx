A status page and uptime monitoring tool built with SvelteKit.

This page describes the Levelrail template for Kener (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://kener.ing/docs.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `kener` | `rajnandan1/kener:4.2.1-alpine` | 3000 | `kener_data -&#62; /app/database`<br />`kener_uploads -&#62; /app/uploads` |
| `redis` | `redis:7-alpine` | none | `redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `kener` | `DATABASE_URL` | Preset in the template |
| `kener` | `KENER_SECRET_KEY` | Generated at deploy |
| `kener` | `ORIGIN` | Preset in the template |
| `kener` | `REDIS_URL` | Preset in the template |
| `kener` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`kener`): KENER_SECRET_KEY.
- Stores data in named volumes (`kener`, `redis`): kener_data, kener_uploads, redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Kener with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Kener. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy kener --name my-kener
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
