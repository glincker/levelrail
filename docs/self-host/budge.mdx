A self-hosted envelope budgeting app for personal finance.

This page describes the Levelrail template for Budge (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/linuxserver/budge.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `budge` | `lscr.io/linuxserver/budge:latest` | 80 | `budge_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `budge` | `PGID` | Preset in the template |
| `budge` | `PUID` | Preset in the template |
| `budge` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`budge`): lscr.io/linuxserver/budge:latest.
- Publishes ports directly on the host (`budge`): 80:80.
- Stores data in named volumes (`budge`): budge_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Budge with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Budge. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy budge --name my-budge
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
