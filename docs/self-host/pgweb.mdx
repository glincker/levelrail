A small web client for browsing and querying PostgreSQL databases, with a table browser, query editor and export. Runs as one container with no storage of its own. Sign in with the username and password from the install form, then enter the connection details of your database.

This page describes the Levelrail template for Pgweb (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/sosedoff/pgweb/wiki.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `pgweb` | `sosedoff/pgweb:0.17.0` | 8081 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `pgweb` | `PGWEB_AUTH_PASS` | Generated at deploy |
| `pgweb` | `PGWEB_AUTH_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`pgweb`): PGWEB_AUTH_PASS.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Pgweb with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Pgweb. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy pgweb --name my-pgweb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
