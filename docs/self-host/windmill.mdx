Turn scripts in Python, TypeScript, Go, and SQL into webhooks, workflows, and internal UIs.

This page describes the Levelrail template for Windmill (Automation). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.windmill.dev/docs.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `windmill_db_data -&#62; /var/lib/postgresql/data` |
| `windmill` | `ghcr.io/windmill-labs/windmill:1.365.0` | 8000 | `windmill_worker_logs -&#62; /tmp/windmill/logs`<br />`windmill_worker_cache -&#62; /tmp/windmill/cache` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `windmill` | `BASE_URL` | Preset in the template |
| `windmill` | `DATABASE_URL` | Generated at deploy |
| `windmill` | `MODE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`windmill`): 8000:8000.
- Passwords and keys are generated at deploy time (`db`, `windmill`): DATABASE_URL, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `windmill`): windmill_db_data, windmill_worker_cache, windmill_worker_logs.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Windmill with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Windmill. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy windmill --name my-windmill
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
