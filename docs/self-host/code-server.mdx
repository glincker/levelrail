Run VS Code in the browser, on your own hardware, from any device with a tab open.

This page describes the Levelrail template for code-server (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://coder.com/docs/code-server.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `code-server` | `codercom/code-server:4.93.1` | 8080 | `code_server_data -&#62; /home/coder/project` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `code-server` | `PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy code-server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select code-server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy code-server --name my-code-server
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
