A collection of handy online tools for developers: converters, generators, formatters, and more.

This page describes the Levelrail template for IT Tools (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://it-tools.tech.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `it-tools` | `corentinth/it-tools:2024.10.22-7ca5933` | 80 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy IT Tools with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select IT Tools. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy it-tools --name my-it-tools
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
