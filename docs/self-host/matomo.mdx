A privacy-friendly, self-hosted alternative to Google Analytics with full data ownership.

This page describes the Levelrail template for Matomo (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://matomo.org/faq/how-to-install/install-matomo-with-docker/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:10.11` | none | `matomo_db_data -&#62; /var/lib/mysql` |
| `matomo` | `matomo:5.13.0-apache` | 80 | `matomo_data -&#62; /var/www/html` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `matomo` | `MATOMO_DATABASE_DBNAME` | Preset in the template |
| `matomo` | `MATOMO_DATABASE_HOST` | Preset in the template |
| `matomo` | `MATOMO_DATABASE_PASSWORD` | Generated at deploy |
| `matomo` | `MATOMO_DATABASE_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`matomo`): 8080:80.
- Passwords and keys are generated at deploy time (`db`, `matomo`): MATOMO_DATABASE_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `matomo`): matomo_data, matomo_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Matomo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Matomo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy matomo --name my-matomo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
