Private global discovery server that lets your Syncthing devices find each other without the public one. Plain HTTP mode, meant to sit behind your own TLS proxy.

This page describes the Levelrail template for Syncthing Discovery Server (Networking). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.syncthing.net/users/stdiscosrv.html.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `syncthing-discovery` | `syncthing/discosrv:2.1.7` | 8443 | `data -&#62; /var/stdiscosrv` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`syncthing-discovery`).
- Stores data in named volumes (`syncthing-discovery`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Syncthing Discovery Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Syncthing Discovery Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy syncthing-discovery --name my-syncthing-discovery
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
