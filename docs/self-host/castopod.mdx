An open-source podcast hosting platform with built-in analytics, a web player, and ActivityPub federation.

This page describes the Levelrail template for Castopod (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.castopod.org/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `castopod` | `castopod/castopod:1.15.4` | 8080 | `castopod_media -&#62; /var/www/castopod/public/media` |
| `mariadb` | `mariadb:11.2` | none | `castopod_db -&#62; /var/lib/mysql` |
| `redis` | `redis:7.2-alpine` | none | `castopod_cache -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `castopod` | `CP_ANALYTICS_SALT` | Generated at deploy |
| `castopod` | `CP_BASEURL` | Preset in the template |
| `castopod` | `CP_CACHE_HANDLER` | Preset in the template |
| `castopod` | `CP_DISABLE_HTTPS` | Preset in the template |
| `castopod` | `CP_REDIS_HOST` | Preset in the template |
| `castopod` | `CP_REDIS_PASSWORD` | Generated at deploy |
| `castopod` | `MYSQL_DATABASE` | Preset in the template |
| `castopod` | `MYSQL_PASSWORD` | Generated at deploy |
| `castopod` | `MYSQL_USER` | Generated at deploy |
| `mariadb` | `MYSQL_DATABASE` | Preset in the template |
| `mariadb` | `MYSQL_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mariadb` | `MYSQL_USER` | Generated at deploy |
| `redis` | `REDIS_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Castopod with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Castopod. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy castopod --name my-castopod
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
