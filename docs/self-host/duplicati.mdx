Scheduled, encrypted backups of your files to local storage, network shares, or cloud storage.

This page describes the Levelrail template for Duplicati (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://duplicati.readthedocs.io.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `duplicati` | `lscr.io/linuxserver/duplicati:2.4.0` | 8200 | `duplicati_config -&#62; /config`<br />`duplicati_backups -&#62; /backups` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `duplicati` | `DUPLICATI__WEBSERVICE_PASSWORD` | Generated at deploy |
| `duplicati` | `PGID` | Preset in the template |
| `duplicati` | `PUID` | Preset in the template |
| `duplicati` | `SETTINGS_ENCRYPTION_KEY` | Generated at deploy |
| `duplicati` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`duplicati`): 8200:8200.
- Passwords and keys are generated at deploy time (`duplicati`): DUPLICATI__WEBSERVICE_PASSWORD, SETTINGS_ENCRYPTION_KEY.
- Stores data in named volumes (`duplicati`): duplicati_backups, duplicati_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Duplicati with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Duplicati. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy duplicati --name my-duplicati
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
