A media request manager for Jellyfin, Plex and Emby with Sonarr and Radarr hand-off, the merged successor of Overseerr and Jellyseerr. MIT licensed. On first open, sign in with your media server account to become the admin.

This page describes the Levelrail template for Seerr (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.seerr.dev/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `seerr` | `ghcr.io/seerr-team/seerr:v3.5.1` | 5055 | `config -&#62; /app/config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `seerr` | `LOG_LEVEL` | Preset in the template |
| `seerr` | `PORT` | Preset in the template |
| `seerr` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`seerr`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Seerr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Seerr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy seerr --name my-seerr
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
