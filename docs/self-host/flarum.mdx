A modern forum platform with a clean interface and extensions.

This page describes the Levelrail template for Flarum (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.flarum.org/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11.4` | none | `flarum_db_data -&#62; /var/lib/mysql` |
| `flarum` | `crazymax/flarum:1.8.20` | 8000 | `flarum_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `flarum` | `DB_HOST` | Preset in the template |
| `flarum` | `DB_NAME` | Preset in the template |
| `flarum` | `DB_PASSWORD` | Generated at deploy |
| `flarum` | `DB_USER` | Preset in the template |
| `flarum` | `FLARUM_ADMIN_PASS` | Generated at deploy |
| `flarum` | `FLARUM_BASE_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `flarum`): DB_PASSWORD, FLARUM_ADMIN_PASS, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`db`, `flarum`): flarum_data, flarum_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Flarum with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Flarum. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flarum --name my-flarum
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
