Continuous, peer-to-peer file synchronization between your own devices, no cloud in between.

This page describes the Levelrail template for Syncthing (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.syncthing.net.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `syncthing` | `lscr.io/linuxserver/syncthing:1.29.4` | 8384, 22000 | `syncthing_config -&#62; /config`<br />`syncthing_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Syncthing with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Syncthing. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy syncthing --name my-syncthing
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
