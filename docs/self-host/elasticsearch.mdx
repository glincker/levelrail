A distributed, RESTful search and analytics engine for full-text search and log analytics. Security is off, so reach it from other services in this project at elasticsearch:9200, or attach a domain only behind Basic Auth. Not published on the host.

This page describes the Levelrail template for Elasticsearch (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.elastic.co/guide/en/elasticsearch/reference/current/index.html.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `elasticsearch` | `docker.elastic.co/elasticsearch/elasticsearch:8.19.22` | 9200 | `elasticsearch_data -&#62; /usr/share/elasticsearch/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `elasticsearch` | `ES_JAVA_OPTS` | Preset in the template |
| `elasticsearch` | `discovery.type` | Preset in the template |
| `elasticsearch` | `xpack.security.enabled` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`elasticsearch`): elasticsearch_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Elasticsearch with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Elasticsearch. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy elasticsearch --name my-elasticsearch
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
