A lightweight, self-hosted password manager server compatible with the Bitwarden clients.

This page describes the Levelrail template for Vaultwarden (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/dani-garcia/vaultwarden/wiki.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `vaultwarden` | `vaultwarden/server:1.32.1` | 80 | `vaultwarden_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `vaultwarden` | `ADMIN_TOKEN` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Vaultwarden with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Vaultwarden. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy vaultwarden --name my-vaultwarden
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
