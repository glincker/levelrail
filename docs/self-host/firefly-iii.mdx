A self-hosted personal finance manager for tracking budgets, bills, and spending.

This page describes the Levelrail template for Firefly III (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.firefly-iii.org.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `firefly_db_data -&#62; /var/lib/mysql` |
| `firefly` | `fireflyiii/core:version-6.2.3` | 8080 | `firefly_upload_data -&#62; /var/www/html/storage/upload` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `firefly` | `APP_KEY` | Generated at deploy |
| `firefly` | `APP_URL` | Preset in the template |
| `firefly` | `DB_CONNECTION` | Preset in the template |
| `firefly` | `DB_DATABASE` | Preset in the template |
| `firefly` | `DB_HOST` | Preset in the template |
| `firefly` | `DB_PASSWORD` | Generated at deploy |
| `firefly` | `DB_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Firefly III with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Firefly III. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy firefly-iii --name my-firefly-iii
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
