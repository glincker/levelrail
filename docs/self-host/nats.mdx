A lightweight messaging server for pub/sub, request/reply and durable streams, with JetStream persistence enabled.

This page describes the Levelrail template for NATS (Infrastructure). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.nats.io/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `nats` | `nats:2.10-alpine` | 4222, 8222 | `nats_data -&#62; /data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy NATS with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select NATS. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nats --name my-nats
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
