Lightweight log and metrics processor and forwarder. The install form carries fluent-bit.conf as an editable file, so it starts listening for forwarded records with a health endpoint.

This page describes the Levelrail template for Fluent Bit (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.fluentbit.io/manual/.

Recommended memory: about 64 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `fluent-bit` | `fluent/fluent-bit:5.2.0` | 2020, 24224 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`fluent-bit`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Fluent Bit with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Fluent Bit. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy fluent-bit --name my-fluent-bit
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
