A business intelligence platform for exploring data and building dashboards, with its metadata kept in SQLite.

This page describes the Levelrail template for Apache Superset (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://superset.apache.org/docs/intro.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `superset` | `apache/superset:4.1.1` | 8088 | `home -&#62; /app/superset_home` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `superset` | `ADMIN_PASSWORD` | Generated at deploy |
| `superset` | `ADMIN_USERNAME` | Preset in the template |
| `superset` | `SUPERSET_SECRET_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Apache Superset with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Apache Superset. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy superset --name my-superset
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
