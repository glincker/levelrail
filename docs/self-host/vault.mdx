HashiCorp Vault for secrets storage, encryption as a service, and dynamic credentials, with integrated Raft storage. Vault is reachable only from services in this project at vault:8200 over plain HTTP and is not published on the host. It starts uninitialized and sealed: run vault operator init and vault operator unseal from the app console, keep the unseal keys and root token offline, and put a domain with HTTPS in front of it before anything outside this project talks to it.

This page describes the Levelrail template for Vault (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://developer.hashicorp.com/vault/docs/deploy/run-container.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `vault` | `hashicorp/vault:2.1.2` | 8200 | `vault_data -&#62; /vault/file` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `vault` | `VAULT_ADDR` | Preset in the template |
| `vault` | `VAULT_LOCAL_CONFIG` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`vault`): vault_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Vault with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Vault. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy vault --name my-vault
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
