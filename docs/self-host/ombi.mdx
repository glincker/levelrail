A request portal where media server users ask for movies and shows and your download apps fill them. GPL-2.0 licensed. On first open, the wizard creates the admin account and connects your media server and Sonarr or Radarr.

This page describes the Levelrail template for Ombi (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.ombi.app/.

Recommended memory: about 384 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ombi` | `lscr.io/linuxserver/ombi:4.53.10` | 3579 | `config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `ombi` | `PGID` | Preset in the template |
| `ombi` | `PUID` | Preset in the template |
| `ombi` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`ombi`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Ombi with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ombi. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ombi --name my-ombi
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
