Forgejo backed by Postgres instead of its default SQLite, for a multi-writer-safe production setup.

This page describes the Levelrail template for Forgejo (Postgres) (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://forgejo.org/docs/latest/admin/installation-docker/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `forgejo_postgres_db_data -&#62; /var/lib/postgresql/data` |
| `forgejo` | `codeberg.org/forgejo/forgejo:9.0.3` | 3000 | `forgejo_postgres_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `forgejo` | `FORGEJO__database__DB_TYPE` | Preset in the template |
| `forgejo` | `FORGEJO__database__HOST` | Preset in the template |
| `forgejo` | `FORGEJO__database__NAME` | Preset in the template |
| `forgejo` | `FORGEJO__database__PASSWD` | Generated at deploy |
| `forgejo` | `FORGEJO__database__USER` | Preset in the template |
| `forgejo` | `FORGEJO__security__SECRET_KEY` | Generated at deploy |
| `forgejo` | `FORGEJO__server__ROOT_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`forgejo`): 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `forgejo`): FORGEJO__database__PASSWD, FORGEJO__security__SECRET_KEY, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `forgejo`): forgejo_postgres_data, forgejo_postgres_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Forgejo (Postgres) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Forgejo (Postgres). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy forgejo-postgres --name my-forgejo-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
