Proxy built for agent traffic that routes MCP, A2A and LLM requests. The install form carries config.yaml as an editable file, so it starts with a listener that answers on port 3000.

This page describes the Levelrail template for Agentgateway (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://agentgateway.dev/docs/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `agentgateway` | `ghcr.io/agentgateway/agentgateway:v1.7.0` | 3000 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`agentgateway`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Agentgateway with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Agentgateway. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy agentgateway --name my-agentgateway
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
