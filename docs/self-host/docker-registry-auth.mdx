A private container registry with HTTP basic auth baked in at boot, unlike the catalog's open registry entry.

This page describes the Levelrail template for Docker Registry (Authenticated) (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://distribution.github.io/distribution/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `registry` | `registry:3` | 5000 | `registry_auth_data -&#62; /var/lib/registry` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `registry` | `HTPASSWD_PASS` | Generated at deploy |
| `registry` | `HTPASSWD_USER` | Generated at deploy |
| `registry` | `REGISTRY_AUTH` | Preset in the template |
| `registry` | `REGISTRY_AUTH_HTPASSWD_PATH` | Preset in the template |
| `registry` | `REGISTRY_AUTH_HTPASSWD_REALM` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Docker Registry (Authenticated) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Docker Registry (Authenticated). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy docker-registry-auth --name my-docker-registry-auth
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
