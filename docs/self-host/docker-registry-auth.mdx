A private container registry with HTTP basic auth baked in at boot, unlike the catalog's open registry entry.

This page describes the Levelrail template for Docker Registry (Authenticated) (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://distribution.github.io/distribution/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `registry` | `registry:3` | 5000 | `registry_auth_data -&#62; /var/lib/registry` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `registry` | `HTPASSWD_PASS` | Generated at deploy |
| `registry` | `HTPASSWD_USER` | Generated at deploy |
| `registry` | `REGISTRY_AUTH` | Preset in the template |
| `registry` | `REGISTRY_AUTH_HTPASSWD_PATH` | Preset in the template |
| `registry` | `REGISTRY_AUTH_HTPASSWD_REALM` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`registry`): 5000:5000.
- Passwords and keys are generated at deploy time (`registry`): HTPASSWD_PASS, HTPASSWD_USER.
- Stores data in named volumes (`registry`): registry_auth_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Docker Registry (Authenticated) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Docker Registry (Authenticated). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy docker-registry-auth --name my-docker-registry-auth
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
