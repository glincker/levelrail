A lightweight, self-hosted Git service with issues, pull requests, and a package registry.

This page describes the Levelrail template for Gitea (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gitea.com.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `gitea_db_data -&#62; /var/lib/mysql` |
| `gitea` | `gitea/gitea:1.23.1` | 3000, 22 | `gitea_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `gitea` | `GITEA__database__DB_TYPE` | Preset in the template |
| `gitea` | `GITEA__database__HOST` | Preset in the template |
| `gitea` | `GITEA__database__NAME` | Preset in the template |
| `gitea` | `GITEA__database__PASSWD` | Generated at deploy |
| `gitea` | `GITEA__database__USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Gitea with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Gitea. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gitea --name my-gitea
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
