A web-based database manager for browsing and querying Postgres, MySQL, SQLite and more.

This page describes the Levelrail template for CloudBeaver (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://dbeaver.com/docs/cloudbeaver/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cloudbeaver` | `dbeaver/cloudbeaver:24.1.0` | 8978 | `cloudbeaver_workspace -&#62; /opt/cloudbeaver/workspace` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy CloudBeaver with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select CloudBeaver. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy cloudbeaver --name my-cloudbeaver
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
