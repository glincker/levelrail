A fast time series database with SQL, a web console, the PostgreSQL wire protocol on 8812 and InfluxDB line protocol ingestion on 9009. The console and the PostgreSQL port share one generated password. Only the console is offered a domain.

This page describes the Levelrail template for QuestDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://questdb.com/docs/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `questdb` | `questdb/questdb:10.1.0` | 9000, 8812, 9009 | `questdb_data -&#62; /var/lib/questdb` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `questdb` | `QDB_HTTP_PASSWORD` | Generated at deploy |
| `questdb` | `QDB_HTTP_USER` | Preset in the template |
| `questdb` | `QDB_PG_PASSWORD` | Generated at deploy |
| `questdb` | `QDB_PG_USER` | Preset in the template |
| `questdb` | `QDB_TELEMETRY_ENABLED` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`questdb`): QDB_HTTP_PASSWORD, QDB_PG_PASSWORD.
- Stores data in named volumes (`questdb`): questdb_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy QuestDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select QuestDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy questdb --name my-questdb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
