A mature photo gallery with albums, tags, plugins and themes.

This page describes the Levelrail template for Piwigo (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://piwigo.org/doc.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11.4` | none | `piwigo_db -&#62; /var/lib/mysql` |
| `piwigo` | `linuxserver/piwigo:16.5.0` | 80 | `piwigo_config -&#62; /config`<br />`piwigo_gallery -&#62; /gallery` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MARIADB_DATABASE` | Preset in the template |
| `db` | `MARIADB_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_USER` | Preset in the template |
| `piwigo` | `PGID` | Preset in the template |
| `piwigo` | `PUID` | Preset in the template |
| `piwigo` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`): MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- Stores data in named volumes (`db`, `piwigo`): piwigo_config, piwigo_db, piwigo_gallery.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Piwigo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Piwigo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy piwigo --name my-piwigo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
