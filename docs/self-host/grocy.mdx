A self-hosted ERP for your household: groceries, chores, and a shopping list that stays in sync.

This page describes the Levelrail template for Grocy (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://grocy.info/en/docs.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `grocy` | `lscr.io/linuxserver/grocy:4.6.0` | 80 | `grocy_data -&#62; /config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Grocy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Grocy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy grocy --name my-grocy
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
