A widely used open-source support ticket system for teams handling customer requests.

This page describes the Levelrail template for osTicket (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.osticket.com/en/latest/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `osticket_db_data -&#62; /var/lib/mysql` |
| `osticket` | `tiredofit/osticket:1.18.2` | 80 | `osticket_data -&#62; /www/osticket` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MARIADB_DATABASE` | Preset in the template |
| `db` | `MARIADB_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MARIADB_USER` | Preset in the template |
| `osticket` | `ADMIN_EMAIL` | Preset in the template |
| `osticket` | `ADMIN_PASS` | Generated at deploy |
| `osticket` | `ADMIN_USER` | Generated at deploy |
| `osticket` | `DB_HOST` | Preset in the template |
| `osticket` | `DB_NAME` | Preset in the template |
| `osticket` | `DB_PASS` | Generated at deploy |
| `osticket` | `DB_USER` | Preset in the template |
| `osticket` | `INSTALL_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`osticket`): 80:80.
- Passwords and keys are generated at deploy time (`db`, `osticket`): ADMIN_PASS, ADMIN_USER, DB_PASS, INSTALL_SECRET, MARIADB_PASSWORD, MARIADB_ROOT_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `osticket`): osticket_data, osticket_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy osTicket with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select osTicket. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy osticket --name my-osticket
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
