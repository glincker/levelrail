A simple image host with on-the-fly format conversion.

This page describes the Levelrail template for Picsur (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/CaramelFur/Picsur.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:17-alpine` | none | `db_data -&#62; /var/lib/postgresql/data` |
| `picsur` | `ghcr.io/caramelfur/picsur:0.5.6` | 8080 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `picsur` | `PICSUR_ADMIN_PASSWORD` | Generated at deploy |
| `picsur` | `PICSUR_DB_DATABASE` | Preset in the template |
| `picsur` | `PICSUR_DB_HOST` | Preset in the template |
| `picsur` | `PICSUR_DB_PASSWORD` | Generated at deploy |
| `picsur` | `PICSUR_DB_PORT` | Preset in the template |
| `picsur` | `PICSUR_DB_USERNAME` | Preset in the template |
| `picsur` | `PICSUR_JWT_SECRET` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `picsur`): PICSUR_ADMIN_PASSWORD, PICSUR_DB_PASSWORD, PICSUR_JWT_SECRET, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Picsur with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Picsur. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy picsur --name my-picsur
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
