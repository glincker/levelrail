A fast, typo-tolerant search engine API built as a lighter alternative to Elasticsearch.

This page describes the Levelrail template for Typesense (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://typesense.org/docs/guide/install-typesense.html.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `typesense` | `typesense/typesense:30.2` | 8108 | `typesense_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `typesense` | `TYPESENSE_API_KEY` | Generated at deploy |
| `typesense` | `TYPESENSE_DATA_DIR` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Typesense with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Typesense. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy typesense --name my-typesense
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
