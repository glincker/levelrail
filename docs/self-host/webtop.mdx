A full Linux desktop in your browser, running as a container with a login.

This page describes the Levelrail template for Webtop (Applications). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.linuxserver.io/images/docker-webtop/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `webtop` | `lscr.io/linuxserver/webtop:0c46c80a-ls325` | 3000 | `config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `webtop` | `CUSTOM_USER` | Preset in the template |
| `webtop` | `PASSWORD` | Generated at deploy |
| `webtop` | `PGID` | Preset in the template |
| `webtop` | `PUID` | Preset in the template |
| `webtop` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`webtop`): PASSWORD.
- Stores data in named volumes (`webtop`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Webtop with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Webtop. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy webtop --name my-webtop
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
