OpenID Connect identity provider that fronts other identity sources. The install form carries config.yaml as an editable file, so it starts with a local database and the issuer address you choose.

This page describes the Levelrail template for Dex (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://dexidp.io/docs/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `dex` | `ghcr.io/dexidp/dex:v2.46.1` | 5556 | `data -&#62; /var/dex` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- No health check, so a deploy is judged by the process starting (`dex`).
- Stores data in named volumes (`dex`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Dex with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Dex. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy dex --name my-dex
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
