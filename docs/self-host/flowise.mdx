Drag-and-drop builder for LLM chatbots, agents, and RAG flows, with an API for each flow.

This page describes the Levelrail template for Flowise (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.flowiseai.com.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `flowise` | `flowiseai/flowise:3.1.4` | 3000 | `flowise_data -&#62; /root/.flowise` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `flowise` | `APIKEY_PATH` | Preset in the template |
| `flowise` | `BLOB_STORAGE_PATH` | Preset in the template |
| `flowise` | `DATABASE_PATH` | Preset in the template |
| `flowise` | `FLOWISE_PASSWORD` | Generated at deploy |
| `flowise` | `FLOWISE_USERNAME` | Preset in the template |
| `flowise` | `LOG_PATH` | Preset in the template |
| `flowise` | `PORT` | Preset in the template |
| `flowise` | `SECRETKEY_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Flowise with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Flowise. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy flowise --name my-flowise
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
