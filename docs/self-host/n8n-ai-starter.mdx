n8n wired to a local Ollama model and a Qdrant vector store, ready for private AI workflows.

This page describes the Levelrail template for n8n AI Starter Kit (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.n8n.io/advanced-ai.

Recommended memory: about 4096 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `n8n_ai_db_data -&#62; /var/lib/postgresql/data` |
| `n8n` | `n8nio/n8n:1.62.1` | 5678 | `n8n_ai_data -&#62; /home/node/.n8n` |
| `ollama` | `ollama/ollama:0.34.4` | none | `n8n_ai_ollama -&#62; /root/.ollama` |
| `qdrant` | `qdrant/qdrant:v1.12.4` | none | `n8n_ai_qdrant -&#62; /qdrant/storage` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `n8n` | `DB_POSTGRESDB_DATABASE` | Preset in the template |
| `n8n` | `DB_POSTGRESDB_HOST` | Preset in the template |
| `n8n` | `DB_POSTGRESDB_PASSWORD` | Generated at deploy |
| `n8n` | `DB_POSTGRESDB_USER` | Preset in the template |
| `n8n` | `DB_TYPE` | Preset in the template |
| `n8n` | `N8N_ENCRYPTION_KEY` | Generated at deploy |
| `n8n` | `OLLAMA_HOST` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`n8n`): 5678:5678.
- Passwords and keys are generated at deploy time (`db`, `n8n`): DB_POSTGRESDB_PASSWORD, N8N_ENCRYPTION_KEY, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`ollama`, `qdrant`).
- Stores data in named volumes (`db`, `n8n`, `ollama`, `qdrant`): n8n_ai_data, n8n_ai_db_data, n8n_ai_ollama, n8n_ai_qdrant.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy n8n AI Starter Kit with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select n8n AI Starter Kit. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy n8n-ai-starter --name my-n8n-ai-starter
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
