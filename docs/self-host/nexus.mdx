A universal artifact repository for Maven, npm, Docker, PyPI, and more, with proxying and caching.

This page describes the Levelrail template for Sonatype Nexus Repository (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://help.sonatype.com/en/sonatype-nexus-repository.html.

Recommended memory: about 3072 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `nexus` | `sonatype/nexus3:3.96.3` | 8081 | `nexus_data -&#62; /nexus-data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Sonatype Nexus Repository with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Sonatype Nexus Repository. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nexus --name my-nexus
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
