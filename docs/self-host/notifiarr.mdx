Client for the Notifiarr service that relays notifications and syncs profiles for your media apps. The install form carries notifiarr.conf as an editable file and asks for your API key.

This page describes the Levelrail template for Notifiarr (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://notifiarr.wiki/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `notifiarr` | `ghcr.io/notifiarr/notifiarr:v0.10.0` | 5454 | `config -&#62; /config` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- You must provide one or more secrets before it can deploy (`notifiarr`): /etc/notifiarr/notifiarr.conf.
- Stores data in named volumes (`notifiarr`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

<Warning>This template needs configuration before it can deploy. Open it in the dashboard, set each variable marked "You must provide" in the Compose body, then deploy.</Warning>

## Deploy Notifiarr with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Notifiarr. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates get notifiarr --output json | jq -r .compose > notifiarr.compose.yaml
# edit notifiarr.compose.yaml to set the variables you must provide
levelrail-cli apps deploy-compose my-notifiarr --file notifiarr.compose.yaml
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
