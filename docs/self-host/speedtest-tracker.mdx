Runs Ookla speed tests on a schedule and charts your connection's throughput, latency, and jitter over time.

This page describes the Levelrail template for Speedtest Tracker (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.speedtest-tracker.dev.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `speedtest-tracker` | `lscr.io/linuxserver/speedtest-tracker:v1.15.0-ls174` | 80 | `speedtest_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `speedtest-tracker` | `APP_KEY` | Generated at deploy |
| `speedtest-tracker` | `DB_CONNECTION` | Preset in the template |
| `speedtest-tracker` | `PGID` | Preset in the template |
| `speedtest-tracker` | `PUID` | Preset in the template |
| `speedtest-tracker` | `SPEEDTEST_SCHEDULE` | Preset in the template |
| `speedtest-tracker` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`speedtest-tracker`): 8765:80.
- Passwords and keys are generated at deploy time (`speedtest-tracker`): APP_KEY.
- Stores data in named volumes (`speedtest-tracker`): speedtest_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Speedtest Tracker with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Speedtest Tracker. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy speedtest-tracker --name my-speedtest-tracker
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
