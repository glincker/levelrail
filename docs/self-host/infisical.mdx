An open-source secrets manager to centralize API keys, database credentials, and app config.

This page describes the Levelrail template for Infisical (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://infisical.com/docs/self-hosting/overview.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `infisical_db_data -&#62; /var/lib/postgresql/data` |
| `infisical` | `infisical/infisical:v0.154.6` | 8080 | none |
| `redis` | `redis:7-alpine` | none | `infisical_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `infisical` | `AUTH_SECRET` | Generated at deploy |
| `infisical` | `DB_CONNECTION_URI` | Generated at deploy |
| `infisical` | `ENCRYPTION_KEY` | Generated at deploy |
| `infisical` | `REDIS_URL` | Preset in the template |
| `infisical` | `SITE_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`infisical`): 8080:8080.
- Passwords and keys are generated at deploy time (`db`, `infisical`): AUTH_SECRET, DB_CONNECTION_URI, ENCRYPTION_KEY, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`, `redis`).
- Stores data in named volumes (`db`, `redis`): infisical_db_data, infisical_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Infisical with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Infisical. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy infisical --name my-infisical
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
