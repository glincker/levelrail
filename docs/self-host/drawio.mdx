A self-hosted diagramming and whiteboarding editor for flowcharts, architecture diagrams, and more.

This page describes the Levelrail template for draw.io (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.drawio.com/doc/faq/docker.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `drawio` | `jgraph/drawio:29.0.3` | 8080 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy draw.io with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select draw.io. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy drawio --name my-drawio
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
