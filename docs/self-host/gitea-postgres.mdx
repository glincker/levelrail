Gitea backed by Postgres instead of its default MySQL, for operators standardizing on one database engine.

This page describes the Levelrail template for Gitea (Postgres) (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.gitea.com.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `gitea_postgres_db_data -&#62; /var/lib/postgresql/data` |
| `gitea` | `gitea/gitea:1.23.1` | 3000, 22 | `gitea_postgres_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `gitea` | `GITEA__database__DB_TYPE` | Preset in the template |
| `gitea` | `GITEA__database__HOST` | Preset in the template |
| `gitea` | `GITEA__database__NAME` | Preset in the template |
| `gitea` | `GITEA__database__PASSWD` | Generated at deploy |
| `gitea` | `GITEA__database__USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`gitea`): 2222:22, 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `gitea`): GITEA__database__PASSWD, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`, `gitea`): gitea_postgres_data, gitea_postgres_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Gitea (Postgres) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Gitea (Postgres). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gitea-postgres --name my-gitea-postgres
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
