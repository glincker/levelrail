A self-hosted newsletter and mailing list manager with a fast, dependency-light core.

This page describes the Levelrail template for Listmonk (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://listmonk.app/docs/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `listmonk_db_data -&#62; /var/lib/postgresql/data` |
| `listmonk` | `listmonk/listmonk:v6.0.0` | 9000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `listmonk` | `LISTMONK_ADMIN_PASSWORD` | Generated at deploy |
| `listmonk` | `LISTMONK_ADMIN_USER` | Generated at deploy |
| `listmonk` | `LISTMONK_app__address` | Preset in the template |
| `listmonk` | `LISTMONK_db__database` | Preset in the template |
| `listmonk` | `LISTMONK_db__host` | Preset in the template |
| `listmonk` | `LISTMONK_db__password` | Generated at deploy |
| `listmonk` | `LISTMONK_db__port` | Preset in the template |
| `listmonk` | `LISTMONK_db__ssl_mode` | Preset in the template |
| `listmonk` | `LISTMONK_db__user` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`listmonk`): 9000:9000.
- Passwords and keys are generated at deploy time (`db`, `listmonk`): LISTMONK_ADMIN_PASSWORD, LISTMONK_ADMIN_USER, LISTMONK_db__password, POSTGRES_PASSWORD.
- Stores data in named volumes (`db`): listmonk_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Listmonk with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Listmonk. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy listmonk --name my-listmonk
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
