An offline image compression, format conversion, and background-removal API for self-hosted pipelines.

This page describes the Levelrail template for ImgCompress (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://imgcompress.karimzouine.com.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `imgcompress` | `karimz1/imgcompress:0.9.0` | 5000 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy ImgCompress with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ImgCompress. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy imgcompress --name my-imgcompress
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
