A multi model database for graphs and documents with the Studio web console, a generated root password and data volumes. The binary protocol port 2424 stays private.

This page describes the Levelrail template for OrientDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://orientdb.org/docs/3.2.x/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `orientdb` | `orientdb:3.2.58` | 2480, 2424 | `orientdb_databases -&#62; /orientdb/databases`<br />`orientdb_backup -&#62; /orientdb/backup` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `orientdb` | `ORIENTDB_ROOT_PASSWORD` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`orientdb`): ORIENTDB_ROOT_PASSWORD.
- Stores data in named volumes (`orientdb`): orientdb_backup, orientdb_databases.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy OrientDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select OrientDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy orientdb --name my-orientdb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
