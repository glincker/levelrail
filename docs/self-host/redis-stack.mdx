Redis with JSON, search, time series and probabilistic modules built in.

This page describes the Levelrail template for Redis Stack Server (Databases). It deploys the services below as one Docker Compose app on your own server. Project site: https://redis.io/docs/latest/operate/oss_and_stack.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `redis-stack` | `redis/redis-stack-server:7.4.0-v8` | 6379 | `redis_stack_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `redis-stack` | `REDISCLI_AUTH` | Generated at deploy |
| `redis-stack` | `REDIS_ARGS` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`redis-stack`): REDISCLI_AUTH, REDIS_ARGS.
- Stores data in named volumes (`redis-stack`): redis_stack_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Redis Stack Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Redis Stack Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redis-stack --name my-redis-stack
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
