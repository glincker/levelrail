Run your own live video streaming server with built-in chat, no third-party platform required.

This page describes the Levelrail template for Owncast (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://owncast.online/docs.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `owncast` | `owncast/owncast:0.3.0` | 8080, 1935 | `owncast_data -&#62; /app/data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Owncast with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Owncast. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy owncast --name my-owncast
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
