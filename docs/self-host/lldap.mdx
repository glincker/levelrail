A lightweight LDAP server with a friendly web UI, built for homelab and small-team authentication.

This page describes the Levelrail template for lldap (Security). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/lldap/lldap.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `lldap` | `lldap/lldap:v0.6.3` | 17170, 3890 | `lldap_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `lldap` | `LLDAP_JWT_SECRET` | Generated at deploy |
| `lldap` | `LLDAP_KEY_SEED` | Generated at deploy |
| `lldap` | `LLDAP_LDAP_BASE_DN` | Preset in the template |
| `lldap` | `LLDAP_LDAP_USER_PASS` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`lldap`): 17170:17170, 3890:3890.
- Passwords and keys are generated at deploy time (`lldap`): LLDAP_JWT_SECRET, LLDAP_KEY_SEED, LLDAP_LDAP_USER_PASS.
- Stores data in named volumes (`lldap`): lldap_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy lldap with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select lldap. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy lldap --name my-lldap
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
