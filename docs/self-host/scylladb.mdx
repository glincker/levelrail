A wide column database compatible with Cassandra, running as one node in developer mode with a data volume. It has no web page, so connect over the project network at scylladb:9042.

This page describes the Levelrail template for ScyllaDB (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://opensource.docs.scylladb.com/stable/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `scylladb` | `scylladb/scylla:2026.3.5` | 9042 | `scylla_data -&#62; /var/lib/scylla` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`scylladb`): scylla_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy ScyllaDB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select ScyllaDB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy scylladb --name my-scylladb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
