A self-hosted server for your audiobooks and podcasts, with sync across every device.

This page describes the Levelrail template for Audiobookshelf (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.audiobookshelf.org/docs.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `audiobookshelf` | `ghcr.io/advplyr/audiobookshelf:2.34.0` | 80 | `audiobookshelf_config -&#62; /config`<br />`audiobookshelf_metadata -&#62; /metadata`<br />`audiobookshelf_audiobooks -&#62; /audiobooks`<br />`audiobookshelf_podcasts -&#62; /podcasts` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `audiobookshelf` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Audiobookshelf with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Audiobookshelf. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy audiobookshelf --name my-audiobookshelf
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
