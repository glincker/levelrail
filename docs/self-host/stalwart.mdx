An all-in-one SMTP, IMAP, JMAP, and WebDAV mail server in a single lightweight container.

This page describes the Levelrail template for Stalwart Mail Server (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://stalw.art/docs/install/platform/docker/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `stalwart` | `stalwartlabs/stalwart:v0.16.23` | 8080 | `stalwart_config -&#62; /opt/stalwart/etc`<br />`stalwart_data -&#62; /opt/stalwart/data` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Stalwart Mail Server with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Stalwart Mail Server. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy stalwart --name my-stalwart
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
