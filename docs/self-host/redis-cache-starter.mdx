A web service backed by a Redis cache, the cache-aside pattern most apps reach for first.

This page describes the Levelrail template for Redis Cache Starter (Starter Kits). It deploys the services below as one Docker Compose app on your own server. Project site: https://redis.io/docs/latest/develop/connect/clients/.

Recommended memory: about 192 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cache` | `redis:7-alpine` | none | `redis_cache_data -&#62; /data` |
| `web` | `node:22-alpine` | 3000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `web` | `NODE_ENV` | Preset in the template |
| `web` | `REDIS_URL` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Redis Cache Starter with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Redis Cache Starter. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redis-cache-starter --name my-redis-cache-starter
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
