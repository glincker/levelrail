Open-source scheduling infrastructure for booking meetings without the back-and-forth.

This page describes the Levelrail template for Cal.com (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://cal.com/docs/self-hosting/installation.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `calcom` | `calcom/cal.com:v5.0.9` | 3000 | none |
| `db` | `postgres:16-alpine` | none | `calcom_db_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `calcom` | `CALCOM_TELEMETRY_DISABLED` | Preset in the template |
| `calcom` | `CALENDSO_ENCRYPTION_KEY` | Generated at deploy |
| `calcom` | `DATABASE_URL` | Generated at deploy |
| `calcom` | `NEXTAUTH_SECRET` | Generated at deploy |
| `calcom` | `NEXTAUTH_URL` | Preset in the template |
| `calcom` | `NEXT_PUBLIC_WEBAPP_URL` | Preset in the template |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`calcom`): 3000:3000.
- Passwords and keys are generated at deploy time (`calcom`, `db`): CALENDSO_ENCRYPTION_KEY, DATABASE_URL, NEXTAUTH_SECRET, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`): calcom_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Cal.com with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Cal.com. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy calcom --name my-calcom
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
