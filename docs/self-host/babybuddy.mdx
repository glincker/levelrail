Track sleep, feeding, diaper changes, and growth for a baby or toddler, with charts and timers.

This page describes the Levelrail template for Baby Buddy (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.baby-buddy.net/.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `babybuddy` | `lscr.io/linuxserver/babybuddy:latest` | 8000 | `babybuddy_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `babybuddy` | `CSRF_TRUSTED_ORIGINS` | Preset in the template |
| `babybuddy` | `PGID` | Preset in the template |
| `babybuddy` | `PUID` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`babybuddy`): lscr.io/linuxserver/babybuddy:latest.
- Publishes ports directly on the host (`babybuddy`): 8000:8000.
- Stores data in named volumes (`babybuddy`): babybuddy_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Baby Buddy with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Baby Buddy. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy babybuddy --name my-babybuddy
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
