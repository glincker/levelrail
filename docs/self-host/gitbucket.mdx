A Git hosting platform with issues, pull requests and a wiki, on a data volume. The first account is root with the password root, so change it right after the first sign in.

This page describes the Levelrail template for GitBucket (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/gitbucket/gitbucket/wiki.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `gitbucket` | `gitbucket/gitbucket:4.38.4` | 8080 | `gitbucket_data -&#62; /gitbucket` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`gitbucket`): gitbucket_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy GitBucket with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GitBucket. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy gitbucket --name my-gitbucket
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
