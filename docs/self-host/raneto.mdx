A flat file knowledge base that renders a folder of Markdown files as a searchable wiki, packaged by the community maintainers. MIT licensed. Edit pages from the file volume or the built-in editor.

This page describes the Levelrail template for Raneto (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/ryanlelek/Raneto.

Recommended memory: about 192 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `raneto` | `lscr.io/linuxserver/raneto:0.18.1` | 3000 | `config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `raneto` | `PGID` | Preset in the template |
| `raneto` | `PUID` | Preset in the template |
| `raneto` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`raneto`): config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Raneto with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Raneto. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy raneto --name my-raneto
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
