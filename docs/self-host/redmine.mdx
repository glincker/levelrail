A mature project management and issue tracker with Gantt charts, wikis and time tracking, backed by Postgres.

This page describes the Levelrail template for Redmine (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.redmine.org/projects/redmine/wiki/Guide.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `pgdata -&#62; /var/lib/postgresql/data` |
| `redmine` | `redmine:6-alpine` | 3000 | `files -&#62; /usr/src/redmine/files` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `redmine` | `REDMINE_DB_DATABASE` | Preset in the template |
| `redmine` | `REDMINE_DB_PASSWORD` | Generated at deploy |
| `redmine` | `REDMINE_DB_PORT` | Preset in the template |
| `redmine` | `REDMINE_DB_POSTGRES` | Preset in the template |
| `redmine` | `REDMINE_DB_USERNAME` | Preset in the template |
| `redmine` | `SECRET_KEY_BASE` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`, `redmine`): POSTGRES_PASSWORD, REDMINE_DB_PASSWORD, SECRET_KEY_BASE.
- Stores data in named volumes (`db`, `redmine`): files, pgdata.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Redmine with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Redmine. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy redmine --name my-redmine
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
