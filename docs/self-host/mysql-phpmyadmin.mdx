A MySQL 8.4 server paired with the phpMyAdmin web console, already wired together. The database is not published on the host, so other services in this project reach it at db:3306. Sign in to phpMyAdmin as root with the generated root password.

This page describes the Levelrail template for MySQL with phpMyAdmin (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.phpmyadmin.net/en/latest/setup.html#docker.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mysql:8.4.13` | none | `mysql_data -&#62; /var/lib/mysql` |
| `phpmyadmin` | `phpmyadmin:5.2.3` | 80 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `phpmyadmin` | `PMA_HOST` | Preset in the template |
| `phpmyadmin` | `PMA_PORT` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`db`): MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`db`): mysql_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MySQL with phpMyAdmin with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MySQL with phpMyAdmin. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mysql-phpmyadmin --name my-mysql-phpmyadmin
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
