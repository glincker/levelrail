A bookmark manager that archives full page snapshots, not just links, so pages stay readable.

This page describes the Levelrail template for Linkwarden (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.linkwarden.app/self-hosting/setup.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `linkwarden_db_data -&#62; /var/lib/postgresql/data` |
| `linkwarden` | `ghcr.io/linkwarden/linkwarden:v2.9.3` | 3000 | `linkwarden_data -&#62; /data/data` |
| `meilisearch` | `getmeili/meilisearch:v1.11.1` | none | `linkwarden_meili_data -&#62; /meili_data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `linkwarden` | `DATABASE_URL` | Generated at deploy |
| `linkwarden` | `MEILI_HOST` | Preset in the template |
| `linkwarden` | `MEILI_MASTER_KEY` | Generated at deploy |
| `linkwarden` | `NEXTAUTH_SECRET` | Generated at deploy |
| `linkwarden` | `NEXTAUTH_URL` | Preset in the template |
| `meilisearch` | `MEILI_MASTER_KEY` | Generated at deploy |
| `meilisearch` | `MEILI_NO_ANALYTICS` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`linkwarden`): 3000:3000.
- Passwords and keys are generated at deploy time (`db`, `linkwarden`, `meilisearch`): DATABASE_URL, MEILI_MASTER_KEY, NEXTAUTH_SECRET, MEILI_MASTER_KEY, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`, `meilisearch`).
- Stores data in named volumes (`db`, `linkwarden`, `meilisearch`): linkwarden_data, linkwarden_db_data, linkwarden_meili_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Linkwarden with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Linkwarden. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy linkwarden --name my-linkwarden
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
