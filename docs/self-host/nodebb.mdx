A modern forum platform with real-time discussions, SSO, and a plugin ecosystem, backed by Postgres.

This page describes the Levelrail template for NodeBB (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.nodebb.org/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `nodebb` | `ghcr.io/nodebb/nodebb:latest` | 4567 | `nodebb_build -&#62; /usr/src/app/build`<br />`nodebb_uploads -&#62; /usr/src/app/public/uploads`<br />`nodebb_config -&#62; /opt/config` |
| `postgres` | `postgres:16-alpine` | none | `nodebb_postgres_data -&#62; /var/lib/postgresql/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `nodebb` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_DB` | Preset in the template |
| `postgres` | `POSTGRES_PASSWORD` | Generated at deploy |
| `postgres` | `POSTGRES_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`nodebb`): ghcr.io/nodebb/nodebb:latest.
- Publishes ports directly on the host (`nodebb`): 4567:4567.
- Passwords and keys are generated at deploy time (`nodebb`, `postgres`): POSTGRES_PASSWORD.
- Stores data in named volumes (`nodebb`, `postgres`): nodebb_build, nodebb_config, nodebb_postgres_data, nodebb_uploads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy NodeBB with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select NodeBB. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy nodebb --name my-nodebb
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
