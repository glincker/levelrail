A self-hosted, lightweight error tracking server with a Sentry-compatible SDK ingestion API.

This page describes the Levelrail template for Bugsink (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.bugsink.com/docs/.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mysql` | `mysql:8.4` | none | `bugsink_mysql_data -&#62; /var/lib/mysql` |
| `web` | `bugsink/bugsink:latest` | 8000 | none |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mysql` | `MYSQL_DATABASE` | Preset in the template |
| `mysql` | `MYSQL_PASSWORD` | Generated at deploy |
| `mysql` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mysql` | `MYSQL_USER` | Preset in the template |
| `web` | `BASE_URL` | Preset in the template |
| `web` | `BEHIND_HTTPS_PROXY` | Preset in the template |
| `web` | `CREATE_SUPERUSER` | Generated at deploy |
| `web` | `DATABASE_URL` | Generated at deploy |
| `web` | `SECRET_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Bugsink with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Bugsink. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy bugsink --name my-bugsink
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
