A local SMTP server and web inbox for catching and inspecting outgoing email during development.

This page describes the Levelrail template for Mailpit (Developer Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://mailpit.axllent.org/docs/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mailpit` | `axllent/mailpit:v1.21.8` | 8025 | `mailpit_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mailpit` | `MP_DATABASE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Mailpit with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Mailpit. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mailpit --name my-mailpit
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
