An SFTP, FTP/S, and WebDAV server with a web admin UI and per-user storage backends.

This page describes the Levelrail template for SFTPGo (Storage). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.sftpgo.com/latest/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `sftpgo` | `drakkan/sftpgo:v2.6.6` | 8080 | `sftpgo_data -&#62; /srv/sftpgo`<br />`sftpgo_home -&#62; /var/lib/sftpgo` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy SFTPGo with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select SFTPGo. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy sftpgo --name my-sftpgo
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
