An open-source design and prototyping platform, a self-hosted alternative to Figma.

This page describes the Levelrail template for Penpot (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://help.penpot.app.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `backend` | `penpotapp/backend:2.11.1` | none | `penpot_assets -&#62; /opt/data/assets` |
| `exporter` | `penpotapp/exporter:2.11.1` | none | none |
| `frontend` | `penpotapp/frontend:2.11.1` | 8080 | none |
| `postgres` | `postgres:15-alpine` | none | `penpot_db_data -&#62; /var/lib/postgresql/data` |
| `valkey` | `valkey/valkey:8.1-alpine` | none | `penpot_valkey_data -&#62; /data` |

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`frontend`): 8080:8080.
- Passwords and keys are generated at deploy time (`backend`, `postgres`): PENPOT_DATABASE_PASSWORD, PENPOT_DATABASE_USERNAME, PENPOT_SECRET_KEY, POSTGRES_PASSWORD, POSTGRES_USER.
- No health check, so a deploy is judged by the process starting (`backend`, `exporter`, `postgres`, `valkey`).
- Stores data in named volumes (`backend`, `postgres`, `valkey`): penpot_assets, penpot_db_data, penpot_valkey_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Penpot with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Penpot. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy penpot --name my-penpot
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
