Self-hosted invoicing, quotes, and payments for freelancers and small businesses.

This page describes the Levelrail template for Invoice Ninja (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://invoiceninja.github.io.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `mariadb:11` | none | `invoiceninja_db_data -&#62; /var/lib/mysql` |
| `invoiceninja` | `invoiceninja/invoiceninja:5` | 80 | `invoiceninja_data -&#62; /var/www/app/storage` |
| `redis` | `redis:7.4-alpine` | none | `invoiceninja_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `MYSQL_DATABASE` | Preset in the template |
| `db` | `MYSQL_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `db` | `MYSQL_USER` | Preset in the template |
| `invoiceninja` | `APP_KEY` | Generated at deploy |
| `invoiceninja` | `APP_URL` | Preset in the template |
| `invoiceninja` | `DB_DATABASE` | Preset in the template |
| `invoiceninja` | `DB_HOST` | Preset in the template |
| `invoiceninja` | `DB_PASSWORD` | Generated at deploy |
| `invoiceninja` | `DB_USERNAME` | Preset in the template |
| `invoiceninja` | `REDIS_HOST` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`invoiceninja`): 8080:80.
- Passwords and keys are generated at deploy time (`db`, `invoiceninja`): APP_KEY, DB_PASSWORD, MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`, `redis`).
- Stores data in named volumes (`db`, `invoiceninja`, `redis`): invoiceninja_data, invoiceninja_db_data, invoiceninja_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Invoice Ninja with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Invoice Ninja. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy invoice-ninja --name my-invoice-ninja
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
