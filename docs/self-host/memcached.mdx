A fast in-memory cache for query results, sessions and rendered pages, reachable by other apps on host memcached.

This page describes the Levelrail template for Memcached (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://memcached.org/.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `memcached` | `memcached:1.6-alpine` | 11211 | none |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Memcached with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Memcached. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy memcached --name my-memcached
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
