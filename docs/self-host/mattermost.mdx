An open-source, self-hosted alternative to Slack for team messaging and collaboration.

This page describes the Levelrail template for Mattermost (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.mattermost.com.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `mattermost_db_data -&#62; /var/lib/postgresql/data` |
| `mattermost` | `mattermost/mattermost-team-edition:release-10` | 8065 | `mattermost_data -&#62; /mattermost/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `mattermost` | `MM_SERVICESETTINGS_SITEURL` | Preset in the template |
| `mattermost` | `MM_SQLSETTINGS_DATASOURCE` | Generated at deploy |
| `mattermost` | `MM_SQLSETTINGS_DRIVERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`mattermost`): 8065:8065.
- Passwords and keys are generated at deploy time (`db`, `mattermost`): MM_SQLSETTINGS_DATASOURCE, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`).
- Stores data in named volumes (`db`, `mattermost`): mattermost_data, mattermost_db_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Mattermost with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Mattermost. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mattermost --name my-mattermost
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
