A federated, end-to-end encrypted chat server implementing the Matrix protocol.

This page describes the Levelrail template for Matrix Synapse (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://element-hq.github.io/synapse/latest/setup/installation.html.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `synapse` | `matrixdotorg/synapse:v1.145.0` | 8008 | `synapse_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `synapse` | `SYNAPSE_REPORT_STATS` | Preset in the template |
| `synapse` | `SYNAPSE_SERVER_NAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Matrix Synapse with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Matrix Synapse. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy matrix-synapse --name my-matrix-synapse
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
