A self-hosted chat interface for running local large language models through Ollama.

This page describes the Levelrail template for Open WebUI (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://docs.openwebui.com.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ollama` | `ollama/ollama:0.33.3` | none | `ollama_data -&#62; /root/.ollama` |
| `open-webui` | `ghcr.io/open-webui/open-webui:0.11.3` | 8080 | `openwebui_data -&#62; /app/backend/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `open-webui` | `OLLAMA_BASE_URL` | Preset in the template |
| `open-webui` | `WEBUI_SECRET_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`open-webui`): 8080:8080.
- Passwords and keys are generated at deploy time (`open-webui`): WEBUI_SECRET_KEY.
- No health check, so a deploy is judged by the process starting (`ollama`).
- Stores data in named volumes (`ollama`, `open-webui`): ollama_data, openwebui_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Open WebUI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Open WebUI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy open-webui --name my-open-webui
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
