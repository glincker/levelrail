A lightweight, self-hosted error tracking service compatible with the Sentry SDK.

This page describes the Levelrail template for GlitchTip (Monitoring). It deploys the services below as one Docker Compose app on your own server. Project site: https://glitchtip.com/documentation.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `db` | `postgres:16-alpine` | none | `glitchtip_db_data -&#62; /var/lib/postgresql/data` |
| `glitchtip` | `glitchtip/glitchtip:6.0` | 8080 | none |
| `redis` | `redis:7-alpine` | none | `glitchtip_redis_data -&#62; /data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `db` | `POSTGRES_DB` | Preset in the template |
| `db` | `POSTGRES_PASSWORD` | Generated at deploy |
| `db` | `POSTGRES_USER` | Preset in the template |
| `glitchtip` | `DATABASE_URL` | Generated at deploy |
| `glitchtip` | `DEFAULT_FROM_EMAIL` | Preset in the template |
| `glitchtip` | `GLITCHTIP_DOMAIN` | Preset in the template |
| `glitchtip` | `REDIS_URL` | Preset in the template |
| `glitchtip` | `SECRET_KEY` | Generated at deploy |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`glitchtip`): 8080:8080.
- Passwords and keys are generated at deploy time (`db`, `glitchtip`): DATABASE_URL, SECRET_KEY, POSTGRES_PASSWORD.
- No health check, so a deploy is judged by the process starting (`db`, `redis`).
- Stores data in named volumes (`db`, `redis`): glitchtip_db_data, glitchtip_redis_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy GlitchTip with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select GlitchTip. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy glitchtip --name my-glitchtip
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
