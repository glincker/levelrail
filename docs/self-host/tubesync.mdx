Syncs chosen video channels and playlists to local storage on a schedule and keeps media library files tidy.

This page describes the Levelrail template for TubeSync (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/meeb/tubesync.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `tubesync` | `ghcr.io/meeb/tubesync:v0.19.0` | 4848 | `config -&#62; /config`<br />`downloads -&#62; /downloads` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `tubesync` | `HTTP_PASS` | Generated at deploy |
| `tubesync` | `HTTP_USER` | Preset in the template |
| `tubesync` | `PGID` | Preset in the template |
| `tubesync` | `PUID` | Preset in the template |
| `tubesync` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`tubesync`): HTTP_PASS.
- Stores data in named volumes (`tubesync`): config, downloads.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy TubeSync with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select TubeSync. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy tubesync --name my-tubesync
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
