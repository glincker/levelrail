A browser-based IMAP email client with a clean interface, address books, and plugin support.

This page describes the Levelrail template for Roundcube Webmail (Communication). It deploys the services below as one Docker Compose app on your own server. Project site: https://roundcube.net/about.

Recommended memory: about 256 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `roundcube` | `roundcube/roundcubemail:1.7.4-apache` | 80 | `roundcube_db -&#62; /var/roundcube/db` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `roundcube` | `ROUNDCUBEMAIL_DB_TYPE` | Preset in the template |
| `roundcube` | `ROUNDCUBEMAIL_DEFAULT_HOST` | Preset in the template |
| `roundcube` | `ROUNDCUBEMAIL_SMTP_SERVER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Roundcube Webmail with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Roundcube Webmail. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy roundcube --name my-roundcube
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
