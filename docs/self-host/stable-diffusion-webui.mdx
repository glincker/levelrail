A browser interface for generating and editing images with Stable Diffusion checkpoints.

This page describes the Levelrail template for Stable Diffusion WebUI (AI). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/AUTOMATIC1111/stable-diffusion-webui/wiki.

Recommended memory: about 8192 MiB.

<Warning>This template reserves an NVIDIA GPU, so it needs a node with a GPU and the NVIDIA container runtime.</Warning>

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `sd-webui` | `ghcr.io/ai-dock/stable-diffusion-webui:latest-cuda` | 7860 | `sd_webui_workspace -&#62; /workspace` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `sd-webui` | `WEB_ENABLE_AUTH` | Preset in the template |
| `sd-webui` | `WEB_PASSWORD` | Generated at deploy |
| `sd-webui` | `WEB_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Publishes ports directly on the host (`sd-webui`): 7860:7860.
- Passwords and keys are generated at deploy time (`sd-webui`): WEB_PASSWORD.
- Stores data in named volumes (`sd-webui`): sd_webui_workspace.
- Reserves an NVIDIA GPU (`sd-webui`).

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Stable Diffusion WebUI with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Stable Diffusion WebUI. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy stable-diffusion-webui --name my-stable-diffusion-webui
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
