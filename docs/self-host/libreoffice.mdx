A full LibreOffice desktop running in a container, reachable from any browser, for editing office documents.

This page describes the Levelrail template for LibreOffice (Remote Desktop) (Productivity). It deploys the services below as one Docker Compose app on your own server. Project site: https://www.libreoffice.org/discover/libreoffice/.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `libreoffice` | `lscr.io/linuxserver/libreoffice:latest` | 3000 | `libreoffice_config -&#62; /config` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `libreoffice` | `PGID` | Preset in the template |
| `libreoffice` | `PUID` | Preset in the template |
| `libreoffice` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`libreoffice`): lscr.io/linuxserver/libreoffice:latest.
- Publishes ports directly on the host (`libreoffice`): 3000:3000.
- Stores data in named volumes (`libreoffice`): libreoffice_config.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LibreOffice (Remote Desktop) with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LibreOffice (Remote Desktop). Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy libreoffice --name my-libreoffice
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
