A media server that organizes your movies, shows, and music and streams them to any device.

This page describes the Levelrail template for Emby (Media). It deploys the services below as one Docker Compose app on your own server. Project site: https://emby.media/support/articles/Home.html.

Recommended memory: about 1024 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `emby` | `lscr.io/linuxserver/emby:latest` | 8096 | `emby_config -&#62; /config`<br />`emby_tvshows -&#62; /tvshows`<br />`emby_movies -&#62; /movies` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `emby` | `PGID` | Preset in the template |
| `emby` | `PUID` | Preset in the template |
| `emby` | `TZ` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Review before deploying**.

What this template needs:

- Image is not pinned to a version tag, so a redeploy can pull different code (`emby`): lscr.io/linuxserver/emby:latest.
- Publishes ports directly on the host (`emby`): 8096:8096.
- Stores data in named volumes (`emby`): emby_config, emby_movies, emby_tvshows.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Emby with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Emby. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy emby --name my-emby
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
