A browser based SQL and NoSQL client for PostgreSQL, MySQL, MongoDB, Redis and more, with a query editor, schema explorer and saved connections. MIT licensed. The admin password and session secret are generated for you and shown in the deployment variables.

This page describes the Levelrail template for LibreDB Studio (Databases). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/libredb/libredb-studio.

Recommended memory: about 512 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `libredb-studio` | `ghcr.io/libredb/libredb-studio:1.3.0` | 3000 | `data -&#62; /app/data` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `libredb-studio` | `ADMIN_EMAIL` | Preset in the template |
| `libredb-studio` | `ADMIN_PASSWORD` | Generated at deploy |
| `libredb-studio` | `JWT_SECRET` | Generated at deploy |
| `libredb-studio` | `NEXT_PUBLIC_AUTH_PROVIDER` | Preset in the template |
| `libredb-studio` | `STORAGE_PROVIDER` | Preset in the template |
| `libredb-studio` | `STORAGE_SQLITE_PATH` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`libredb-studio`): ADMIN_PASSWORD, JWT_SECRET.
- Stores data in named volumes (`libredb-studio`): data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy LibreDB Studio with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select LibreDB Studio. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy libredb-studio --name my-libredb-studio
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
