A self-hosted, privacy-friendly web analytics tool that tracks page views without cookies or personal data. MIT licensed. Runs with a MongoDB service. The admin password is generated for you and shown in the deployment variables.

This page describes the Levelrail template for Ackee (Analytics). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/electerious/Ackee/blob/master/docs/Get%20started.md.

Recommended memory: about 640 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `ackee` | `electerious/ackee:3.7.1` | 3000 | none |
| `mongo` | `mongo:7.0.45` | none | `mongo -&#62; /data/db` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `ackee` | `ACKEE_MONGODB` | Preset in the template |
| `ackee` | `ACKEE_PASSWORD` | Generated at deploy |
| `ackee` | `ACKEE_TRACKER` | Preset in the template |
| `ackee` | `ACKEE_USERNAME` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`ackee`): ACKEE_PASSWORD.
- Stores data in named volumes (`mongo`): mongo.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Ackee with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Ackee. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy ackee --name my-ackee
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
