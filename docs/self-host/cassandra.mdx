A single node Apache Cassandra wide-column database on the official image, with a persistent volume. It is not published on the host and starts without authentication, so reach it only from other services in this project at cassandra:9042. A node needs about 2 GB of memory.

This page describes the Levelrail template for Apache Cassandra (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://cassandra.apache.org/doc/latest/.

Recommended memory: about 2048 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `cassandra` | `cassandra:5.0.2` | 9042 | `cassandra_data -&#62; /var/lib/cassandra` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `cassandra` | `CASSANDRA_CLUSTER_NAME` | Preset in the template |
| `cassandra` | `HEAP_NEWSIZE` | Preset in the template |
| `cassandra` | `MAX_HEAP_SIZE` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Stores data in named volumes (`cassandra`): cassandra_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy Apache Cassandra with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Apache Cassandra. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy cassandra --name my-cassandra
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
