The MySQL Community database server on the official image, with a persistent volume, generated root and user passwords, and an application database. It is not published on the host, so reach it from other services in this project at mysql:3306.

This page describes the Levelrail template for MySQL (Database Tools). It deploys the services below as one Docker Compose app on your own server. Project site: https://dev.mysql.com/doc/refman/8.4/en/.

Recommended memory: about 768 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `mysql` | `mysql:8.4.13` | 3306 | `mysql_data -&#62; /var/lib/mysql` |

## Environment variables

| Service | Variable | Value |
| --- | --- | --- |
| `mysql` | `MYSQL_DATABASE` | Preset in the template |
| `mysql` | `MYSQL_PASSWORD` | Generated at deploy |
| `mysql` | `MYSQL_ROOT_PASSWORD` | Generated at deploy |
| `mysql` | `MYSQL_USER` | Preset in the template |

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Security and requirements

Level: **Standard**.

What this template needs:

- Passwords and keys are generated at deploy time (`mysql`): MYSQL_PASSWORD, MYSQL_ROOT_PASSWORD.
- Stores data in named volumes (`mysql`): mysql_data.

What Levelrail adds around it:

- Automatic HTTPS and an ingress shield in front of every domain.
- Secrets are generated, stored encrypted and masked in logs and the UI.
- Named volumes can be backed up and restored.
- Deploys are gated on the health check before traffic switches.
- One-step rollback to the previous revision.
- Exposure report shows what is reachable from outside.
- Host firewall rules managed for published ports.

## Deploy MySQL with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select MySQL. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy mysql --name my-mysql
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
