A personal subscription tracker that shows what you pay each month, with reminders and multi-currency support.

This page describes the Levelrail template for Wallos (Finance). It deploys the services below as one Docker Compose app on your own server. Project site: https://github.com/ellite/Wallos.

Recommended memory: about 128 MiB.

## Services, ports and volumes

| Service | Image | Container ports | Volumes |
| --- | --- | --- | --- |
| `wallos` | `bellamy/wallos:5.8.1` | 80 | `wallos_db -&#62; /var/www/html/db`<br />`wallos_logos -&#62; /var/www/html/images/uploads/logos` |

## Environment variables

This template sets no environment variables.

Passwords and keys marked as generated are created for you when the app is deployed and stored as secrets. Values are not shown here.

## Deploy Wallos with Levelrail

In the dashboard, open **Apps**, choose **New app**, then **Browse templates**, and select Wallos. Review the Compose body and deploy.

With the CLI:

```bash
levelrail-cli templates deploy wallos --name my-wallos
```

See the [service template catalog](/templates-and-registry) for how templates work, and [Getting started](/getting-started) if you have not installed Levelrail yet.
