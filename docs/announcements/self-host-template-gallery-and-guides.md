# Self-host template gallery and guides are live

The docs now include a [self-host template gallery](/self-host/) with a page for each of the 330 catalog templates, listing the services, ports, volumes and environment variables each one deploys.

Three new guides cover [Coolify versus Levelrail](/guides/coolify-vs-levelrail), [self-hosting Postgres with backups](/guides/self-host-postgres-with-backups) and [zero-downtime deploys without Kubernetes](/guides/zero-downtime-deploys-without-kubernetes).

You can follow along by RSS, Atom or JSON Feed from the [announcements page](/announcements/).
