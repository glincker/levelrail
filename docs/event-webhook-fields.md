The dashboard form, the CLI flags and the API all read one field registry, served at `GET /api/v1/field-descriptors/event-webhooks`. Secrets are write only: they are accepted on create and update and never returned.

| Field | Type | Required | Shown when | CLI flag | Description |
| --- | --- | --- | --- | --- | --- |
| `name` (name) | string | yes | always | `--name` | webhook name |
| `url` (url) | string | yes | always | `--url` | https endpoint that receives signed POSTs |
| `events` (events) | string | no | always | `--event` | event type or family such as apps.*, comma separated or repeated; empty delivers every event |
