Runtime settings are the controls operators change in production. A stored value always wins, the environment variable only seeds the default while nothing is stored, and a setting marked live applies without a restart. There are 122 settings.

Change one in the dashboard under Settings > Runtime, or with the CLI:

```bash
levelrail-cli settings runtime list
levelrail-cli settings runtime get <key>
levelrail-cli settings runtime set <key> <value>
levelrail-cli settings runtime reset <key>
```

The environment variables that seed these defaults are also listed on [Environment variables](/environment-variables#runtime-settings).
