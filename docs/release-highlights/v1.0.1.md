- **574 catalog templates.** 346 are proven by a real engine run. The other 228 are flagged Preview: they install today and move to proven as they pass.
- **Template inputs.** Templates can take file inputs and secret inputs at install time.
- **Capability tiers.** Services run with a declared tier that lists the Linux capabilities they get.
- **Secret connections.** Link Vault or OpenBao, Doppler, Infisical or 1Password and reference values with `secret://`, with allow lists and a required-reference policy.
- **Preview cloud connections.** Off by default.

Install:

```sh
curl -fsSL https://levelrail.com/install.sh | sudo sh
```

**Upgrade notes**

- Environment-restricted secret connections reject cloned and preview environments until the policy lists them.
- Secret refs written by deploys resolve only after root binds them.
