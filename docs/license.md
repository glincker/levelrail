# License and notices

Levelrail is licensed under the [Apache License, Version 2.0](https://github.com/glincker/levelrail/blob/main/LICENSE). There is one edition, with no license key and no feature gated behind a plan.

## What it allows

- Use the software for any purpose, including commercially.
- Modify it and distribute your changes.
- Use it in private without sharing your changes.

## What it asks

- Keep the license text and copyright notices when you redistribute it.
- State significant changes you make to files you redistribute.
- Understand it is provided without warranty. See the [terms of use](/terms).

## Patents and trademarks

The license includes a patent grant from contributors. It does not grant rights to use the Levelrail name or logo beyond describing where the software comes from.

## Contributions

Contributions are accepted under the same license. See the [contributing guide](https://github.com/glincker/levelrail/blob/main/CONTRIBUTING.md).

## Third-party software

Levelrail builds on open source libraries, each under its own license. The dependency manifests in the repository list them, and the project's supply-chain documentation describes how they are tracked: see [supply chain](/supply-chain).

## Security

Report vulnerabilities through the [security policy](https://github.com/glincker/levelrail/blob/main/SECURITY.md).
