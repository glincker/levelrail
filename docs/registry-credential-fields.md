The dashboard form, the CLI flags and the API all read one field registry, served at `GET /api/v1/field-descriptors/registry-credentials`. Secrets are write only: they are accepted on create and update and never returned.

| Field | Type | Required | Shown when | CLI flag | Description |
| --- | --- | --- | --- | --- | --- |
| `name` (name) | string | yes | always | `--name` | display name, referenced from app.yaml build.registryCredential |
| `registry_host` (registry_host) | string | yes | always | `--registry-host` | registry hostname, for example ghcr.io |
| `username` (username) | string | yes | always | `--username` | registry username |
| `password` (password) | secret, write only | yes | always | `--password` | registry password or access token, write only |
| `expires_at` (expires_at) | string | no | always | `--expires-at` | optional RFC3339 expiry the operator already knows, for example from a GitHub token |
