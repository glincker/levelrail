The dashboard form, the CLI flags and the API all read one field registry, served at `GET /api/v1/field-descriptors/status-page-webhooks`. Secrets are write only: they are accepted on create and update and never returned.

| Field | Type | Required | Shown when | CLI flag | Description |
| --- | --- | --- | --- | --- | --- |
| `url` (url) | string | yes | always | `--url` | https URL that receives the signed events |
| `label` (label) | string | no | always | `--label` | short name for this subscriber |
| `events` (events) | string | no | always | `--event` | event to send, repeatable: incident_opened, incident_updated, incident_resolved, component_changed, maintenance_scheduled, maintenance_updated, maintenance_completed; empty sends all |
