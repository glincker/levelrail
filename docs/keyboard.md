## Lists

These single keys work on the Apps, Databases, Builds, Domains, Backups, Certificates, Servers, Alerts history, Firewall rules and Projects lists. Deployments has its own shortcuts.

| Key | Action |
| --- | --- |
| `j` | Move focus to the next row |
| `k` | Move focus to the previous row |
| `x` | Select or clear the focused row |
| `Enter` | Open the focused row |
| `/` | Focus the list filter |
| `?` | Show or hide the shortcut hint |
| `Esc` | Hide the hint |

The keys never fire while you type in an input, a text area, a select or an editable region, and never when Ctrl, Cmd or Alt is held.

## Turning them off

Single character shortcuts can clash with screen readers and speech input (WCAG 2.1.4). Turn them off in **Settings > Appearance > Keyboard shortcuts for lists**. The choice is on by default, stored in this browser and synced with the rest of your appearance settings.
